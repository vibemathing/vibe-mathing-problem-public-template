# Glossary

**`add_assoc`** — Reassociates addition: `(a+b)+c = a+(b+c)`; essential for exposing rewrite/cancellation patterns. (Addition)

**`add_comm`** — Swaps addends; enables mirrored proofs and AC normalization. (Addition)

**`add_succ`** — Primitive recursion equation `a + succ d = succ (a+d)`. (Foundation/Tutorial)

**`add_zero`** — Primitive base equation `a + 0 = a`. (Foundation/Tutorial)

**`apply`** — Uses an implication/theorem either backward on a goal or forward at a hypothesis. (Implication)

**`cases`** — Eliminates an inductive value/hypothesis into constructor branches; use when no induction hypothesis is needed. (Advanced Addition onward)

**`decide`** — NNG custom route for closed decidable propositions after MyNat-specific simplification. (Algorithm)

**`DecidableEq MyNat`** — Recursive verified procedure deciding equality of two game naturals. (Algorithm/Foundation)

**`exact`** — Closes a goal with a proof whose type matches it. (Implication)

**`generalizing`** — Induction option that keeps dependent variables universally quantified in the IH. (Advanced Multiplication)

**`induction`** — Zero/successor induction; align the induction variable with the recursive argument of the operation. (Addition)

**`is_zero`** — Constructor discriminator used to derive `zero_ne_succ`/related algorithmic facts. (Peano/Algorithm)

**`le` / `≤`** — In NNG, `a ≤ b` means `∃ c, b = a + c`; a proof carries an additive-gap witness. (≤ World)

**`left` / `right`** — Select the branch of a disjunction goal. (≤ World)

**`mul_succ`** — Primitive recursion equation `a * succ b = a*b + a`. (Multiplication)

**`mul_zero`** — Primitive multiplication base equation `a * 0 = 0`. (Multiplication)

**MyNat** — Game natural numbers, generated by `zero` and `succ`; displayed as `ℕ` in the curriculum. (Foundation)

**`nth_rewrite`** — Rewrites a chosen occurrence when ordinary `rw` would target the wrong one. (Tutorial/Power/Advanced Multiplication)

**Negation (`≠`)** — `a ≠ b` is `a = b → False`; prove it by assuming equality and deriving a contradiction. (Implication)

**`pow_succ`** — Primitive exponent recursion: `a ^ succ n = a^n * a`. (Power)

**`pow_zero`** — Primitive exponent base: `a ^ 0 = 1`. (Power)

**`pred`** — Predecessor observation, used to turn successor equality into predecessor equality. (Peano/Algorithm)

**`rfl`** — Reflexive closure; NNG intentionally restricts its reducibility compared with ordinary Lean behavior. (Tutorial)

**`rw`** — Directed equality substitution; NNG custom behavior does not automatically finish with reflexivity. (Tutorial)

**`simp_add`** — Controlled automation for associative/commutative addition normalization. (Algorithm)

**`succ`** — Successor constructor of MyNat. (Foundation)

**`succ_inj`** — Successor injectivity: equality of successors implies equality of predecessors. (Peano/Implication)

**`tauto`** — Propositional automation used after arithmetic/constructor facts are in context; it does not supply missing arithmetic facts. (Advanced Multiplication)

**`use`** — Supplies an existential witness; especially important for the witness definition of `≤`. (≤ World)

**`xyzzy`** — Hidden final-level escape hatch backed by an unrestricted axiom; game mechanism, not a derivation of FLT. (Power final boss)

**`zero_ne_succ`** — Zero cannot equal a successor; the core contradiction used in many inequality/negation proofs. (Peano/Implication)
