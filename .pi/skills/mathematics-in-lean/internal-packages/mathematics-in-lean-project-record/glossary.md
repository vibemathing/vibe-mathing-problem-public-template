# Glossary — Mathematics in Lean

**`apply`** — Matches a theorem's conclusion to the current target and turns unmet premises into subgoals (Ch 2).

**`calc`** — Structured transitive reasoning that makes intermediate expressions explicit (Ch 2).

**Class / instance** — A structure eligible for typeclass synthesis / a registered inhabitant that Lean can synthesize automatically (Ch 7–8).

**`comap`** — Pulls a subobject/filter/topology backward along a function; commonly paired with `map` in a Galois connection (Ch 8–11).

**Continuous linear map (`→L`)** — Bundled map carrying linearity and continuity, with an operator norm (Ch 12).

**Definitional equality** — Equality Lean can recognize by reduction/unfolding without a propositional proof; `rfl` exploits it (Ch 2).

**`deriv` / `fderiv`** — Total derivative functions; return a default value at nondifferentiability, so hypotheses still matter for most theorems (Ch 12).

**`DFunLike`** — Abstraction for bundled function-like objects, supporting coercion to functions and extensionality/injectivity (Ch 8).

**`Eventually` (`∀ᶠ`)** — A predicate holds on a set belonging to a filter; central for “for sufficiently large/close/almost every” reasoning (Ch 11, 13).

**Extensionality (`ext`)** — Prove equality by equality of observable components, values, or membership (Ch 3–4, 7, 10).

**Filter** — A generalized notion of sufficiently large/near sets; the basis for `Tendsto`, eventual behavior, neighborhoods, and almost-everywhere filters (Ch 11).

**Finset** — Computational finite set, usually requiring decidable equality for operations such as membership/intersection (Ch 5–6).

**Fintype** — A type equipped with a finite enumeration of all elements; type-level analogue of a finset (Ch 6).

**Galois connection** — Paired monotone operations such as map/comap where each direction characterizes the other by an order equivalence (Ch 4, 10–11).

**`HasBasis`** — Describes a filter using a generating family of sets; bridges abstract filters and ε–N/ball formulations (Ch 11).

**`HasDerivAt` / `HasFDerivAt`** — Proof-bearing predicates asserting a specific derivative at a point; preferred when differentiability data is available (Ch 12).

**Image / preimage** — Direct image introduces an existential witness; preimage reduces membership to a function application and is often easier to reason with (Ch 4).

**Inductive type** — A type generated by constructors, with corresponding recursion and structural induction principles (Ch 5–6).

**`LinearMap` (`→ₗ`)** — Bundled linear map used throughout Mathlib linear algebra; supports composition, kernels, ranges, and algebraic structure (Ch 10).

**`map`** — Pushes a subobject/filter/topology forward along a function; dual to `comap` (Ch 8–11).

**Morphism** — Structure-preserving map; Mathlib generally bundles reusable algebraic morphisms rather than storing a property on a bare function (Ch 8–10).

**Neighborhood filter (`nhds`)** — Filter of sets sufficiently near a point; continuity at a point is a `Tendsto` statement between neighborhood filters (Ch 11).

**`outParam`** — Marks a typeclass parameter intended to be inferred after the main class/morphism type is known, avoiding problematic search (Ch 8).

**Quotient / lift** — Quotients identify elements by an equivalence relation; `lift` defines maps out of a quotient once representative-independence is proved (Ch 8–10).

**`rcases` / `rintro`** — Recursive pattern destructuring of existentials, conjunctions, disjunctions, and introduced hypotheses (Ch 3).

**`rw`** — Syntactic rewriting by equalities or iff lemmas, with direction/location control (Ch 2–4).

**`SetLike`** — Abstraction for bundled subobjects that coerce to sets while retaining additional closure structure (Ch 8).

**`simp`** — Repeated simplification using a curated lemma set; `simp only` restricts the database for predictability (Ch 3–10).

**Submodule / subgroup / ideal** — Bundled subobjects that inherit ambient algebraic structure and form lattices; use map/comap, top/bottom, kernel/range APIs (Ch 8–10).

**`Tendsto`** — Filter-based convergence: the pushforward of the source filter is below the target filter (Ch 11).

**Typeclass inference** — Lean's search mechanism for instance-implicit square-bracket arguments, enabling generic notation and inherited mathematical structure (Ch 7–8).

**Universal property** — Characterizes an object by canonical mapping behavior; often the best way to construct maps from bases, quotients, free objects, and polynomial algebras (Ch 8–10).
