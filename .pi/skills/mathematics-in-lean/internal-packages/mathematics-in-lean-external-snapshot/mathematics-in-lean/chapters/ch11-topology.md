# Chapter 11: Topology

## Core Idea
Use filters as the common algebra for limits, neighborhoods, restricted convergence, eventual behavior, uniformity, and cluster points. Metric epsilon statements are concrete filter bases; general topology gains functoriality and complete-lattice structure through induced/coinduced topologies and neighborhood filters.

## Frameworks Introduced

- **Filter-as-generalized-set model**
  - A filter collects sets regarded as sufficiently large/near/eventual.
  - `𝓟 s` is the principal filter generated by a set.
  - Order is chosen so principal filters preserve set inclusion.
  - Bottom is the trivial filter containing every set; some theorems therefore require `NeBot`.

- **Tendsto algebra**
  - When to use: any limit/convergence statement.
  - How: read `Tendsto f F G` as `Filter.map f F ≤ G`. Compose limits through the algebra of `Filter.map`/`Tendsto`; restrict or pull domains with `comap`; use products/infima for multiple coordinates or simultaneous conditions.
  - Benefit: one theorem replaces many epsilon variants (point, infinity, one-sided, restricted, sequence, etc.).

- **Basis boundary**
  - When to use: abstract filter theorem must become a concrete epsilon/ball inequality, or vice versa.
  - How: use `HasBasis` for `atTop`, `𝓝 x`, balls/closed balls, and then `HasBasis.tendsto_iff`/membership lemmas. Stay abstract until the concrete inequality is needed.

- **Eventually algebra**
  - When to use: several properties hold sufficiently late/near/almost everywhere.
  - How: represent `P` as `∀ᶠ x in F, P x`; combine with `.and`; strengthen with `.mono`; use `filter_upwards` to gather multiple eventual hypotheses into one pointwise context. Use `Frequently` for “arbitrarily often.”

- **Metric-space bridge**
  - When to use: prove continuity/convergence/closedness in metric terms.
  - How: use `Metric.tendsto_atTop`, `Metric.continuous_iff`, ball/closed-ball neighborhood bases, and distance lemmas. Let `continuity` or compositional continuity lemmas handle standard expressions.

- **Compactness/completeness route**
  - Compact metric set: subsequence convergence, extrema of continuous functions, closedness.
  - Complete metric space: Cauchy sequences converge.
  - For Baire-style arguments, construct nested closed balls with radii tending to zero and a Cauchy sequence of centers.

- **Induced/coinduced topology route**
  - When to use: subtypes, quotients, products, or topology transported by a map.
  - How: `TopologicalSpace.induced` pulls a topology back; `coinduced` pushes one forward; they form a Galois connection. Product topology is an infimum of induced topologies through coordinate projections.

- **Separation/countability assumptions**
  - `T2Space` gives uniqueness of limits.
  - `RegularSpace`/`T3Space` supply closed neighborhood bases useful for extension arguments.
  - `FirstCountableTopology` allows closure to be characterized by sequences.

## Key Concepts

- **Filter**: generalized set of “large/near” inputs.
- **`map` / `comap`**: pushforward/pullback of filters; a Galois connection.
- **`Tendsto`**: convergence expressed as filter inclusion.
- **`Eventually` / `Frequently`**: quantified behavior relative to a filter.
- **`NeBot`**: filter nontriviality; needed for cluster/existence reasoning.
- **Filter basis**: selected family generating all members of a filter.
- **Metric space**: topology arising from a distance.
- **Uniform continuity**: one input-distance bound works uniformly over all points.
- **Cauchy sequence**: eventually pairwise close; converges in complete spaces.
- **Topological space**: structure captured by open sets or equivalently compatible neighborhood filters.
- **Induced/coinduced topology**: initial/final topology constructions along maps.
- **Cluster point**: point whose neighborhood filter has nontrivial intersection with another filter.
- **Compact set**: every nontrivial filter contained in it has a cluster point in it; equivalent to familiar finite-cover/subsequence formulations under suitable assumptions.

## Mental Models

- `atTop` is the generalized set of very large values; `𝓝 x` is the generalized set of points near `x`; `map f` takes generalized direct images.
- Epsilon proofs are basis expansions of filter inequalities. Move back to filters after proving the concrete estimate.
- `filter_upwards` is the abstract replacement for repeatedly taking maxima of finitely many threshold indices.
- Topologies are ordered to make neighborhood filters monotone, so the order direction may look opposite to “has more open sets.”
- General topology deliberately includes pathological spaces; add separation/countability typeclasses only where the desired theorem needs them.

## Anti-patterns

- **Writing a separate epsilon proof for every limit variant**: encode source/target behavior as filters and reuse composition/order theorems.
- **Unfolding filter membership too early**: algebraic `map`/`comap`/order proofs are usually shorter.
- **Forgetting `NeBot`**: bottom-filter convergence can make existence claims vacuous.
- **Building continuity through a syntactically hidden composition and expecting `apply Continuous.comp` to elaborate**: use pointwise combinators (`.dist`, `.add`, `.prodMk`) or `continuity`.
- **Assuming limit uniqueness in an arbitrary topology**: require Hausdorff/T2.
- **Using sequential closure without first countability**: the sequence characterization needs that assumption.

## Code Examples

```lean
open Filter

example {X Y : Type*} (f : X → Y) (F : Filter X) (G : Filter Y) :
    Tendsto f F G ↔ map f F ≤ G := Iff.rfl
```

- **What it demonstrates**: convergence is a filter-order statement.

```lean
example (P Q : ℕ → Prop)
    (hP : ∀ᶠ n in atTop, P n) (hQ : ∀ᶠ n in atTop, Q n) :
    ∀ᶠ n in atTop, P n ∧ Q n :=
  hP.and hQ
```

- **What it demonstrates**: finite threshold bookkeeping is absorbed by the filter intersection axiom.

```lean
example {X Y : Type*} [MetricSpace X] [MetricSpace Y]
    {f : X → Y} (hf : Continuous f) :
    Continuous fun p : X × X => dist (f p.1) (f p.2) :=
  hf.fst'.dist hf.snd'
```

- **What it demonstrates**: pointwise continuity combinators can elaborate more reliably than exposing nested compositions.

## Worked Example

To prove coordinatewise convergence into a product, replace `𝓝 (x₀,y₀)` with `𝓝 x₀ ×ˢ 𝓝 y₀`. The product filter is built from pullbacks along `Prod.fst` and `Prod.snd` combined with infimum. Unfolding only enough to use `le_inf_iff` turns a single `Tendsto f atTop (𝓝 (x₀,y₀))` into the conjunction of the two coordinate `Tendsto` statements. This algebraic argument works without epsilon bookkeeping.

For Baire's theorem in a complete metric space, use density/open assumptions to recursively choose nested closed balls whose radii are geometrically bounded. Their centers form a Cauchy sequence; completeness supplies a limit. Closedness/nesting places the limit in every dense open set and in the starting neighborhood. The proof combines choice, recursive construction, geometric-series control, and metric completeness; each part has a separate invariant.

## Key Takeaways

1. Filters unify limit variants and “eventually” reasoning.
2. `map`/`comap` and order let convergence proofs stay algebraic.
3. Filter bases are the controlled bridge back to epsilon/ball statements.
4. Topological induced/coinduced constructions solve functorial problems that metrics cannot.
5. Separation, countability, compactness, and completeness assumptions should be added exactly where their theorems require them.
