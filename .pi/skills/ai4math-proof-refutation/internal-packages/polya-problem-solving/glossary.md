# Glossary

**Analogy（类比）** — 根据各部分之间的对应关系迁移结果或方法；只能提供启发或需另行验证。（Ch 03–04）

**Analysis / backward work（分析 / 逆向工作）** — 暂把目标视为已达，从目标追问前置条件，直到连接到已知。（Ch 05）

**Auxiliary element（辅助元素）** — 为使某个已知方法可用而有目的引入的线、点、变量、构造或定理。（Ch 03）

**Auxiliary problem（辅助问题）** — 为原问题服务的较易、较熟悉、较特殊、较一般或类似问题。（Ch 03–04）

**Condition（条件）** — 在求解题中把未知量与已知条件联系起来的要求；可能充分、不充分、多余或矛盾。（Ch 02）

**Conjecture（猜想）** — 由观察、类比或启发式推理产生的暂定断言；须检验并最终证明或否证。（Ch 06）

**Contradiction / reductio（归谬法）** — 从假定情形推出明显矛盾，从而否定该假定。（Ch 07）

**Decomposition and recombination（分解与重组）** — 先把主要部分拆开，再通过改变固定/变化的部分形成更有利组合。（Ch 04）

**Definition（定义）** — 把术语展开为精确关系的入口；用于重新表述并检查基本概念是否真正被使用。（Ch 02, 04）

**Dimensional check（量纲检验）** — 比较公式各项和两边的量纲一致性；是快速检错工具，不是完整证明。（Ch 08）

**Execution（执行）** — 在已有计划后，把启发式联系转成逐步可辩护的推导、计算或构造。（Ch 07）

**Generalization（一般化）** — 从较窄对象转向包含它的更广集合，以暴露本质结构。（Ch 04）

**Heuristic reasoning（启发式推理）** — 暂时、合情而非最终严格的推理，用来发现解法。（Ch 06–07）

**Induction（归纳）** — 从具体实例发现一般规律的过程；与严格的数学归纳法区分。（Ch 06）

**Lemma（引理）** — 为主定理服务的辅助定理。（Ch 03, 07）

**Mathematical induction（数学归纳法）** — 对整数参数命题证明基例与 `n→n+1` 的严格方法。（Ch 07）

**Notation（记号）** — 用无歧义、易记、能反映对象关系的符号组织问题。（Ch 11）

**Practical problem（实际问题）** — 目标、数据、条件与概念往往模糊，需要选择显著因素与模型近似。（Ch 10）

**Progress sign（进展的征兆）** — 提示某路线更值得继续的启发式证据，如未用条件被连接、结构变得协调。（Ch 06, 12）

**Proof problem（证明题）** — 目标是确立或否定断言；主要部分通常是假设与结论。（Ch 02, 07）

**Reformulation（重新表述）** — 用等价或更有操作性的语言表达同一问题。（Ch 04）

**Review（回顾）** — 解后检验、替代推导、简化、一般化与迁移的方法阶段。（Ch 08）

**Solve problem（求解题）** — 目标是找到满足条件的对象；主要部分是未知量、已知条件、条件。（Ch 02）

**Specialization（特殊化）** — 转向较小集合、简单或极端情形，用于降低复杂度、找反例或获取线索。（Ch 04, 08）

**Synthesis（综合）** — 从逆向分析抵达的已知点出发，按相反次序正向完成构造或证明。（Ch 05）

**Symmetry（对称）** — 可互换部分应优先获得相同处理；也是设计与检查结果的线索。（Ch 04, 08）

**Transformation of problem（问题的变换）** — 改变表述、条件、未知量、问题层级或表示来创造新联系。（Ch 04）

**Unknown（未知量）** — 求解题真正要求得到的对象；是检索相关问题的高价值索引。（Ch 02–03）
