# Chapter 6: 启发式推理、猜想与进展信号

**Source**: 第三部分“启发式推理”“考察你的猜想”“归纳与数学归纳法”“进展与成就”“进展的征兆”“灵感”“一般化”“特殊化”。

## Core Idea

计划出现之前，很多合理推断只能提高某个方向的可信度。把这种“有希望”明确标记为暂时状态，既能利用直觉，又能避免把发现工具冒充证明。

## Frameworks Introduced

- **启发式推理**
  - 用类比、归纳、特殊情形、对称、先验经验来生成和排序路线。
  - 输出：更可信 / 更值得尝试，不输出“已证明”。
- **猜想检验**
  1. 把模糊直觉写成精确断言。
  2. 寻找支持例，也主动找反例。
  3. 检验简单、极端、边界情形。
  4. 失败则修正猜想；存活则转入证明。
- **归纳发现**
  - 观察若干例 → 找规律 → 一般化 → 用新例与结构检验。
- **进展信号**
  - 未用数据进入结构；
  - 条件条款逐步被解释；
  - 相关已解题或更简单问题浮现；
  - 结果开始具有预期的对称、边界或量纲性质。
- **灵感**
  - 可视为问题表征的突然重组；强烈信号仍需验证。

## Key Concepts

- **调动**: 唤回相关知识。
- **组织**: 形成适合当前题的连接。
- **合情推理**: 增减信心的推理。
- **反例**: 一个即可推翻一般断言。
- **进展迹象**: 分配注意力的证据，不能替代证明。

## Anti-patterns

- **确认偏误**: 只找支持猜想的例子。
- **没有想法就拒绝暂时猜测**: 发现过程会停滞。
- **看到一个好迹象就宣布成功**。
- **把数学归纳法与经验归纳混为一谈**: 前者是证明模式，后者是发现过程。

## Worked Example

观察前几个连续立方和后，可猜它们有统一平方形式。先用更多小规模值检验，再观察平方根本身的规律，使猜想变得更精确。精确表达后，才可能寻找从 `n` 到 `n+1` 的结构关系，进而转成严格的数学归纳证明。这里“经验归纳 → 精确猜想 → 严格证明”是三个不同状态。

## Key Takeaways

1. 暂时可信的推理是发现的脚手架。
2. 好猜想需要精确化和反向压力测试。
3. 进展信号帮助决定继续还是换路。
4. 灵感应跟随，同时保留怀疑。
5. 一旦进入交付阶段，所有关键启发式步骤都要被严格替换或明确标注。
