# Chapter 8: 回顾、验证与再利用

**Source**: 第一部分“回顾”；第三部分“你能检验结果吗？”“你能用别的方法导出这个结果吗？”“你能利用这个结果吗？”“量纲检验”“对称”“特殊化”。

## Core Idea

答案出现后，工作还没结束。回顾同时承担三件事：降低错误概率、压缩理解、把一次解法变成未来可调用的知识。

## Frameworks Introduced

- **结果检查**
  - 代回原条件；
  - 检查特殊、极端、退化情形；
  - 检查符号、数量级、单调性；
  - 对几何/物理公式做量纲检查；
  - 检查自然对称是否保留。
- **论证检查**
  - 改变检查顺序或分组，避免沿原错误轨迹重读；
  - 找论证最脆弱、最依赖隐含假设的步骤；
  - 检查是否用到了应当起作用的条件。
- **替代推导**
  - 第二条独立路线可以提高置信度，并可能揭示更简单的直接解释。
- **利用结果**
  - 一般化、特殊化、类比、交换已知与未知、改变参数、生成新问题。

## Key Concepts

- **量纲检验**: 同一公式两边及可相加项的量纲必须一致。
- **极端情形**: 最容易暴露普遍陈述漏洞的特殊情形。
- **对称检查**: 可互换数据若在答案中被无理由区别对待，应审查。
- **独立检查**: 使用不同表示或不同推理路径。

## Mental Models

- **Attack your own result**: 主动寻找失败条件。
- **Two anchors**: 重要结果尽量有两种不同确认。
- **A solved problem is new prior knowledge**: 把决定性想法存成可复用模式。

## Anti-patterns

- **只把原推导从头读一遍**: 同一盲点往往继续存在。
- **把量纲正确当充分证明**: 它只能排除某些错误。
- **只检验友好数值**: 优先测试边界、极端和容易出错的情形。
- **成功后过度一般化**: 新范围仍需单独证明。

## Worked Example

若得到一个棱台侧面积公式，可先检查：上、下底半径交换后结果是否保持；两半径相等时是否退化为圆柱侧面积；一个半径趋近 0 时是否符合圆锥情形；公式整体是否具有面积量纲。若这些都通过，可信度上升，但仍需保留原推导或另一条严格证明。

## Key Takeaways

1. 回顾至少做一种独立于原推导的检查。
2. 特殊/极端情形、对称、量纲是高收益检查器。
3. 替代推导既检错，也改善解释。
4. 把方法迁移到新问题，才真正完成知识组织。
