# Chapter 9: 教学、诊断与提示梯度

**Source**: 第一部分 §§1–5、15–17；第三部分“诊断”“教学的规则”“常规问题”“拘泥与熟练”“聪明的读者”。

## Core Idea

帮助学生的目标是恢复其独立思考。先诊断他卡在哪个阶段，再给最一般、最自然、恰好足以重新启动工作的提示。

## Frameworks Introduced

- **四阶段诊断**
  - 理解障碍：不能清楚复述目标/条件。
  - 计划障碍：理解题意却只等待灵感，无法连接已知与所求。
  - 执行障碍：计划已成，但步骤粗心或无法说明理由。
  - 回顾障碍：得到结果后不检查、不总结。
- **提示梯度**
  1. 一般问题：“未知量是什么？”“你见过类似问题吗？”
  2. 若无反应，逐渐具体到某个结构或子目标。
  3. 一旦学生开始推进，立刻停止加提示。
  4. 事后回到一般问题，帮助学生学会自问。
- **示范 + 模仿 + 实践**
  - 教师可把自己的自我提问过程示范出来，再让学生在非例行题上练习。
- **熟练而非拘泥**
  - 清单是方法库，不是必须按顺序问完的脚本。

## Decision Points

- 学生正在进展 → 不介入。
- 学生重复同一失败动作 → 提醒“能否换一种表述/相关问题”。
- 学生知道关键定理但没想到 → 先问同类目标；最后才具体指向定理。
- 学生不会执行 → 要他解释每步“为什么成立”。

## Anti-patterns

- **过早点名关键定理**: 把最需要学习的检索工作替学生做掉。
- **连续追问直到学生只填空**。
- **只给常规题**: 训练机械套用，几乎不给判断和发明机会。
- **清单机械化**: 不看当前困难就逐条提问。

## Worked Example

学生面对陌生几何证明，能复述题意，却乱试定理。教师先问“结论是什么？你知道哪些结论相同或相似的熟悉定理？”若学生仍无思路，再问“这些熟悉定理通常需要什么图形结构？”只有再失败时，才提示是否需要一条辅助线。学生一旦提出可行构造，就停下提示，让他执行并检查。若证明结束，再问“哪一步是决定性的？还可怎样证明？”

## Key Takeaways

1. 先诊断阶段，后给提示。
2. 提示应从一般到具体，并尽早停止。
3. 学生应承担合理份额的发现工作。
4. 非例行题、回顾和方法比较是培养独立解题能力的关键。
5. 教师必须自己理解方法的适用边界，才能教会判断。
