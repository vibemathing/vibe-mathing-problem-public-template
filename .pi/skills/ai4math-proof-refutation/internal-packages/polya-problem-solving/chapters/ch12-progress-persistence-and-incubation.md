# Chapter 12: 进展、坚持、暂停与熟练判断

**Source**: 第三部分“进展与成就”“进展的征兆”“决心、希望、成功”“潜意识工作”“拘泥与熟练”“聪明的解题者”“未来的数学家”。

## Core Idea

解题需要坚持，也需要判断何时继续、换路或暂停。经验的价值很大一部分体现在识别“接近解答的迹象”和“当前路线正在枯竭的迹象”。

## Frameworks Introduced

- **进展四视角**
  - 调动：召回更多相关知识。
  - 组织：把知识连接到当前问题。
  - 变换：问题表征变得更适合。
  - 预见：开始看见最终论证可能包含什么。
- **路线管理**
  - 有越来越多进展信号 → 加大投入。
  - 长时间无信号且有可行替代路线 → 换路。
  - 有一个局部好想法但主线未通 → 保存它，尝试改造而非丢弃。
- **生产性暂停**
  1. 先经过真实、高度集中的努力。
  2. 停下前至少记录一个小成果、清晰疑问或失败位置。
  3. 暂停。
  4. 回来后重新审视问题表示，不只继续原动作。
- **熟练**
  - 准备好多种规则，却依据当前情境选择；不让规则文字遮蔽目的。

## Key Concepts

- **灵感**: 问题构想的突然重组。
- **进展信号**: 路线价值的启发式证据。
- **潜意识工作**: 暂停后问题有时以更澄清的形式回来。
- **拘泥**: 无视适用条件机械套规则。
- **熟练**: 有判断地使用规则。

## Anti-patterns

- **坚持 = 重复同一动作**。
- **一遇困难就暂停**: 没有充分投入，暂停很少产生收益。
- **进展信号当证明**。
- **清单依赖**: 不先看问题本身就调用技巧。

## Worked Example

证明卡住时，你已经确定主定理可能需要一个平面几何的类似结果，但尚未找到恰当引理。此时继续随机展开计算未必有价值。记录“缺的是把三维关系压成某个平面类比”的状态，暂停后再回来。若一个具体类似定理浮现，先把它当进展信号，验证它是否真的能填补缺口，再决定是否投入执行。

## Key Takeaways

1. 进展是知识调动、组织、表征和预见的共同变化。
2. 坚持应伴随问题变换。
3. 暂停应建立在真实努力和清晰停点上。
4. 规则库越大，越需要情境判断。
5. 每次解题后复盘“困难在哪里、决定性想法是什么”，会改善未来检索。
