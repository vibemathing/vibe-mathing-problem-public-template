# Chapter 10: 实际问题、模型与近似

**Source**: 第三部分“实际问题”；与“条件”“量纲检验”相关。

## Core Idea

实际问题与纯数学题共享寻找目标—手段联系的核心过程，但数据、条件、概念与目标往往更模糊。必须主动决定“哪些因素值得进入模型”，并把忽略与近似写明。

## Frameworks Introduced

- **实际问题建模**
  1. 列出真正的决策目标和多个未知量。
  2. 区分硬约束、重要偏好、次要影响。
  3. 盘点已有信息并识别缺口。
  4. 收集会显著改变答案的数据；到边际价值降低时停止。
  5. 选择可处理的数学模型并声明近似。
  6. 求解模型。
  7. 回到现实语境，检查敏感性与遗漏风险。
- **显著性筛选**
  - 数学题通常要求用上全部给定条件；实际题常必须忽略一部分低影响因素。
- **近似换简明**
  - 若小幅精度损失能显著简化模型，可以接受，但需说明误差来源和适用范围。

## Key Concepts

- **模型**: 对现实关系的有目的简化。
- **显著因素**: 会改变决策或答案的因素。
- **近似**: 明知与现实有偏差但在目的下可接受的表示。
- **停止规则**: 数据收集不能无限继续。

## Mental Models

- **Clarify before quantify**: 模糊概念本身可能是主要困难。
- **Enough information, not all information**.
- **Model result ≠ reality**: 结果只在假设范围内有效。

## Anti-patterns

- **把现实问题伪装成完全确定的数学题**。
- **无限收集数据**: 不给决策留终点。
- **省略近似声明**: 让精确数字制造虚假精确感。
- **把次要条件与关键约束同权处理**。

## Worked Example

设计水坝时，地点、形状、材料、成本、洪水、灌溉、航运、地质等都可能相关。可行做法是先确定主要功能与安全约束，再收集对结构安全和方案选择有显著影响的数据；随后建立力学模型，明确忽略的次要因素及近似。模型计算完成后，还需检查结果对关键参数变化是否敏感。若某个缺失地质参数能改变安全结论，就不能假装“足够确定”。

## Key Takeaways

1. 实际问题先做目标与因素澄清。
2. 只追求对决策有意义的精度。
3. 近似、数据缺口和适用范围必须显式。
4. 无法可靠判断时，应返回“不足以确定”或给出范围。
