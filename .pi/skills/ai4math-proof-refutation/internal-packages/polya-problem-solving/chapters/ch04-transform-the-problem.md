# Chapter 4: 变换问题

**Source**: 第三部分“问题的变换”“分解与重组”“定义”“一般化”“特殊化”“类比”“如果你不能解决所提出的问题”“发明者悖论”“对称”。

## Core Idea

重复同一种失败尝试只消耗时间。停滞时，应有目的地改变表示、条件范围或问题层级，以创造新的联系。

## Frameworks Introduced

- **重新表述 / 回到定义**
  - 把术语转成关系；寻找等价表达。
- **分解与重组**
  - 先保留整体目标，再分离未知量、已知、条件条款；改变“固定什么、变化什么”，重新组合。
- **特殊化**
  - 取简单、对称或极端情形，降低变化量；用于找线索、反例、检验。
- **一般化**
  - 抽去偶然细节，寻找更本质的性质。更广的问题有时结构更简单，这就是“发明者悖论”的可用面。
- **类比**
  - 映射部分之间的关系，而非仅凭外观相似。
- **对称**
  - 对可互换部分优先采用相同处理；把不必要的破坏对称视为警报。
- **问题变式**
  - 改变已知、改变未知、交换已知与未知、只保留部分条件，观察结构如何变化。

## Decision Points

- 变化太多 → **特殊化**。
- 某个具体对象遮蔽本质 → **一般化**。
- 术语不产生关系 → **回到定义**。
- 条件纠缠 → **分解与重组**。
- 有结构相似的熟悉问题 → **类比**。
- 多次尝试无新信息 → 改变问题，而非继续原样重试。

## Anti-patterns

- **从一个特殊例子直接推出一般结论**。
- **一般化仅为变难**: 若没有暴露更清楚的结构，退回特殊化。
- **类比当证明**: 类比只能生成或支持猜想。
- **变换后忘记原题**: 每次变换都要记录如何返回。

## Worked Example

“两艘船各以恒速直线航行，求最近距离”变化因素很多。先特殊化：让一艘船静止，此时问题化为“点到直线的最短距离”。随后利用相对运动，把整个系统同时加上与第二艘船速度相反的速度；相对位置和距离保持不变，原问题就被化到已解决的特殊情形。成功来自“有利特殊情形 + 把一般情形移到特殊情形的补充关系”。

## Key Takeaways

1. 变换问题的目标是制造新接触点，唤起可用知识。
2. 一般化、特殊化、类比各自解决不同的搜索困难。
3. 失败尝试也可保留有用结构，再经修改成为成功尝试。
4. 任何变换都要追踪逻辑方向与返回路径。
