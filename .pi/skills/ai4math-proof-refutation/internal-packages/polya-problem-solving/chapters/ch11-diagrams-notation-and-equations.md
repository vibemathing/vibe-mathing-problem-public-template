# Chapter 11: 图形、记号与列方程

**Source**: 第三部分“图形”“记号”“列方程”“分开条件的各个部分”。

## Core Idea

好的表示能降低记忆负担、暴露关系并唤起熟悉方法。表示本身也是解题步骤，需要按任务目的设计。

## Frameworks Introduced

- **画图**
  - 几何题：把未知、已知和条件放在同一图中。
  - 非几何题：若关系能被空间化，用图表或状态图表示。
  - 避免图形无意暗示题目没有的等长、垂直或对称。
- **记号设计**
  - 无歧义；
  - 易记；
  - 顺序与对象关系一致；
  - 利用传统含义，但避免冲突；
  - 同类对象使用有结构的符号族。
- **列方程 = 翻译**
  1. 先理解条件整体。
  2. 把条件拆成可表达的条款。
  3. 选择能反映关系的变量。
  4. 必要时先重排语义，再翻成公式。
  5. 每个方程都应能指回一个条件条款。

## Key Concepts

- **含蓄力**: 记号本身能保存并提示结构。
- **几何表示**: 把抽象关系转成可同时观察的结构。
- **语义重排**: 翻译前先按数学关系重新组织文字。
- **条件条款**: 方程来源的最小关系单元。

## Mental Models

- **External memory**: 图和符号把许多关系留在纸面上。
- **Notation should compute meaning**: 好记号让后续式子自然反映对象关系。
- **Translate meaning, not words**.

## Anti-patterns

- **逐词翻成方程**: 忽略整体意义。
- **同一符号表示两个对象**。
- **复杂记号没有收益**。
- **依赖看起来“很准”的图形作证明**: 图只辅助，逻辑关系才是依据。

## Worked Example

“求两个量，使其和为某数、积为某数”容易直接翻译。更难的情形是一个几何对称条件：先回到“关于直线对称”的定义，把它拆成可由解析几何表达的关系，再选坐标和变量。关键工作往往发生在方程出现之前：找到合适的条件分解方式。

## Key Takeaways

1. 表示选择会改变问题的可解性。
2. 图形要通用，记号要有结构。
3. 列方程前先拆条件、重排语义。
4. 每个表示都应服务于某个关系或方法，不要为形式而形式。
