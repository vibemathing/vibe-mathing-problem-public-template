# Chapter 3: 相关问题与辅助结构

**Source**: 第三部分“你以前见过它吗？”“你知道一个相关的问题吗？”“这里有一个与你的问题相关且以前已经解过的问题”“辅助元素”“辅助问题”“注视未知量”“引理”。

## Core Idea

计划阶段最有效的检索方式，是从**未知量或结论**反向约束记忆：先找“同类目标”的熟悉问题，再决定能否移用它的结果、方法或结构。

## Frameworks Introduced

- **同目标检索**
  - 求解题：找具有相同或相似未知量的熟悉问题。
  - 证明题：找具有相同或相似结论的熟悉定理。
- **相关已解题复用**
  1. 比较新旧问题的对应元素。
  2. 尝试复用结果。
  3. 尝试复用方法。
  4. 若方法几乎可用，问是否缺一个辅助元素。
- **辅助元素**
  - 引入辅助线、变量、构造或定理时，必须说清它将启用哪个已知方法。
- **辅助问题**
  - 原题难时发明更容易、特殊、类似或更一般的问题。
  - 明确辅助问题与原题的关系：等价、较弱、较强。
- **引理**
  - 当一个中间命题能解锁主证明，可先把它作为辅助定理，再补证明。

## Key Concepts

- **调动**: 从已有知识中召回相关材料。
- **组织**: 把召回材料组合成适合当前题的整体。
- **同一未知量**: 比“任意相关”更窄、更高效的检索键。
- **辅助问题**: 为原题服务的临时目标。
- **可逆归约**: 允许从辅助解安全返回原题。

## Mental Models

- **Reuse before inventing**: 先问“这种目标我以前怎样得到过？”
- **Auxiliary structure has a job**: 任何新增对象都应承担明确连接任务。
- **Relation strength matters**: 弱化问题能给线索，却未必足以解决原题；强化问题可能更难，却有时更整洁。

## Anti-patterns

- **随机加辅助线**: 没有要启用的方法，只增加搜索空间。
- **只看表面相似**: 需要映射关系结构。
- **忘记归约方向**: 由辅助问题解回原题时产生伪解或漏解。

## Worked Example

要找四面体的外接球，可以先回忆平面中“给定三角形作外接圆”。旧问题用边的垂直平分线定位圆心。把对应关系提升到三维，可尝试引入棱的垂直平分平面。这个辅助结构并非装饰；它把“到两个端点等距”的旧方法移植到三维，并把球心变成若干平面的交点。

## Key Takeaways

1. 看未知量或结论，能显著缩小记忆检索范围。
2. 旧问题可复用结果、方法，或两者。
3. 辅助元素必须有目的。
4. 辅助问题要标注与原题的逻辑关系。
5. 当某个中间命题成为桥梁时，把它显式化为引理。
