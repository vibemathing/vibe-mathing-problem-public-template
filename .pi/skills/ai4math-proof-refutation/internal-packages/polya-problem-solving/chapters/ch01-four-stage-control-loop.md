# Chapter 1: 四阶段控制循环

**Source**: “怎样解题”总表；第一部分 §§6–17；第二部分。

## Core Idea

把解题视为四个可回退的阶段：**理解问题 → 拟订计划 → 执行计划 → 回顾**。阶段不是固定仪式；当后续失败暴露前置缺口时，回到最早未解决的阶段。

## Frameworks Introduced

- **四阶段法**
  - **When to use**: 陌生题、证明设计、建模、辅导、解答审查。
  - **How**:
    1. 理解：明确目标、已知、约束与问题类型。
    2. 计划：寻找已知与目标的联系，允许暂时的猜想与辅助问题。
    3. 执行：把计划转成逐步可辩护的推导或构造。
    4. 回顾：独立检验、寻找更短路线、提炼可迁移方法。
- **阶段门控**
  - 计划阶段允许“看起来可行”的理由。
  - 执行阶段要求把关键推断转成证明、计算或可验证操作。
  - 回顾阶段要求改变检查视角，避免只重读同一条推导。

## Key Concepts

- **理解**: 能用自己的话说清目标和条件。
- **计划**: 一个把已知和所求连接起来的主要想法。
- **执行**: 检查每个决定性步骤。
- **回顾**: 验结果、验论证、找替代、找迁移。
- **内心对话**: 用一般问题唤起合适的心理操作。

## Mental Models

- **Use the earliest broken stage**: 算到一半反复出错，先查计划与理解；卡住不等于“计算能力不足”。
- **Search then certify**: 发现阶段追求有希望的联系，完成阶段追求确定性。
- **Whole before parts**: 先把题作为整体看懂，再拆条件。

## Anti-patterns

- **跳过理解直接算**: 容易解决了另一个问题。
- **把计划当证明**: “应该能用某定理”仍缺少适用条件与推导。
- **做完即停**: 丢掉检错、简化与迁移机会。
- **机械逐问清单**: 已经顺利推进时继续打断，会破坏自然思路。

## Worked Example

求长方体空间对角线时，先明确三条棱长是已知，空间对角线是未知。计划阶段先在一个面上得到面对角线，再把面对角线与第三条棱组成直角三角形。执行时两次应用勾股关系并检查每步。回顾时验证公式对三条棱对称；若第三条棱趋近 0，结果退化为矩形对角线。这一回顾同时检验结构与极端情形。

## Key Takeaways

1. 四阶段法提供控制流，具体启发法主要在“拟订计划”和“回顾”中调用。
2. 卡住时先诊断阶段，再选方法。
3. 启发式搜索与严格执行要分开管理。
4. 解后回顾把一次成功变成可复用能力。
