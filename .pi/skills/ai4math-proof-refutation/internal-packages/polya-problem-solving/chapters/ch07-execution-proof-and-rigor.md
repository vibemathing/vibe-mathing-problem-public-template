# Chapter 7: 执行、证明与严格性

**Source**: 第一部分“执行计划”；第三部分“执行”“求解题，证明题”“归谬法和间接证明”“归纳与数学归纳法”“为什么要证明？”“引理”。

## Core Idea

计划阶段可以靠合情理由前进，执行阶段必须切换到可检查的论证。发现顺序、检查顺序、最终呈现顺序可以不同。

## Frameworks Introduced

- **严格执行**
  1. 先确认论证主干：若主连接错误，细节无意义。
  2. 再验证每个步骤的条件与方向。
  3. 将“我觉得可行”替换为定理、定义、计算或构造。
- **证明题路由**
  - 明确假设与结论。
  - 从结论检索相同/类似结论的定理。
  - 需要时引入引理或辅助结构。
- **归谬 / 间接证明**
  - 假设不可能情形或结论的反面，推出明确矛盾。
  - 成功后回顾：能否抽出正面的直接论证？
- **数学归纳法**
  - 只在断言精确地依赖整数参数时使用：基例 + `n→n+1`。
- **不完整证明的边界**
  - 教学中可以展示证明胚芽，但必须标明未完成；讲授者自己应清楚完整证明。

## Key Concepts

- **证明题**: 要确立或否定清晰断言。
- **引理**: 为主定理服务的辅助定理。
- **论证主干**: 使结论成立的决定性连接。
- **完整证明**: 没有逻辑缺口。
- **不完整证明**: 只展示主要思想，不能冒充完整证明。

## Mental Models

- **Scaffold vs building**: 启发式理由像脚手架；完成后要由正式结构承重。
- **Prove the bridge**: 最值得检查的是把已知跨到目标的那一步。
- **Discovery can be messy; presentation can be clean**.

## Anti-patterns

- **用多个数值例子代替证明**。
- **在归谬法中忘记矛盾来自哪条假设**。
- **数学归纳只验了几个值**。
- **把不完整证明写成“显然”**。

## Worked Example

证明素数无穷时，可先假设存在“最后一个素数”，构造由所有已知素数乘积再加 1 得到的数，从而产生无法由“全部素数”整除的矛盾。回顾后还能把发现过程改写得更直接：给定任意有限个素数，取其乘积加 1，再取该数的一个素因子，就得到一个不在原列表中的新素数。回顾把间接发现转成了正面的构造过程。

## Key Takeaways

1. 执行阶段要求每个关键步骤可证明。
2. 证明策略可以从结论反向检索。
3. 归谬法适合发现，也应在回顾中考虑更直接表达。
4. 不完整证明必须明确标注其不完整性。
5. 最终呈现优先体现目的与逻辑，而非机械复述发现顺序。
