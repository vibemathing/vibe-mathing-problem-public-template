# Chapter 13: 问题工作坊

**Source**: 第四部分“问题、提示、解答”20 题。

## Core Idea

练习部分把启发法作为“选择方法”的训练，而非题型配方。每道题的提示都尽量只补一个关键思想；完整解答则展示关键思想怎样落到可验证步骤。

## Method Selection Map

| Problem family | First useful move | Why |
|---|---|---|
| 地球/球面路径 | 澄清几何模型；找相关问题 | 日常直觉在球面上会失效 |
| 分配/计数下界 | 重新表述成最小需求 | 直接构造困难时先求必要下界 |
| 页码/数位 | 拆范围 | 不同位数区间成本不同 |
| 缺失数字/整除 | 重述为整除条件 | 把叙述题转成数论约束 |
| 对称图形平分 | 一般化到“有对称中心的图形” | 更一般问题反而更直接 |
| 轨迹 | 召回已解轨迹问题 | 用类似结构重建新轨迹 |
| 立方体旋转轴 | 分类 + 穷尽性证明 | 找到例子还不等于列全 |
| 四面体体积 | 看未知量，找更易子体 | 体积提示底×高与分割 |
| 棱锥性质 | 类比平面等腰三角形 | 旧证明方法提供辅助直角三角形 |
| 线性方程组 | 观察对称系数 | 组合方程可降维 |
| 分段运动 | 分开条件并设各阶段时间 | 先结构化再列方程 |
| 等差/等比混合 | 参数化两个数列 | 记号直接编码结构 |
| 对称多项式根 | 利用偶次幂对称 | 根成 ± 对，减少自由度 |
| 几何量关系 | 分开条件 | 周长、直角、高分别成方程 |
| 观察数列 | 归纳猜想 → 证明 | 先发现规律，再严格建立 |
| 三角网格计数 | 画图、递推、交叉核对 | 图形提供规律，恒等式提供检查 |
| 换零钱 | 先一般化并构造递归 | 一般函数族让递推关系显现 |

## Frameworks Introduced

- **最小提示原则**: 只补“缺失的思想”，不要替代后续推理。
- **先认真尝试再读提示**: 提示只有与已有失败经验接触时才有学习价值。
- **比较解法**: 自己解出后，对照另一方法，找更短、更一般或更可迁移的结构。
- **解答后二次任务**: 证明穷尽性、检查极端情形、构造递推、寻找一般化。

## Anti-patterns

- **把 20 题记成 20 个模板**。
- **看到提示立刻照抄**: 失去方法选择训练。
- **找到若干候选就以为列全**: 对分类问题必须证明穷尽。
- **猜出规律不证明**。

## Worked Example

换零钱问题若只问“一美元有多少种”，直接枚举很快失控。把它一般化为“支付 `n` 分的方法数”，并进一步按允许使用的硬币种类建立一组相关函数，就能得到“使用最大面额 / 不使用最大面额”的递推分解。这里一般化创造了一个可递归计算的理论框架，随后原问题只是 `n=100` 的特例。

## Key Takeaways

1. 练习的重点是识别哪种启发法适合当前障碍。
2. 提示应补关键连接，执行仍由解题者完成。
3. 结果之后继续问：是否列全、是否可验证、是否可一般化。
4. 同一方法可以跨几何、代数、数论、组合与实际情境迁移。
