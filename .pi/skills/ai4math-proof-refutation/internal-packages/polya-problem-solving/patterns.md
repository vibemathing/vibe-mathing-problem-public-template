# Patterns

## 四阶段循环
**When to use**: 新问题或当前思路失控时。  
**How**: 理解目标与条件 → 找连接形成计划 → 严格执行 → 独立回顾。失败时回到最早有缺口的阶段。  
**Trade-offs**: 作为控制流；不要机械逐条提问。

## 同目标检索
**When to use**: 不知道用什么定理/方法。  
**How**: 看未知量或结论 → 想同类目标的熟悉问题/定理 → 比较结果与方法 → 映射到当前题。  
**Trade-offs**: 检索范围小而高效；可能漏掉远距离但有用的联系。

## 相关已解题复用
**When to use**: 已想起相近问题。  
**How**: 试结果 → 试方法 → 若结构缺一块，引入有明确作用的辅助元素。  
**Trade-offs**: 必须验证对应关系。

## 辅助问题
**When to use**: 原题直接攻击失败。  
**How**: 发明更容易/特殊/类似/更一般的问题 → 解决 → 把结果或方法迁回原题 → 标注等价、较弱或较强。  
**Trade-offs**: 太远的辅助题会消耗时间。

## 分解与重组
**When to use**: 条件纠缠。  
**How**: 保留整体目标 → 拆未知、数据、条件条款 → 改变固定与变化部分 → 围绕有用关系重组。  
**Trade-offs**: 拆得太碎会失去目标感。

## 回到定义
**When to use**: 技术词熟悉却不产生可用关系。  
**How**: 展开定义 → 引入定义要求的元素/关系 → 重新表述 → 选最有用的等价定义。  
**Trade-offs**: 可能增加细节，应以能解锁方法为准。

## 特殊化
**When to use**: 变化太多、要找反例、要预判公式。  
**How**: 取简单/对称/极端情形 → 求解或检验 → 提取线索 → 再回一般情形。  
**Trade-offs**: 一个成功特例不能证明一般命题。

## 一般化
**When to use**: 特殊细节遮蔽本质。  
**How**: 抽象出真正起作用的性质 → 解决更广但更整洁的问题 → 专门化回原题。  
**Trade-offs**: 若结构更糟，立即退回。

## 类比
**When to use**: 有结构相似的已解问题。  
**How**: 映射对应部分与关系 → 暂时迁移结果/方法 → 用原题条件检验。  
**Trade-offs**: 类比提供可信度，不提供证明。

## 逆向工作
**When to use**: 终点清楚、正向路不清楚。  
**How**: 假定目标已得 → 找直接前置条件 → 重复至已知 → 反转链条正向执行 → 检查可逆性。  
**Trade-offs**: 单向蕴含会破坏回程。

## 猜想—压力测试
**When to use**: 出现模式或直觉。  
**How**: 精确陈述 → 找支持例与反例 → 测极端/边界 → 修正或进入证明。  
**Trade-offs**: 防止确认偏误。

## 进展信号管理
**When to use**: 不确定当前路线是否值得继续。  
**How**: 观察未用条件是否被连接、结构是否更协调、相关问题是否浮现；信号累积则继续，长期消失则换路。  
**Trade-offs**: 信号可能误导，只决定投入，不决定真伪。

## 列方程
**When to use**: 文字条件可量化。  
**How**: 理解整体 → 拆条款 → 选记号 → 按意义而非字面翻译 → 求解 → 回代解释。  
**Trade-offs**: 表示选择常决定难度。

## 严格执行
**When to use**: 已有计划。  
**How**: 先核论证主干 → 再逐步证明/计算 → 标出所有依赖条件。  
**Trade-offs**: 发现过程可凌乱，最终推导应清晰。

## 结果验证
**When to use**: 已得到结果。  
**How**: 回代/逻辑复核 → 特殊和极端情形 → 对称/量纲/单调性 → 可能时独立推导。  
**Trade-offs**: 单项检查只能排除部分错误。

## 教学提示梯度
**When to use**: 学生卡住。  
**How**: 诊断阶段 → 一般问题 → 必要时逐级具体 → 一旦恢复进展就停止 → 解后复盘决定性想法。  
**Trade-offs**: 过具体会替学生完成检索。

## 生产性暂停
**When to use**: 长时间高投入却循环。  
**How**: 先记录小进展/清晰缺口 → 暂停 → 返回后重新表征问题。  
**Trade-offs**: 没有前期努力的暂停通常只是拖延。
