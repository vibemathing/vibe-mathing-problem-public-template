# Cheatsheet

## Route by situation

| Signal | Next move | Load |
|---|---|---|
| 说不清目标/条件 | 写未知量-已知-条件，或假设-结论 | ch02 |
| 条件可能无解/多解 | 查可能性、充分性、冗余、矛盾 | ch02 |
| 不知道用什么 | 看未知量/结论，检索同类目标 | ch03 |
| 已有近似旧题 | 试结果、方法、辅助元素 | ch03 |
| 同一尝试反复失败 | 重新表述/定义/分解/特殊化/一般化/类比 | ch04 |
| 目标清楚但正向卡住 | 假定目标已达，逐层找前置条件 | ch05 |
| 有模式或“感觉对” | 精确成猜想，主动找反例 | ch06 |
| 计划有了但论证松 | 切换到严格执行，先验主干 | ch07 |
| 已有答案 | 独立检验 + 替代推导 + 迁移 | ch08 |
| 学生卡住 | 诊断阶段，用提示梯度 | ch09 |
| 现实数据很乱 | 筛显著因素，写模型与近似 | ch10 |
| 条件难以同时把握 | 图形/记号/方程翻译 | ch11 |
| 高投入却循环 | 记录缺口后暂停，再回来重构 | ch12 |

## Recovery ladder

1. **重述**：我要什么？手上有什么？什么限制答案？
2. **定义**：哪个术语一展开就会产生关系？
3. **检索**：同类未知量/结论以前怎样得到？
4. **变换**：更简单？更特殊？更一般？类比？只保留部分条件？
5. **辅助**：缺哪个元素/子问题才能让旧方法适用？
6. **逆向**：目标的直接前置条件是什么？
7. **换路/暂停**：进展信号长期消失时停止重复。

## Fast validation

| Check | Use when | Failure smell |
|---|---|---|
| 回代原条件 | 任何求解题 | 候选只满足部分条件 |
| 用尽关键条件 | 表述完善的数学题 | 某假设从未出现 |
| 极端/退化情形 | 一般公式/定理 | 边界立即反例 |
| 对称 | 输入角色可互换 | 输出无理由偏向某一项 |
| 量纲 | 几何/物理公式 | 面积与长度等量纲冲突 |
| 替代推导 | 高价值结果 | 两路给出不同结构 |
| 反例搜索 | 猜想 | 只做支持性测试 |

## Tutoring defaults

- 学生在前进 → **不提示**。
- 第一次提示 → 用一般问题。
- 第二次 → 指向问题结构。
- 最后才 → 指向具体定理/构造。
- 学生一恢复推进 → **停止提示**。
- 解完 → 问“决定性想法是什么？还能怎样做？能迁移到哪里？”

## Hard boundaries

- 启发式理由 ≠ 证明。
- 特例支持 ≠ 一般证明。
- 图形看起来正确 ≠ 逻辑正确。
- 变换后的问题 ≠ 原题，除非返回关系已说明。
- 实际问题中的精确数字 ≠ 精确现实；写出模型和近似。
- 规则服务于目标；情境不适用时停用规则。
