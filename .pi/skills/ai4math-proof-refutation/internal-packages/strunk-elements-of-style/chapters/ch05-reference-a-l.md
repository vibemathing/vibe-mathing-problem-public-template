# Chapter 5 Reference A–L

Use this file only when the queried expression falls in A–L. The “modern route” column is an implementation aid; it does not claim Strunk made a modern-usage judgment.

| Entry | Source diagnostic | Modern route |
|---|---|---|
| **All right** | two-word form; source restricts some uses | historical/style gate |
| **As good or better than** | rearrange so each comparison has complete syntax | durable clarity principle |
| **As to whether** | `whether` is usually sufficient | durable concision preference |
| **Bid** | infinitive without `to`; historical past-tense note | historical gate |
| **But** | remove needless `but`; avoid contrast-on-contrast | durable when redundant |
| **Can / may** | distinguishes ability from permission | context + modern usage gate |
| **Case** | often empty in “in many cases” / “it is the case that” | durable concision diagnostic |
| **Certainly** | habitual intensifier becomes a mannerism | durable style diagnostic |
| **Character** | often redundant in phrases such as “of a hostile character” | durable concision diagnostic |
| **Claim** | source restricts senses and dislikes generic `say` use | historical/semantic gate |
| **Clever** | warns against vague overuse | context-sensitive style |
| **Compare to / compare with** | assigns resemblance vs. difference functions | historical/modern usage gate |
| **Consider** | omits `as` when meaning “believe to be” | durable in many contexts |
| **Data** | treats `data` as strictly plural | historical gate |
| **Dependable** | source prefers `reliable` / `trustworthy` | historical lexical preference |
| **Different than** | source rejects it | historical/variety gate |
| **Divided into / composed of** | preserve distinction between partition and composition | durable when distinction matters |
| **Don't / doesn't** | distinguishes contractions by subject | durable grammar |
| **Due to** | source rejects adverbial use and restricts it to relation with a noun | historical gate |
| **Folk** | source treats as a collective singular form | historical/variety gate |
| **Effect / affect** | `effect` noun=result, verb=bring about; `affect`=influence | durable semantic core; broader modern senses exist |
| **Etc.** | use only when omitted continuation is predictable; avoid after `such as`/`for example` | durable precision diagnostic |
| **Fact** | reserve for verifiable matters; avoid padded `the fact that` | durable epistemic + concision principle |
| **Factor** | often hackneyed; name the actual causal role | durable recast diagnostic |
| **Feature** | often empty; say what the feature is or does | durable recast diagnostic |
| **Fix** | source restricts colloquial American senses | historical gate |
| **Get / have got** | source dislikes colloquial `have got` in writing | register/style gate |
| **He is a man who** | redundant frame; state the predicate directly | durable concision principle |
| **Help** | cross-reference to needless `but` construction | durable where redundant |
| **However** | source places conjunctive `however` away from clause-initial position | historical/style gate |
| **Interesting** | do not announce interest; make the material earn it | durable rhetoric principle |
| **Kind of / sort of** | reserve literal classification; source rejects vague intensifier uses in formal prose | register/style gate |
| **Less / fewer** | quantity vs. count distinction with a source-noted round-number nuance | style/usage gate; often useful |
| **Like / as** | source restricts `like` before clauses | historical/variety gate |
| **Line / along these lines** | warns against overworked formula | durable cliché diagnostic |
| **Literal / literally** | do not use literalness terminology to support a nonliteral claim | semantic diagnostic; hyperbole can be intentional |

## Quick decision rule

If the entry protects a concrete semantic distinction, check the sentence's meaning. If it attacks vagueness or wordiness, recast the thought. If it rests on a period-specific acceptability judgment, consult Appendix A before editing modern prose.
