# Glossary

**反例** — 满足某个全称命题的假设却违反其结论的例子；一个合法反例足以推翻全称命题（Ch12）。

**反证法** — 假设目标的否定（证明蕴含时通常同时保留原假设），推出明确矛盾（Ch23）。

**泛化** — 通过弱化假设、扩大对象范围，必要时调整结论，获得更一般命题（Ch33）。

**归纳假设** — 数学归纳步骤中，对任意固定 k 暂时假设 A(k) 成立，以证明 A(k+1)（Ch24）。

**定义** — 规定术语/对象满足什么条件；使用时可展开条件并识别满足条件的对象（Ch14–15）。

**定义域 / 陪域** — 函数允许输入的集合 / 声明输出所在的集合；它们是函数身份的一部分（Ch1, Ch30）。

**等价关系** — 同一集合上的自反、对称、传递关系（Ch31）。

**等价类** — 与给定元素等价的全部元素构成的集合；等价类形成分割（Ch31）。

**当且仅当（iff）** — A⇔B，要求 A⇒B 与 B⇒A 都成立（Ch9, Ch20）。

**充分条件** — “A 对 B 充分”表示 A⇒B（Ch8）。

**必要条件** — “A 对 B 必要”表示 B⇒A（Ch8）。

**逆命题（converse）** — A⇒B 的逆命题是 B⇒A；与原命题真值没有自动绑定（Ch9）。

**逆否命题 / 逆否法** — A⇒B 的等价形式 ¬B⇒¬A；可作为证明路线（Ch8, Ch26）。

**蕴含** — A⇒B；唯一失败情形是 A 真且 B 假（Ch7）。

**全称量词** — ∀；证明时需处理任意符合范围的对象（Ch10）。

**存在量词** — ∃；证明时需给出或保证至少一个对象（Ch10）。

**量词否定** — 否定量化命题时交换 ∀/∃ 并否定最终谓词（Ch11）。

**反射/对称/传递** — 等价关系的三个独立条件（Ch31）。

**良定义（well-defined）** — 用代表元定义函数或运算时，结果不依赖代表元选择（Ch31）。

**注入** — 不同输入不碰撞；常用等价证明形态 f(x₁)=f(x₂)⇒x₁=x₂（Ch30）。

**满射** — 陪域每个 y 都有定义域中的原像 x（Ch30）。

**双射** — 同时注入和满射；是可逆与集合等势的核心工具（Ch30）。

**可数无限** — 与自然数集合存在双射的无限集合（Ch30）。

**整除** — a|b 表示存在整数 k 使 b=ka（Ch27）。

**最大公因数（gcd）** — 两数共同正因子中的最大者；Euclidean algorithm 可高效计算（Ch27–28）。

**Bézout 恒等式** — gcd(a,b) 可写成 a,b 的整数线性组合（Ch28）。

**同余** — x≡y (mod n) 等价于 n|(x−y)（Ch29）。

**数学归纳法** — 基例 + A(k)⇒A(k+1) 的步骤证明自然数索引命题族（Ch24）。

**强归纳** — 证明 k+1 时允许假设此前一整段命题都成立（Ch25）。

**不失一般性（WLOG）** — 通过对称或重标记作表面特殊化，但不减少需覆盖的一般情形（Ch22, Ch33）。

**证明骨架** — 去掉细节后仍保留的核心依赖、方法与中间桥梁（Ch18）。

**特殊化** — 加强假设/缩小对象范围以获得更易处理的问题或实例（Ch33）。
