# 第5章：如何解决问题

## Core Idea
采用 Polya 四阶段循环：理解问题、制定计划、执行计划、回顾。卡住时生成信息，别等待一个“一步到位”的定理。

## Frameworks Introduced
- **Polya 四步**：1) 理解目标与数据；2) 制定候选计划；3) 小步执行并验证；4) 回看、检验、寻找更好解释。
- **双向搜索**：从假设向前推出后果，同时从结论向后问“什么足以推出它”；探索可双向，但最终证明必须正向。
- **例子探针**：先做初始、特殊、具体、极端案例，寻找模式和障碍。
- **表示切换**：文字↔符号、画图、命名对象、分解子问题、寻找等价问题。
- **系统换法**：当前路线无进展时，依次试定义、例子、图、反例、分情况、简化问题、相似问题或另一证明法。

## Procedure
1. 把题目重写成“已知什么/要得到什么”。
2. 从例子、特殊情形、图或等价表述中收集线索。
3. 列两到三条候选路线，选前提最匹配的一条执行。
4. 执行失败就回计划层换法；成功后回代、找反例或用另一视角检查。

## Key Concepts
- **理解问题**：明确所有术语、给定信息、限制条件与最终目标。
- **假设**：证明中可以作为已知使用的前置条件。
- **结论**：需要从假设与已知结果推出的目标陈述。
- **猜想**：有证据支持但尚未证明的数学陈述。
- **子问题**：把原问题拆成的更小、可独立推进的目标。
- **特殊情况**：对一般问题增加条件得到的更窄情形。
- **回顾**：解完后检验答案、寻找替代路线并反思可推广之处。

## Mental Models
- 卡住意味着需要制造新信息。
- 探索时可倒推；交付时重写为不循环的正向论证。

## Anti-patterns
- 只搜“长得像答案”的现成公式。
- 没有验证就把直觉当证明。
- 得到答案后立即停止，不做回看。

## Worked Example (reconstructed)
目标：证明两个集合相等。理解阶段把目标拆成 $A\subseteq B$ 与 $B\subseteq A$；计划阶段决定元素法；执行时分别任取元素证明包含；回顾时检查两个方向都覆盖且没有使用结论本身。

## Key Takeaways
1. 先精确写出假设和目标。
2. 从例子、特殊情形和定义中制造线索。
3. 执行每一步要有依据。
4. 回顾时主动尝试推翻答案。
