# 第33章：泛化与特殊化

## Core Idea
泛化通常通过弱化假设（必要时调整结论）扩大适用范围；特殊化通过加强假设缩小问题，让结构更容易看见。两者可组成“先特例求洞见，再返回一般”的循环。

## Frameworks Introduced
- **弱化假设**：逐项删除或放宽条件，测试原结论是否仍成立。成功即得到更一般结果；失败时反例说明边界。
- **调整结论**：若弱化条件后原结论失效，寻找一个较弱或修正后的结论，使新定理仍包含原结果作为特例。
- **特殊化求解**：一般问题太难时，限制到自然数、低维、对称情形、固定参数等，先学习结构。
- **WLOG**：通过对称/重标记得到看似特殊的假设，但实际不缩小一般性。

## Procedure
1. 把原定理的假设和结论分开列出。
2. 一次弱化一个假设并搜索反例；若仍真，尝试证明推广。
3. 若推广失败，考虑特殊化或调整结论。
4. 使用 WLOG 前写出对称/重标记依据，并确认没丢情形。

## Key Concepts
- **泛化**：弱化假设或扩大对象范围以获得更一般结果。
- **弱化假设**：删除或放宽一个前提条件。
- **特殊化**：加强假设或缩小对象范围，以研究更易处理的版本。
- **加强假设**：增加限制，使适用对象更少。
- **不失一般性**：有对称/重标记依据时采用代表性情况而不缩小一般范围。

## Mental Models
- 每次弱化只改一个条件，便于知道反例针对哪个假设。
- 错误的推广也有价值：它揭示真正障碍并可导向新问题。

## Anti-patterns
- 删掉假设后默认结论还真。
- 用 WLOG 掩盖未证明的对称。

## Worked Example (reconstructed)
若一个定理先在正整数 y 上证明，想推广到非零整数 y：先保留已证正数情形，再对负 y 令 $y'=-y>0$，把正数结果转回；另查零是否被原命题排除。

## Key Takeaways
1. 泛化=弱化假设/扩大对象。
2. 特殊化=加强假设/缩小对象。
3. 反例告诉你推广哪里断。
