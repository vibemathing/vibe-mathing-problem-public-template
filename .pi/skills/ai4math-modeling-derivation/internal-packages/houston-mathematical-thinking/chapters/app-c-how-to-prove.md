# 附录 C：如何证明……（证明配方）

这是主路由的快速落地版本。先识别目标形状，再调用对应配方。

| 目标形状 | 首选动作 | 常见备选 |
|---|---|---|
| $A\Rightarrow B$ | 从 A 展开定义，直接推到 B | 逆否；反证 |
| $A\Leftrightarrow B$ | 分成 A⇒B 与 B⇒A | 两方向可用不同方法 |
| $a=b$ | 化一边；证 a−b=0 | 双向不等式；共同等于 c |
| $A\subseteq B$ | 任取 x∈A，证 x∈B | 在集合描述层做等价变形 |
| $A=B$ | 证 A⊆B 与 B⊆A | 可逆的集合等式链 |
| “存在 x” | 直接构造一个 x | 反证不存在会矛盾 |
| “不存在 x” | 假设存在并反证 | 结构分类后逐类排除 |
| $\forall x\in X,P(x)$ | 任取 x∈X 后证明 P(x) | 穷尽分情况；若自然数索引则归纳 |
| “唯一” | 先证存在；再设两个候选并证相等 | 反证两个不同对象不可能 |
| 集合无限 | 与已知无限集构造双射 | 假设有限并推出矛盾 |
| 自然数索引 | 数学归纳 | 强归纳/多基例 |
| 整数索引 | 先处理非负/自然数，再处理负数 | 按正/零/负分情况 |
| f 注入 | 假设 f(x₁)=f(x₂)，证 x₁=x₂ | 证逆否形式 |
| f 满射 | 任取陪域 y，构造定义域 x 使 f(x)=y | 解方程/构造原像 |
| f 双射 | 分别证明注入与满射 | 构造反函数并核验两侧 |

## Failure Recovery
1. 写出所有定义与量词。
2. 造最小/极端例子，尝试反例。
3. 把目标分成更小子目标。
4. 若直接法无进展，比较逆否、反证、分情况、归纳哪个前提最匹配。
5. 若任一方法需要未满足的假设，停止并说明缺口。
