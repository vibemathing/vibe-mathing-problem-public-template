# 第18章：如何阅读证明

## Core Idea
阅读证明要恢复“骨架”：分段、识别方法、追踪假设、补计算、用例子和非例验证，并能在最后只保留关键步骤复述。

## Frameworks Introduced
- **骨架提取**：将证明切成逻辑块，为每块写一句功能说明。
- **假设追踪**：逐个假设标记首次/关键使用位置；若完全没用，问能否推广。
- **方法识别**：标注直接、矛盾、归纳、分情况、逆否等技术。
- **局部重演**：把每个抽象步骤套到具体例子；重算被省略的“简单计算”。
- **非例压力测试**：去掉一个假设，用非例跑证明，定位最先失败的步骤。

## Procedure
1. 把证明切成若干逻辑块，并给每块写功能标签。
2. 标出使用的证明技术和每个假设的关键使用点。
3. 重做被省略的计算，并把抽象步骤套到具体例子。
4. 删掉一个假设或换成非例，定位证明首先失效的位置。

## Key Concepts
- **证明骨架**：去掉计算细节后保留的核心逻辑块和依赖链。
- **假设使用点**：证明中某个假设第一次或关键发挥作用的位置。
- **隐藏步骤**：原文省略但必须能补出的计算或逻辑桥梁。
- **严谨度**：证明对中间步骤、前提和边界情况交代的完整程度。
- **非例**：看似接近某定义却至少违反一个必要条件的对象。

## Mental Models
- 真正理解证明意味着能解释“为什么选择这一步”。
- 总结时删细节但保留逻辑桥梁。

## Anti-patterns
- 背证明文字而不理解依赖。
- 看到图形直观就跳过一般性或退化情况。

## Worked Example (reconstructed)
审计一个“奇数乘积为奇数”的证明：先展开奇数定义，检查变量属于整数；再看是否意外使用了关于自然数的约定，尤其是 0 的归属。极端输入可暴露域定义差异。

## Key Takeaways
1. 提取结构。
2. 追踪每个假设。
3. 补空白并重算。
4. 用非例找失败点。
