# 第22章：证明技术 II：分情况

## Core Idea
当定义或结构天然分支时，把全集切成穷尽且可控的情况逐一证明；最后确认所有可能性都覆盖。

## Frameworks Introduced
- **穷尽分支**：选择覆盖所有对象的案例划分，如奇/偶、余数类、正/零/负。
- **分段定义对齐**：绝对值、max/min 等分段定义通常直接提示案例。
- **退化/极端单列**：几何共线、零值、边界参数等可能需要独立情况。
- **WLOG 规则**：只有存在明确对称/重标记论证时才可“不失一般性”省掉镜像情况。

## Procedure
1. 找出让问题规则发生变化的自然分支。
2. 证明这些分支覆盖全部对象，并单列边界/退化情形。
3. 逐个分支完成相同目标。
4. 若想用 WLOG，先写出交换/重标记为何保持问题不变。

## Key Concepts
- **分情况**：把所有可能输入划为若干类并逐类证明。
- **穷尽**：所列情况覆盖所有可能性。
- **奇偶**：整数按是否为 2 的倍数分为偶/奇两类。
- **余数类**：按模 n 的余数把整数分组。
- **不失一般性**：有对称/重标记依据时采用代表性情况而不缩小一般范围。
- **对称性**：交换或重标记对象后问题结构保持不变的性质。

## Mental Models
- 案例划分是一种信息压缩：每个分支让未知性质变成已知。
- 先检查“互斥”不如先检查“穷尽”重要；重叠案例也可用，只要全覆盖。

## Anti-patterns
- 漏掉零或边界。
- 没有证明对称性就写 WLOG。

## Worked Example (reconstructed)
要证明涉及 $|x|$ 的命题，可按 $x\ge0$ 与 $x<0$ 分两类，把 $|x|$ 分别替换为 $x$ 与 $-x$。结束时注明这两类覆盖所有实数。

## Key Takeaways
1. 案例必须覆盖全部输入。
2. 每个分支内可用不同方法。
3. WLOG 需有对称依据。
