# 第29章：模算术

## Core Idea
把 $x\equiv y\pmod n$ 读成“n 整除 x−y”。同余允许在加减乘和幂运算中持续约简，常把巨大计算变成小余数问题。

## Frameworks Introduced
- **同余定义**：$x\equiv y\pmod n \Leftrightarrow n\mid(x-y)$。
- **运算兼容**：同余可安全地用于加、减、乘，并可迭代处理幂。
- **余数分情况**：证明整数性质时，可按模 n 的所有余数类穷尽。
- **Fermat 小定理**：p 为素数时 $x^p\equiv x\pmod p$；若 p 不整除 x，则 $x^{p-1}\equiv1\pmod p$。
- **合数检测**：若某数违反 Fermat 必要条件，可判为合数；通过测试不自动证明是素数。

## Procedure
1. 把 x≡y (mod n) 翻成 n|(x−y) 以便调用整除工具。
2. 在每一步加减乘或幂运算后把数约到小余数。
3. 复杂整数性质可按全部余数类分情况。
4. 任何消去/除法操作前先检查模 n 下是否存在相应可逆条件。

## Key Concepts
- **同余**：x≡y (mod n) 表示 n|(x−y)。
- **模**：规定同余比较所使用的正整数 n。
- **余数类**：按模 n 的余数把整数分组。
- **Fermat 小定理**：p 为素数时 x^p≡x (mod p)；互素时等价得到 x^(p−1)≡1。
- **整除判别**：利用余数或同余快速判断一个整数是否被给定数整除。

## Mental Models
- 计算巨大幂先找小模下的周期。
- “约分/除法”在模算术中需要额外可逆条件，不可照搬普通代数。

## Anti-patterns
- 在同余式两边随意除以同一个数。
- 把通过 Fermat 测试当作素数证明。

## Worked Example (reconstructed)
求 $3^{100}$ 的末位：在 mod 10 下，3 的幂余数按 3,9,7,1 周期4循环；100 被4整除，所以 $3^{100}\equiv1\pmod{10}$。

## Key Takeaways
1. 同余是“差可整除”的关系。
2. 优先约简后再计算。
3. 使用除法/消去时检查可逆条件。
