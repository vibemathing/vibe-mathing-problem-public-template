# 附录 A：希腊字母快速参考

## Purpose
用于识别数学文本常见希腊字母。读到字母时先把“符号形状”和“变量含义”分开：同一希腊字母在不同课程中可代表完全不同对象。

| 名称 | 大写 | 小写 |
|---|---|---|
| Alpha | Α | α |
| Beta | Β | β |
| Gamma | Γ | γ |
| Delta | Δ | δ |
| Epsilon | Ε | ε/ϵ |
| Zeta | Ζ | ζ |
| Eta | Η | η |
| Theta | Θ | θ |
| Iota | Ι | ι |
| Kappa | Κ | κ |
| Lambda | Λ | λ |
| Mu | Μ | μ |
| Nu | Ν | ν |
| Xi | Ξ | ξ |
| Omicron | Ο | ο |
| Pi | Π | π |
| Rho | Ρ | ρ |
| Sigma | Σ | σ |
| Tau | Τ | τ |
| Upsilon | Υ | υ |
| Phi | Φ | φ/ϕ |
| Chi | Χ | χ |
| Psi | Ψ | ψ |
| Omega | Ω | ω |

## Agent Usage Notes
- 不从字母形状猜语义；先查当前定义。
- 对容易混淆的字形（ν/v、ρ/p、ο/o 等）在重写题目时显式说明。
