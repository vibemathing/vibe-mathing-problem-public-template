# 第19章：毕达哥拉斯定理案例研究

## Core Idea
用一个熟悉定理演示完整数学阅读：拆假设/结论、测强度、造例子与非例、看图但不被图骗、检查逆命题和更一般结果。

## Frameworks Introduced
- **定理全景审查**：对一个定理执行“条件→结论→例子→非例→证明→converse→推广”完整循环。
- **图形证据边界**：图能启发结构，但图示看起来成立不自动替代逻辑证明。
- **逆命题区分**：从未满足勾股等式推断“非直角”属于原定理的逆否；“满足等式则直角”是独立的 converse。
- **避免循环**：用更一般的余弦定理推导毕达哥拉斯时，要确认余弦定理的证明没有先用毕达哥拉斯。

## Procedure
1. 列出毕达哥拉斯定理的对象、直角假设与结论。
2. 用实际三角形测试公式，同时区分“图上看起来对”和证明。
3. 分别考察原命题、逆否和 converse 的任务。
4. 若调用余弦定理等更一般结果，检查依赖链是否循环。

## Key Concepts
- **毕达哥拉斯定理**：直角三角形两直角边平方和等于斜边平方的定理。
- **逆命题**：A⇒B 的 converse：B⇒A，需独立判断。
- **逆否**：从未满足勾股等式推断“非直角”属于原定理的逆否。
- **余弦定理**：把三角形三边与夹角余弦联系起来、推广毕达哥拉斯关系的定理。
- **循环依赖**：用一个直接或间接依赖待证结论的结果来证明该结论。

## Mental Models
- 熟悉的定理也值得做结构审计；熟悉感可能隐藏逻辑错误。

## Anti-patterns
- 把图像直观当证明。
- 用依赖目标定理的结果“证明”目标。

## Worked Example (reconstructed)
对三边 $a,b,c$，先确认“直角三角形”和“斜边 c”是假设的一部分，再使用 $a^2+b^2=c^2$。若算出不相等，可用逆否排除直角；若相等而要断言直角，则需要使用 converse，不能偷换。

## Key Takeaways
1. 区分定理、逆命题和逆否。
2. 检查证明依赖图。
3. 用例子与非例理解假设。
