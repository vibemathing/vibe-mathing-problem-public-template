# 附录 B：常用符号快速参考

| 符号 | 常见含义 | 使用提醒 |
|---|---|---|
| ∀ / ∃ | 对所有 / 存在 | 顺序与作用域决定逻辑强度 |
| ∅ | 空集 | 区分 ∅ 与 {∅} |
| ∈ / ∉ | 属于 / 不属于 | 左侧通常是元素 |
| ⊆ / ⊂ | 子集 / 真子集（约定可能不同） | 先确认教材约定 |
| ∪ / ∩ | 并 / 交 | 可下沉到元素条件 |
| ⇒ / ⇔ | 蕴含 / 当且仅当 | ⇒ 不作“下一步”装饰；⇔ 需双向 |
| ℕ, ℤ, ℚ, ℝ, ℂ | 常见数系 | 尤其确认 ℕ 是否含 0 |
| Σ / ∏ | 求和 / 连乘 | 核对索引范围 |
| ≡ | 常用于恒等或模同余 | 语境决定具体含义 |
| ≈ | 近似相等 | 不与精确等号混用 |
| ± | 正负两种可能 | 解平方方程常见 |
| □ | 证明结束标记 | 只在论证真正完成后使用 |

## Agent Usage Notes
遇到符号歧义时，优先引用题目/教材定义；不要假定所有作者使用同一约定。
