# 第12章：例子与反例

## Core Idea
自己创造例子是数学理解与错误检测的核心工具。全称命题若错误，一个合法反例即可结束。

## Frameworks Introduced
- **例子库**：为重要定义保存典型、简单、极端和反直觉例子，以便检索。
- **反例搜索**：面对全称命题，先写出“反例需要同时满足什么”，再搜索边界与极端。
- **反转练习**：从“给输入求输出”反过来问“想得到某输出，应造什么输入”，迫使你理解结构。
- **例子用途分离**：例子可解释、测试、启发猜想；单个例子通常不能证明全称陈述。

## Procedure
1. 先写待测命题的精确逻辑形式。
2. 若是全称命题，写出反例必须满足的“假设真且结论假”。
3. 优先搜索零、最小、边界、极端和结构最简单对象。
4. 找到候选后核对全部假设；有效反例存入自己的标准例子库。

## Key Concepts
- **例子**：满足指定条件的具体对象，用于理解、测试和探索。
- **非例子**：至少违反定义中一个必要条件、因此不属于该类的对象。
- **反例**：满足命题全部假设但违反结论的对象。
- **标准例子**：能代表一个概念典型结构、适合反复调用的例子。
- **极端例子**：位于边界、最小/最大或退化处，常用于暴露隐藏假设的例子。
- **反转问题**：把“给输入求结果”改成“指定结果，构造输入”的探索法。

## Mental Models
- 证明前先尝试杀死命题；活过系统反例搜索的猜想才值得投入证明。
- 边界值、零、空集、单位元、最小维度通常是高收益反例候选。

## Anti-patterns
- 用几个成功例子“证明”全称命题。
- 反例没有满足命题的全部假设。

## Worked Example (reconstructed)
声称“若 $n\mid ab$，则 $n\mid a$ 或 $n\mid b$”。尝试小数与合数：取 $n=6,a=2,b=3$，有 $6\mid 6$，但 $6$ 不整除 2 或 3，因此命题被反例推翻，也提示缺失了“素数/互素”等额外条件。

## Key Takeaways
1. 先写反例的逻辑形状。
2. 优先试极端/简单边界。
3. 例子支持理解，反例能否定全称。
