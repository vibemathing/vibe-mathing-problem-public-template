# 第31章：等价关系

## Core Idea
等价关系通过自反、对称、传递把集合切成互不重叠的等价类；在商结构上定义运算时必须证明与代表元选择无关。

## Frameworks Introduced
- **三条件检查**：分别证明自反 $x\sim x$、对称 $x\sim y\Rightarrow y\sim x$、传递 $x\sim y,y\sim z\Rightarrow x\sim z$。
- **等价类**：$[x]=\{y:y\sim x\}$；同一类中的代表不同但表示同一个类对象。
- **分割对应**：等价关系产生集合的分割；反过来一个分割也定义“在同一块中”的等价关系。
- **良定义检查**：若用代表元定义类上的函数/运算，需证明换代表元不会改变结果。
- **模同余案例**：mod n 同余把整数分成 n 个余数类。

## Procedure
1. 确认关系确实定义在指定集合上。
2. 自反、对称、传递三项分别证明并分别找失败风险。
3. 写出若干等价类，检查它们相等或互不相交。
4. 若在类上定义运算/函数，换代表元并证明结果不变。

## Key Concepts
- **关系**：集合 X 上的二元关系可视为 X×X 的一个子集。
- **自反**：每个 x 都满足 x~x。
- **对称**：x~y 时必有 y~x。
- **传递**：x~y 且 y~z 时必有 x~z。
- **等价类**：[x]={y:y~x}，收集所有与 x 等价的元素。
- **分割**：把集合拆成互不相交且并回原集合的非空块。
- **代表元**：用来表示某等价类的其中一个元素。
- **良定义**：结果不依赖代表元等任意选择。

## Mental Models
- “商掉无关差异”时通常会出现等价关系。
- 任何代表元公式都先问 well-defined。

## Anti-patterns
- 只验证三个条件中的两个。
- 把同类代表元当作字面相等。
- 未验证代表无关性就定义运算。

## Worked Example (reconstructed)
在模 n 的等价类上定义 $[a]+[b]=[a+b]$。要合法，需证明若 $a\equiv a'$、$b\equiv b'$，则 $a+b\equiv a'+b'$；同余加法兼容性正提供良定义。

## Key Takeaways
1. 三条件分别验。
2. 类等于或互不相交。
3. 代表元构造必须做良定义审计。
