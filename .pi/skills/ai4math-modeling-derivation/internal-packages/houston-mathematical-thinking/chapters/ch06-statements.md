# 第6章：数学陈述

## Core Idea
逻辑推理从可判真假的陈述开始。先分清陈述与含自由变量的条件，再掌握否定、且/或与真值表。

## Frameworks Introduced
- **陈述识别**：一个陈述在给定解释下具有真值；含未量化变量的句子通常仍是条件式表达。
- **否定**：否定必须改变真值，且要覆盖原句全部结构。
- **De Morgan 规则**：$\neg(A\land B)\equiv(\neg A)\lor(\neg B)$；$\neg(A\lor B)\equiv(\neg A)\land(\neg B)$。
- **包容或**：数学中的“或”通常允许两者同时成立，除非条件本身排除了这种情况。
- **真值表**：不确定复杂逻辑式时，用真值表机械验证。

## Procedure
1. 判断句子是否已经是可判真假的陈述。
2. 把复合句拆成原子陈述及“且/或/非”。
3. 需要否定时按逻辑结构逐层改写。
4. 直觉不稳时列真值表验证。

## Key Concepts
- **陈述**：在固定解释下具有真或假真值的句子。
- **真值**：一个陈述为真或假的逻辑状态。
- **否定**：把陈述真值反转的逻辑运算。
- **合取**：A∧B，要求 A 与 B 同时成立。
- **析取**：A∨B，数学中通常为包容“或”。
- **排中律**：一个陈述与其否定中必有一个为真。
- **真值表**：枚举原子陈述真值组合以验证复合逻辑式的表格。

## Mental Models
- 把自然语言先拆成原子陈述和连接词。
- 逻辑直觉不稳时回退到真值表。

## Anti-patterns
- 把数学“或”自动理解为二选一。
- 否定复杂句时只在句首加“不”，却没改变内部连接词。

## Worked Example (reconstructed)
原句：“$n$ 是正数且为偶数。”其否定并非“$n$ 不是正数且不是偶数”，而是“$n$ 非正或 $n$ 非偶”。用一个负偶数即可看出两种否定不同。

## Key Takeaways
1. 先判断语句是否真能判真伪。
2. 否定“且/或”要交换连接词。
3. 含糊时用真值表验证。
