# 第28章：欧几里得算法

## Core Idea
用除法引理不断缩小余数，计算 gcd；再反向代入得到 Bézout 线性组合，并据此解决整除与线性丢番图方程。

## Frameworks Introduced
- **除法引理**：对非零整数 y，把 x 写成 $x=qy+r$，其中 $0\le r<|y|$，并分开证明存在与唯一。
- **Euclidean algorithm**：重复“较大数 = 商×较小数 + 余数”，最后一个非零余数就是 gcd。
- **Bézout 回代**：沿除法链反向代入，把 gcd 写成原两数的整数线性组合。
- **Euclid 引理**：若 $n\mid ab$ 且 $\gcd(n,a)=1$，则 $n\mid b$；素数版本由此得到。
- **丢番图门槛**：$mx+ny=c$ 有整数解 iff $\gcd(m,n)\mid c$；找到一组解后再参数化全部解。

## Procedure
1. 反复应用除法引理，记录每个商和余数。
2. 以最后一个非零余数作为 gcd，并检查终止。
3. 需要线性表示时沿记录反向代入得到 Bézout 系数。
4. 解 mx+ny=c 时先做 gcd|c 的存在性门槛，再构造并参数化解。

## Key Concepts
- **除法引理**：对非零 y，可唯一写 x=qy+r 且 0≤r<|y|。
- **Euclidean algorithm**：反复取余，最后非零余数给出 gcd 的算法。
- **Bézout 恒等式**：gcd(a,b) 可写成 ma+nb 的整数线性组合。
- **Euclid 引理**：在互素条件下，整除一个乘积可传递到另一因子；素数版本尤其常用。
- **线性丢番图方程**：要求整数解的线性方程，如 mx+ny=c。

## Mental Models
- 大整数 gcd 不要先质因数分解，直接跑欧几里得。
- “存在且唯一”类命题分两段证明。

## Anti-patterns
- 只算出 gcd，不利用回代信息。
- 忘记线性丢番图的 gcd 整除门槛。

## Worked Example (reconstructed)
求 $\gcd(252,105)$：252=2·105+42，105=2·42+21，42=2·21。故 gcd=21。再回代 $21=105-2·42=105-2(252-2·105)=5·105-2·252$，立即得到一个 Bézout 表达。

## Key Takeaways
1. 反复除法缩小问题。
2. 最后非零余数是 gcd。
3. 回代把计算升级为证明工具。
