# 第20章：证明技术 I：直接方法

## Core Idea
直接证明从假设出发，通过定义和已有结果逐步得到结论。若搜索需要倒推，成稿时重排成正向链。

## Frameworks Introduced
- **直接链**：假设 A → 展开定义/已知事实 → 中间结论 → B。
- **等式四路**：想证 $x=y$：化复杂边至另一边；证 $x-y=0$；证双向不等式；或证二者都等于同一对象。
- **iff 双向**：$A\Leftrightarrow B$ 分别做 $A\Rightarrow B$ 与 $B\Rightarrow A$。
- **包含/集合相等**：$A\subseteq B$：任取 $x\in A$ 证明 $x\in B$；$A=B$ 常做两个包含。

## Procedure
1. 从假设出发先展开相关定义。
2. 按目标形状选择等式、包含、iff 等标准拆法。
3. 用小步正向推出中间结论，必要时只在草稿中倒推。
4. 检查最终链没有假设结论，也没有把单向变形写成等价。

## Key Concepts
- **直接证明**：从假设出发按合法步骤正向推出结论的方法。
- **等式策略**：证明相等时可化一边、证差为零、证双向不等式或共同等于第三对象。
- **集合包含**：A⊆B 表示 A 每个元素都属于 B。
- **集合相等**：A=B 可通过 A⊆B 与 B⊆A 两个方向证明。
- **双向证明**：对 iff 或等价分别证明两个蕴含方向。

## Mental Models
- 第一反应是展开定义：很多“困难定理”会立刻变成代数或逻辑。
- 探索阶段可以从目标倒推充分条件。

## Anti-patterns
- 最终证明从结论出发并把它当假设。
- 写一串变形却不确认方向/可逆性。

## Worked Example (reconstructed)
证明 $A=B$：先做 $A\subseteq B$，任取 $x\in A$，根据 A 的定义推出 B 的成员条件；再交换角色做 $B\subseteq A$。两个方向都完成后才能写集合相等。

## Key Takeaways
1. 从假设正向推进。
2. 定义通常是第一工具。
3. 等式/集合/iff 各有标准拆法。
