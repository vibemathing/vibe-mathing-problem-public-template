# 第23章：证明技术 III：反证法

## Core Idea
反证法先假设目标的精确否定，再推出不可能。最适合不存在性、无理性或否定后能得到具体对象的命题。

## Frameworks Introduced
- **反证五步**：声明反证 → 写出目标的准确否定 → 推导后果 → 得到矛盾 → 明确结束。
- **蕴含的反证**：要证 $A\Rightarrow B$，反证时应同时假设 $A$ 与 $\neg B$。
- **不存在性路由**：“不存在 X”通常可假设存在一个 X 并追踪其必然后果。

## Procedure
1. 写出目标的精确否定；若目标是 A⇒B，同时保留 A 并假设 ¬B。
2. 从反证假设展开定义或结构。
3. 持续推导直到得到 P 与 ¬P、违反最简性/奇偶性等明确矛盾。
4. 指出矛盾使反证假设不可能，因此原目标成立。

## Key Concepts
- **反证法**：假设目标的否定并推出逻辑矛盾，从而证明目标。
- **矛盾**：两个互斥事实同时成立，或违反已知不可违背条件。
- **不存在**：断言没有任何对象满足给定性质。
- **无理数**：不能写成整数比 p/q（q≠0）的实数。

## Mental Models
- 反证的关键工作常在“正确写出否定”。
- 矛盾应落在明确事实冲突，如同时 P 与非P、违反最小性、奇偶冲突等。

## Anti-patterns
- 只写“假设相反”却没说明相反是什么。
- 推到“看起来奇怪”而非真正矛盾。

## Worked Example (reconstructed)
证明 $\sqrt2$ 无理：假设它可写为最简整数比 $a/b$。平方并利用奇偶性质可推出 a、b 都为偶数，与“最简”冲突。因此假设失败。重点是反证假设给出了可操作的整数结构。

## Decision Notes
反证法适合否定后能产生具体结构的目标；若直接法或逆否能更短地完成，就无需为了“高级”而反证。一个反证只有在落到明确不可能条件时才结束，直觉上的奇怪结果还不够。

## Key Takeaways
1. 先精确否定目标。
2. 非存在/无理性常优先考虑反证。
3. 矛盾必须是逻辑上的不可能。
