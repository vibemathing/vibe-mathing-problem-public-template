# 第2章：阅读数学

## Core Idea
数学阅读是主动解码与验证。目标不是“读完”，而是把符号、定义、命题和证明转化为可操作的理解。

## Frameworks Introduced
- **五步阅读法**：浏览结构并找重点 → 提问 → 慢读关键句 → 动手检查/做例子 → 反思并重组。
- **目的先行**：先决定这次阅读是查定义、学方法、理解证明还是复习；目的决定细读深度。
- **纸笔阅读**：遇到公式、图、例子或“显然”步骤时停下来计算、画图、改写或补步骤。
- **非线性阅读**：允许跳回定义、跨到例子、暂时越过困难证明再回来；根据理解需要重排路径。

## Procedure
1. 先写这次阅读的目的：查定义、学定理、懂证明或做题。
2. 快速浏览结构并标出反复出现的定义/结论。
3. 对关键句停下来改写、计算、画图或补“显然”步骤。
4. 用一个自造例或练习测试理解，再总结本节骨架。

## Key Concepts
- **浏览**：先快速看结构、标题与重点，再决定细读位置。
- **主动阅读**：通过提问、计算、造例和补步骤与文本互动。
- **关键假设**：结论成立所依赖、应用前必须核验的条件。
- **补步骤**：把作者省略的逻辑或计算环节自行写出并验证。
- **例子**：满足指定条件的具体对象，用于理解、测试和探索。
- **练习**：用于检验能否把概念或方法独立运用的任务。
- **反思**：完成阅读或解题后重新组织结构、连接旧知识并检查理解。

## Mental Models
- 读一页时不断问“这一句让我现在能做什么？”
- 理解卡住时切换表示：文字↔符号↔例子↔图。

## Anti-patterns
- 把数学像小说一样匀速从头读到尾。
- 反复盯着同一句，却不计算、不造例子、不回查定义。

## Worked Example (reconstructed)
读到“若 $n$ 为偶数，则 $n^2$ 为偶数”时，不停在语言层面。写 $n=2k$，代入得 $n^2=4k^2=2(2k^2)$，再指出最后一步为何满足“偶数”的定义。这样同时检查了命题、定义和推理链。

## Key Takeaways
1. 先明确阅读目的。
2. 每个重要符号、条件和引用都应能解释。
3. 卡住时动手制造信息。
4. 练习是理解测试。
