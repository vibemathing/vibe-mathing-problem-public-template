# 第30章：注入、满射、双射与无穷

## Core Idea
函数性质要围绕定义域和陪域证明：注入比较两个输入，满射从任意目标反求原像，双射兼有二者；双射也用于比较无限集合大小。

## Frameworks Introduced
- **注入模板**：假设 $f(x_1)=f(x_2)$，证明 $x_1=x_2$；这常比直接写“不相等输入给不同输出”好用。
- **满射模板**：任取 $y$ 于陪域，构造 $x$ 于定义域使 $f(x)=y$。
- **双射**：分别证明注入和满射；随后才可谈全局反函数。
- **复合顺序**：$g\circ f$ 先做 f 后做 g；另一顺序可能不同甚至无定义。
- **可数无限**：与 $\mathbb N$ 存在双射即为可数无限；无限集合可与其真子集等势。
- **对角法**：若假设某集合可列，构造一个按对角线与列表每项不同的对象来反证可列。

## Procedure
1. 先固定函数的定义域和陪域。
2. 证明注入：从 f(x₁)=f(x₂) 出发推出 x₁=x₂。
3. 证明满射：任取陪域 y，反求并验证一个定义域 x。
4. 双射两项都通过后再构造反函数或用于基数比较。

## Key Concepts
- **注入**：f(x1)=f(x2) 必推出 x1=x2 的函数性质。
- **满射**：陪域每个元素都有至少一个定义域原像的函数性质。
- **双射**：同时注入与满射的函数。
- **反函数**：双射下把输出唯一送回原输入的函数。
- **原像**：给定输出或集合，在定义域中映到它的输入集合。
- **可数**：本章重点讨论可数无穷，即能与自然数集合建立双射的无限集合。
- **不可数**：无法与自然数建立双射的无限集合。
- **对角论证**：构造一个与任意列表第 n 项在第 n 位不同的对象以否定可列性的方法。

## Mental Models
- 满射证明从目标 y 开始，反解需要什么 x。
- 定义域/陪域改变会改变注入/满射结论。

## Anti-patterns
- 从任意 x 算出一个 y 就声称满射。
- 只看公式判注射/满射，不看域。

## Worked Example (reconstructed)
证明 $f:\mathbb R\to\mathbb R, f(x)=x^3$ 满射：任取 $y\in\mathbb R$，取 $x=\sqrt[3]{y}$，则 x 属于定义域且 f(x)=y。这里“从任意 y 构造 x”正是满射所需量词顺序。

## Key Takeaways
1. 注入：相同输出迫使相同输入。
2. 满射：任意目标都有原像。
3. 双射是可逆与基数比较的桥梁。
