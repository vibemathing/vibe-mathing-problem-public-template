# 第26章：证明技术 V：逆否法

## Core Idea
当直接从 A 到 B 很难，而“非 B”给出明确结构时，改证等价的 $\neg B\Rightarrow\neg A$。

## Frameworks Introduced
- **逆否转换**：$A\Rightarrow B$ 与 $\neg B\Rightarrow\neg A$ 等价。
- **路由信号**：结论的否定比结论本身更具体、可计算或可分类时优先逆否。
- **与反证区分**：逆否从非B直接推出非A；反证则同时假设 A 与非B，再寻找矛盾。

## Procedure
1. 把目标标准化成 A⇒B。
2. 写出 ¬B 和 ¬A；确认 ¬B 比 B 更容易操作。
3. 假设 ¬B，通过定义/分类直接推出 ¬A。
4. 用逆否等价回到原命题，并检查没有误证 converse。

## Key Concepts
- **逆否法**：通过证明 ¬B⇒¬A 来证明 A⇒B 的方法。
- **结论否定**：目标结论 B 的否定 ¬B，常作为逆否法起点。
- **反证法区别**：逆否直接推出 ¬A；反证同时保留 A 与 ¬B 并推出矛盾。

## Mental Models
- 先试着写出非B；如果它立刻给出一个熟悉类别，逆否往往更短。

## Anti-patterns
- 把逆命题 B⇒A 当逆否。
- 写成反证却声称是逆否。

## Worked Example (reconstructed)
要证“若 $n^2$ 为偶数，则 n 为偶数”，直接从平方拆 n 不方便。改证逆否：“若 n 非偶，即 n 为奇数，则 $n^2$ 为奇数”，展开 $n=2k+1$ 即可。

## Decision Notes
逆否法的成功信号是“¬B”立即把对象归入一个容易描述的类别。若写出 ¬B 后仍没有新增结构，回到直接法、分情况或反证。完成时再次核对自己证明的是 ¬B⇒¬A，而非 B⇒A。

## Key Takeaways
1. 逆否与原命题同真值。
2. 结论否定具体时优先。
3. 与反证保持结构区分。
