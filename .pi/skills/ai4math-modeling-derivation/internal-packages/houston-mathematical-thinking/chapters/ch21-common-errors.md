# 第21章：常见错误

## Core Idea
证明和解方程中的很多错误来自“不可逆操作”和隐含前提。每一次除法、平方、开方、乘不等式都要检查条件与方向。

## Frameworks Introduced
- **禁止假设结论**：倒推只能用于发现路线；最终链不能把待证事实当已知。
- **平方的单向性**：平方可能引入伪解；得到候选解后回代原式。
- **开方语义**：$\sqrt{x}$ 表示主值；解 $t^2=a$ 时通常要考虑 $\pm\sqrt a$。
- **除法前置检查**：约分/除法前确认除数非零。
- **不等式符号**：乘除负数时方向翻转；符号未知就分情况。
- **变形可逆性**：解方程时标注每步是等价还是仅蕴含。

## Procedure
1. 给每一步变形标注它是“等价”还是“只推出”。
2. 遇到除法/约分先证明除数非零。
3. 遇到平方/开方记录可能新增或丢失的解。
4. 遇到不等式乘除先确定因子符号；最后把候选解回代原式。

## Key Concepts
- **伪解**：由不可逆变形引入、但不满足原问题的候选解。
- **主平方根**：√a 按约定取非负平方根（实数范围内 a≥0）。
- **除零**：除数为 0 时普通除法未定义，不能约分或消去。
- **不等式反向**：不等式两边乘或除负数时关系符号必须翻转。
- **可逆变形**：前后两个陈述相互推出、可用 ⇔ 连接的变换。

## Mental Models
- 把推导链标成“⇔”或“⇒”能强迫自己审查可逆性。
- 所有分母和符号条件都属于证明输入。

## Anti-patterns
- 除以可能为零的量。
- 平方后忘记回代。
- 认为 $-x$ 一定为负。

## Worked Example (reconstructed)
解 $\sqrt{x}=x-2$ 时，平方只给必要候选。得到代数解后必须回到原方程检查右边非负并逐一代入，剔除由平方产生的伪解。

## Key Takeaways
1. 每个操作都带前置条件。
2. 不可逆步骤只保留单向蕴含。
3. 候选答案必须回代或独立检查。
