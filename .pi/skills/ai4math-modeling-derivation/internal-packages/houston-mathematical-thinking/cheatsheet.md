# Cheatsheet — 决策优先

## 先判任务
| 你面对的形状 | 第一动作 |
|---|---|
| 新定义 | 列对象类型+全部条件；造例/非例 |
| 新定理 | 分假设/结论；逐项检查前提；问 converse |
| 全称命题真假 | 先猎杀反例；活下来再证明 |
| $A⇒B$ | 定义展开→直接；若 ¬B 更具体→逆否；若“不存在”味重→反证 |
| $A⇔B$ | 拆两个方向 |
| $A=B$（集合） | 双包含 |
| $a=b$（数/表达式） | 化边 / 差为0 / 双不等式 / 共同对象 |
| 自然数索引 | 归纳；多步依赖→强归纳/多基例 |
| 分段/奇偶/符号/余数 | 穷尽分情况 |
| 存在唯一 | 存在、唯一分开 |
| 注入 | 假设同输出，推出同输入 |
| 满射 | 任取目标 y，构造原像 x |
| 等价关系 | 自反、对称、传递三项分别验 |
| 等价类上运算 | 先证良定义 |

## 卡住时的下一步
1. 把术语全部展开成定义。
2. 写最小/极端/非例；尝试反例。
3. 把目标咬成更小子目标。
4. 文字↔符号↔图↔例子切换。
5. 从结论倒问“什么足够”，从假设正推，寻找中间桥梁。
6. 特殊化先解决可控版本；再尝试推广。
7. 对蕴含比较：直接 / 逆否 / 反证 / 分情况。
8. 仍缺信息时，明确报告缺失假设或暂不足以判断。

## 高风险错误
- `=` 仅表示真正相等；`⇒` 仅表示逻辑蕴含。
- 平方、开方、约分、除法、不等式乘除都检查可逆性与前置条件。
- 除法前查非零；乘除负数时不等号反向。
- 反例必须满足全部假设。
- 定理调用必须验全前置条件。
- 图、数值实验和若干例子可启发，不能代替一般证明。
- WLOG 必须有对称/重标记理由。
- 代表元定义必须证明与代表选择无关。

## SELF_CHECK
- 目标和量词是否精确？
- 方法与命题结构匹配吗？
- 每个定理前提都满足吗？
- 是否漏了零、边界、退化或符号情况？
- 是否把 converse 当成原命题？
- 是否用了不可逆步骤却写成等价？
- 能否造一个例子/反例来交叉检查？
- 最终稿是否是读者可审查的完整论证？
