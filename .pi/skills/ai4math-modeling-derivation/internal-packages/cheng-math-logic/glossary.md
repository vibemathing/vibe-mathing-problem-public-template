# Glossary

**抽象（Abstraction）** — 暂时忽略部分细节、保留当前关心结构的过程（Ch 1, 4, 5）。
**单位元（Identity）** — 与对象组合后不改变对象的元素；常规加法为0、乘法为1（Ch 2）。
**打包（Packaging）** — 将重复结构压缩为单一概念，以降低认知负荷（Ch 1）。
**反例（Counterexample）** — 推翻全称命题并暴露适用边界的实例（Ch 1）。
**范畴论（Category theory）** — 以对象之间的关系/态射为核心的抽象数学框架（Ch 1, 7）。
**群论（Group theory）** — 从对称及其组合中抽取结构的理论（Ch 1）。
**亏格（Genus）** — 拓扑中描述表面“手柄式洞”数量的量，与边界开口不同（Ch 8）。
**分配律（Distributivity）** — 连接加法与乘法的结构规则，是括号展开/网格法基础（Ch 3, 6）。
**复数（Complex numbers）** — 通过加入 `i²=-1` 扩展实数所得的数字体系（Ch 4）。
**公理（Axiom）** — 在一个数学世界中暂定为真的基本规则，用来研究其后果（Ch 1, 2）。
**关系（Relation）** — 数学对象之间的连接；方程常用于表达关系（Ch 5）。
**归纳（Generalization / mathematical induction）** — 将结构推广到更广范围；严格数学归纳需证明相邻步骤的逻辑桥梁（Ch 3, 4）。
**极限（Limit）** — 用任意精度逼近来定义无限过程候选结果的严密工具（Ch 4, 6, 8）。
**基本构成要素** — 在给定构建操作下足以生成整体、且希望尽量无冗余的元素（Ch 1, 3）。
**逆元（Inverse）** — 与对象组合后回到单位元的元素（Ch 2）。
**逻辑蕴涵（Implication）** — `A→B`：A为真时B必真；不能由B反推A（Ch 2）。
**测地线（Geodesic）** — 给定几何/距离下的最短路径，可不呈欧氏直线外观（Ch 5）。
**欧氏几何** — 熟悉的平面几何背景，部分学校公式只在此类背景成立（Ch 5, 6）。
**π** — 在给定长度与几何背景下，圆周长与直径之比（Ch 6）。
**三角函数** — 描述圆周运动投影、角度与边长比例关系的函数（Ch 6）。
**算术基本定理** — 自然数可唯一分解为质数乘积（忽略因子次序）（Ch 3）。
**拓扑（Topology）** — 研究连续变形下保持结构的数学；长度和角度可被忽略（Ch 8）。
**凸性（Convexity）** — 图形内任意两点的连线仍完全位于图形内的性质（Ch 8）。
**变量（Variable）** — 用来表达未知或一般对象的符号，使无限实例可由一个关系描述（Ch 5）。
**相等/等价** — 在指定判别标准下视为“相同”；必须说明保留的方面（Ch 7, 8）。
**一致性（Coherence）** — 不同推理/表示路线应表达兼容结构，使切换表示可靠（Ch 7）。
**质数（Prime）** — 在乘法构建自然数时不可约的基本构成要素；1作为单位元被排除（Ch 3）。
**直觉（Intuition）** — 用于发现方向与猜想的认知工具，需要由逻辑校准（Ch 2, 4, 7）。
