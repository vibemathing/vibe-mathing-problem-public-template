# Chapter 4: 什么是好的数学

## Core Idea
“正确”只说明逻辑没有坏；“好”还涉及解释力、启发性、统一能力、可扩展性和审美。直觉可被逻辑修正，定义可以通过巧妙改写问题，使原本不可直接操作的“无穷”变得可推理。

## Frameworks Introduced
- **候选答案式定义**：遇到无法直接执行的无限过程，不硬做“无穷次”，改成判定一个候选值是否满足极限条件。
- **直觉—严谨循环**：直觉提出方向；逻辑找漏洞或迫使直觉升级；新的直觉再引导下一步。
- **启发优先**：比较两个都正确的方法时，偏好能说明“为什么”、暴露结构并可迁移的方法。
- **归纳与统一**：把不同实例提升到共同结构，使一个图式同时解释数字、因子组合或其他系统。
- **高维扩展**：在原世界中无解时，可加入新对象构造更大世界，同时明确哪些旧规则保留。
- **价值框架审计**：评价“进步”“严谨”“好”时，追问判准来自何种文化/制度，并避免把单一传统包装成中立绝对标准。

## Key Concepts
- **极限**：不要求过程抵达“无穷终点”，而要求有限步骤可任意逼近唯一候选值。
- **收敛**：序列/和存在稳定极限；不收敛时不能把“无穷”随便当作普通数。
- **复数**：加入 `i²=-1` 后构成的扩展数字世界，说明“打破规则”实为扩大环境。
- **统一**：不同问题共享同一抽象结构，从而共用方法与直觉。
- **启发性**：方法除给结论外，还能解释成因、提供新的可见结构。
- **知识体系多元性**：拉马努金与哈代的故事被用来追问“谁有权规定有效数学”，提醒区分逻辑价值与制度/文化权威。

## Mental Models
- **抽象拼图**：好的理论像拼图，结构恰好吻合、没有无故凸起或缺口。
- **站到更高维看低维**：扩展空间可能让原空间的模式更清楚。
- **证明像翻译**：一个聪明但不透明的技巧可能正确，却不一定完成“理解”的任务。

## Anti-patterns
- **把形式正确等同于解释充分**：例如只用代数技巧证明循环小数结果，却隐藏极限定义所承担的工作。
- **让直觉拥有否决权**：面对无穷、复数等，人类经验不足，直觉必须接受逻辑训练。
- **把“发展”天然等同于“更好”**：应审视目标、代价、被排除的知识传统和权力结构。

## Worked Example
理解 `0.999…=1`：①不把省略号当神秘完成态；②把 `0.999…` 定义为序列 `0.9, 0.99, 0.999, …` 的极限；③候选值若小于1，总可取足够多位9使序列超过它；若大于1，则1始终更近；④极限唯一，因此候选值为1。这个路线把“无穷相加”转成“任意精度逼近”的可检验条件，并解释为什么“每个有限阶段都小于1”不妨碍极限等于1。

## Key Takeaways
1. 逻辑正确是底线，解释力和可迁移性决定方法的质量。
2. 无法直接操作的对象可以通过关系或极限间接定义。
3. 一般化的价值在于统一多个案例，同时保留差异检查。
4. 扩展数学世界时要检查一致性，而非依熟悉度决定对象“配不配存在”。
5. 数学评价体系也有历史与文化背景，应把判准本身纳入反思。
