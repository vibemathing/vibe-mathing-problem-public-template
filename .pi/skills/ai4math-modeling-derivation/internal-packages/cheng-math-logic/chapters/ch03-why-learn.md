# Chapter 3: 为什么要学习数学

## Core Idea
学习数学的价值可分为直接用途、进入其他学科的基础、以及更广泛的思维训练。许多定义之所以如此设定，是为了让一个目标结构既完整又无冗余；“为什么这样定义”应从目的与构建方式反推。

## Frameworks Introduced
- **三层有用性**：①直接实用；②作为其他学科前置能力；③训练可迁移的抽象、逻辑与结构化思维。
- **目标驱动定义**：先说希望结构实现什么，再选择定义，使目标定理/结构成立且尽量简洁。
  - When to use: 定义带有看似武断的例外。
  - How: 指明构建操作→列候选基本要素→删冗余→检查完整性与唯一性。
- **第一性原理**：把“显而易见”降解成更基础规则的推论。
- **数学归纳/一般化**：从小世界扩到大世界时，要有逻辑桥梁；观察多个例子本身不构成证明。
- **按行为分类**：不执着对象长什么样，比较它们在加法、乘法、对称、关系中的行为。

## Key Concepts
- **质数**：在用乘法构建自然数时发挥不可约基本构成要素作用的数；1是乘法单位元，加入它只制造冗余。
- **算术基本定理**：自然数可以由质数乘积构成且分解在忽略次序后唯一；它解释“足够且无冗余”。
- **位值**：数字列代表不同层级的单位；竖式的深层意义是分类相加与进位结构。
- **进制**：选择多少个符号/何时进位的系统，可一般化到任意大于1的基数。
- **间接应用**：训练大脑处理关系、抽象和逻辑，收益不依赖以后是否再次遇到同一道题。

## Mental Models
- **轻装出行**：基本构成要素太多会冗余，太少无法构建世界；目标是恰好够用。
- **核心肌肉**：抽象数学的普适价值来自训练思维方式，不要求每个知识点有日常直接用途。
- **水坑/山顶**：研究可以出于好奇、满足感、解释欲或挑战，不必伪造现实场景才能正当化。

## Anti-patterns
- **用虚构“生活应用”强行证明价值**：会掩盖真正的间接价值。
- **把算法当目的**：竖式、长除法等应根据是否产生理解与迁移价值评估。
- **把有限观察叫归纳证明**：缺少“第 n 步推出 n+1 步”的逻辑桥梁。

## Worked Example
为什么1不是质数：①先确定目标——用乘法的基本构成要素生成所有自然数；②1与任何数相乘都不改变结果，因此它是单位元，不能“构建”新对象；③合数可由更小因子构建，故也是冗余；④留下的不可约构成要素就是质数；⑤若把1也算质数，一个数可任意多乘几个1，质因数“配方”不再唯一。定义中的“不包括1”由无冗余与唯一分解目标驱动。

## Key Takeaways
1. 先问数学活动的目标，再评价方法是否“有用”。
2. 好定义往往服务于结构完整性与无冗余。
3. 第一性原理能把熟悉事实重新暴露为可证明命题。
4. 旧算法若能揭示结构仍有价值；若只增加痛苦则应重新评估。
5. 无法预测哪项纯数学未来会获得直接应用，因此不要用眼前用途作唯一价值尺度：书中用数论→加密、柏拉图正多面体→穹顶/病毒结构、芝诺式无穷问题→微积分说明这种滞后。
