# Chapter 7: 图形

## Core Idea
图形既可作为直觉辅助，也可成为正式推理语言。关键任务是明确“视觉上哪些特征代表数学结构”，并允许改变不重要的物理布局而保留抽象关系；同时警惕视觉编码操纵判断。

## Frameworks Introduced
- **等式的选择性同一**：`A=B` 通常表示在某个被选中的方面二者等价，同时保留其他差异；完全相同的 `x=x` 反而信息量最低。
- **视觉证明**：用积木、网格或变形证明运算律，目标是不计算具体答案也能看见结构。
- **多模态翻译**：在公式、图形、图表之间转换，让不同直觉互相补足。
- **结构保真布局**：图中对象的物理位置可变，只要连接、顺序或其他不变量保留；伦敦地铁图就是“关系优先于地理位置”的范例。
- **高维升级**：当二维视觉区分的路径在三维中变得可互相变形，就需要更高层关系来记录“变化之间的变化”。
- **视觉操纵审计**：检查截断坐标轴、3D透视、投影、线性/对数尺度等如何改变情绪感受。

## Key Concepts
- **交换律/结合律**：可用空间重排解释，而不只靠数值验证。
- **态射**：范畴论中表示对象间关系/过程的箭头。
- **辫状结构**：记录对象如何交换位置的过程；关注路径而非只有最终排列。
- **一致性**：代数推理与图形推理应表达同一结构，才能安全切换。
- **数据可视化**：通过视觉编码让趋势、比例或结构变得可感知；选择本身带有判断。南丁格尔的极坐标区域图展示了“分析正确”之外还要让关键比例对决策者可见。

## Mental Models
- **等式是“在某个镜头下相同”**：先声明镜头，再利用相同处迁移理解。
- **图形是翻译，不是装饰**：每个视觉元素都应对应一个数学角色。
- **高维像增加绕路空间**：低维中不同的交换路径，在更高维可能变为同一类。

## Anti-patterns
- **“两边都算成6，所以交换律成立”**：验证了一个实例，没有说明一般结构。
- **漂亮图形等于好图形**：数学图的首要质量是把相关特征表达清楚。
- **坐标/透视不披露**：截断纵轴或3D饼图可在逻辑数据不变时制造错误印象。

## Worked Example
用积木理解 `2+4=4+2`：①把2块与4块分成两个连续组，注意两种顺序的“过程”不同；②若只在一维轨道上，两个组不能互相越过；③进入二维平面，可把一组从另一组上方或下方绕过去，最终顺序互换且总对象保持；④因此“和不变”可以解释为存在保持对象数量的空间重排；⑤继续追问上绕和下绕是否同一，会自然引向三维路径、辫子与更高层关系。简单算术因此成为研究“相同到什么程度”的入口。

## Key Takeaways
1. 等价总要说明“在哪个方面相同”。
2. 图形可揭示无需计算就能看见的一般结构。
3. 表示之间的转换需要一致性保证。
4. 视觉化既能启发，也能操纵；尺度和投影是推理的一部分。
5. 当视觉直觉达到维度极限，应切回代数或更抽象语言。
