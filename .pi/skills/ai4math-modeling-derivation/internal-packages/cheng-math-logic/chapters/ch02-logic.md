# Chapter 2: 数学的逻辑

## Core Idea
数学判断“正确”的核心准则是逻辑：重点在可检验的推导过程。直觉和权威可以提出方向，却不能代替证明；定义、单位元与逆元能把负数、除法和“不可做”的边界严格构造出来。

## Frameworks Introduced
- **准则优先**：先说明某领域接受什么作为“足够可靠”。数学采用逻辑蕴涵，科学更依赖证据与不确定性评估。
  - When to use: 争论“谁说得对”、来源权威度或事实/观点混在一起时。
  - How: 分离偏好、证据主张、逻辑主张；对每类采用对应判准。
- **逆元构造**：把“减/除”理解为撤销某种运算。
  - How: 找单位元→定义使对象回到单位元的逆元→证明存在与唯一→识别例外。
- **过程验证**：答案已经给出也要问“为什么一定得到它”。显示过程是在展示逻辑支撑结构。
- **二元逻辑吸收细微差别**：在明确背景和定义之后，可做真/假判断；细微差别应被放进命题本身，而不是用模糊逻辑代替。

## Key Concepts
- **逻辑蕴涵**：`A→B` 表示 A 真时 B 必真；B 真不允许反推 A。
- **单位元**：运算中“无所作为”的元素；加法为0，常规乘法为1。
- **逆元**：与给定元素组合后回到单位元的元素。
- **空集满足**：对象集合为空时，全称陈述可能“空洞地”成立，提醒检查量词和对象域。
- **第一性证明**：从少量规则出发，不借“大家都知道”跨步。
- **基础不安（foundational unease）**：当数字、无理数、实数等概念难以严谨构造时，把不适感当成信号；教学提问可暴露理论地基需要补强之处。

## Mental Models
- **脚手架测试**：证明像安全检查；要拉、拽、冲击，主动尝试让结构失败。
- **定义对象“能做什么”**：无法直观说明负数是什么时，先定义它如何抵消。
- **多解释不是多真理**：同一结论可有不同证明；比较哪条更清晰、更可迁移。

## Anti-patterns
- **权威替代逻辑**：专家身份不能把无效推理变有效。
- **肯后件**：由 `A→B` 和 B 推出 A，是典型方向错误。
- **把“在常规体系中不定义”说成宇宙禁令**：例如除以0；更准确的问题是哪些规则使0无乘法逆元，以及改变规则要付出什么代价。

## Worked Example
推导 `-(-1)=1`：①把0定义为加法单位元；②把 `-x` 定义为 x 的加法逆元，即与 x 相加得到0；③已知 `1+(-1)=0`，所以1能抵消-1；④`-(-1)`按定义也是“能抵消-1的元素”；⑤若逆元唯一，则 `-(-1)=1`。同理分析“为什么不能除以0”：除法要求乘法逆元；若0有逆元 a，则应有 `0·a=1`，但常规乘法规则推出 `0·a=0`，与 `0≠1` 冲突。因此限制来自整个规则系统的一致性。

## Key Takeaways
1. 数学的“对错”主要约束推导过程。
2. 质疑显然结论是严谨性的来源之一。
3. 逆运算的统一视角能解释负数、分数和除法。
4. 细微差别应通过更精确的背景与命题表达。
5. 遇到“不能做”，先查是否是逆元不存在或与其他规则冲突。
