# Chapter 5: 字母

## Core Idea
字母不是把简单数字故意变难；它们把无限多具体实例压缩成一个关系，使数学可以明确谈“一般情况”。方程描述的是对象之间的关系，其真值取决于坐标系、几何背景和定义。

## Frameworks Introduced
- **变量打包**：用一个符号代表任意对象或未知对象，把无限实例压成一个可推理单元。
  - When to use: 规则对许多具体值都一样，或需要在未知量间建立关系。
  - How: 先从具体例识别不变关系→用变量替换实例→声明变量范围→检验边界。
- **关系优先**：把等式/方程视为对象之间的关系，而不是要“算出一个答案”的命令。
- **代入/关系组合**：把一个已知关系作为整体嵌入另一个关系，构建更复杂的推理链。
- **参照系切换**：同一空间可用笛卡儿坐标、极坐标或其他坐标描述；比较时先确定哪些结构不随表示改变。
- **背景限定公式**：公式通常在特定几何/坐标背景下成立，应把背景写进命题。

## Key Concepts
- **变量**：代表未知量或一般对象的符号，其作用是打包关系。
- **代数**：组合与操作符号关系的体系，使一般化推理成为可能。
- **笛卡儿坐标**：用两个方向坐标定位平面点的一种表示。
- **极坐标**：用到中心的距离与角度定位点的另一种表示。
- **测地线**：给定几何/距离定义中两点间的最短路径，可不呈现欧氏直线外观。
- **欧氏/球面/双曲几何**：不同背景中“直线”和三角形角和具有不同性质。

## Mental Models
- **字母是真空压缩袋**：它压缩的是无穷多具体案例，不是为了神秘化。
- **方程是桥梁**：它把两个表示世界连接起来，例如坐标与图形。
- **坐标是描述，不是对象本身**：换坐标不应误以为现实对象发生了变化。

## Anti-patterns
- **从有限点猜唯一图形**：若未声明关系，有限样本可被无数图形穿过。
- **把 `y=mx+c` 当所有“直线”的绝对定义**：它依赖笛卡儿坐标与特定欧氏几何背景，还不能表示某些垂直线的同一形式。
- **只操作符号，不说明变量域**：会把局部规律误用到不兼容对象。

## Worked Example
解释 `y=mx+c`：①选定二维笛卡儿平面；②把一条特定直线固定后，m、c 是常数，x、y 是线上点的坐标；③方程不是列出点，而是一次描述所有满足关系的 `(x,y)`；④通过 m 控制每增加单位 x 时 y 的变化率，c 控制与纵轴的偏移；⑤再检查边界：换成极坐标、球面/双曲几何或不同“距离”定义时，同一“直线”概念需换表达。结论必须写成“在这个背景里”。

## Key Takeaways
1. 变量的力量来自精确表达一般关系。
2. 有限样本只能启发猜想，不能确定一般规律。
3. 坐标系是可选表示；转换时需追踪不变量。
4. 公式的适用范围是公式含义的一部分。
5. 一般化让理解跨案例迁移，但必须同时声明适用域。
