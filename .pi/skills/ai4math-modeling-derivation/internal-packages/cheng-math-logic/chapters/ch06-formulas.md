# Chapter 6: 公式

## Core Idea
公式应被“消化”为关系，而非靠助记符塞进记忆。最可靠的学习路线是追溯它从什么几何、比例、运算律或定义产生，并能够在需要时重新推导。

## Frameworks Introduced
- **消化优于死记**：通过理解、反复使用、联系其他结构，让结果成为可重建的知识。
- **坐标转换生成三角函数**：正弦/余弦可理解为圆周运动在两个笛卡儿方向的投影。
- **缩放不变量**：相似图形按比例缩放时角度不变、边长同比变化，因此边长比可只依赖角度。
- **关系式定义常数**：π首先是圆周长与直径的比值；具体数值依赖所用的距离/几何背景。
- **公式反推法**：遇到口诀，问它由哪个更一般的运算律产生；FOIL来自乘法对加法的分配律，网格表示更容易推广。

## Key Concepts
- **正弦/余弦**：单位圆上点的垂直/水平坐标随角度变化的关系。
- **正切**：单位水平变化对应的垂直变化率，可由正弦与余弦比得到。
- **π**：在给定几何和长度概念下，圆周长与直径的固定比例。
- **面积/曲线长度**：从直边近似与极限逐步构造的量，而非天然无需定义的“显然”对象。
- **运算顺序**：主要是符号书写约定；清晰括号比炫耀记忆规则更重要。
- **分配律**：括号乘法真正的结构来源，能解释并推广网格法。

## Mental Models
- **公式是一台关系机器**：输入一组关系，就能一次处理无限多实例。
- **先做单位圆/标准情形**：把复杂因素归一化为0或1，理解核心结构后再缩放回一般情形。
- **助记符是压缩，不是解释**：只有知道压缩前的结构，口诀才安全。

## Anti-patterns
- **SOHCAHTOA/FOIL/BODMAS 取代理解**：能提高短时速度，却容易阻断迁移。
- **背π的小数位当理解π**：小数展开几乎不解释圆的结构关系。
- **把符号约定当数学定理**：运算顺序改变时数学结构可保持，说明它主要属于表达规范。

## Worked Example
重建 SOHCAHTOA：①从单位圆选一个与 x 轴夹角 θ 的点；②定义垂直坐标 `y=sinθ`、水平坐标 `x=cosθ`；③形成斜边为1的直角三角形；④若斜边缩放为 h，所有边同比缩放，于是对边=`h sinθ`、邻边=`h cosθ`；⑤整理得到 `sinθ=对边/斜边`、`cosθ=邻边/斜边`；⑥斜率=垂直/水平=`sinθ/cosθ`，定义为 `tanθ`，因此 `tanθ=对边/邻边`。这样三条口诀都能从同一几何关系重建。

## Key Takeaways
1. 先找公式的动机与生成关系，再决定是否需要熟练记忆。
2. 归一化与缩放可以显著减少无关复杂性。
3. 常数和公式的数值/形式可能依赖几何背景。
4. 网格法优于FOIL之处在于它暴露分配律并可扩展。
5. 精确不是目的本身；精确应服务于可继续构建的逻辑结构。
