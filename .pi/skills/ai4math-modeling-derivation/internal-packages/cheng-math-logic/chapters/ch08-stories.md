# Chapter 8: 故事

## Core Idea
简单问题可以由不同定义导向不同、同时有效的答案。成熟的数学推理先决定“统计什么”“什么算相同”“当前保留哪些结构”，再在选定规则下严谨前进，并能随目标切换视角。

## Frameworks Introduced
- **计数前先定义对象**：问“有几个角/边/洞”之前，先决定什么算一个对象，以及哪些对象视为同一个。
- **周期—最大公因数分析**：重复跳跃何时覆盖全部位置，取决于步长与总数的公因数；用结构解释循环而非枚举。
- **凸性判别**：把“向里/向外的角”改写为任意两点连线是否始终留在图形内，获得可推广定义。
- **拓扑同一性**：若物体可通过连续变形互相转化而无需切开/粘接，则在拓扑视角下视为同类。
- **多层‘洞’模型**：同一吸管可按功能故障、分子空隙、三维通道、表面边界、亏格等不同对象来数“洞”。
- **视角切换协议**：列候选定义→对每个定义独立求解→说明它保留/忽略什么→根据当前目的选择。

## Key Concepts
- **最大公因数**：决定循环跳步是否会在覆盖全部点之前回到起点。
- **凸图形**：任意两点间直线段都位于图形内部的图形。
- **拓扑**：忽略长度、角度等度量细节，研究连续变形下保持的结构。
- **流形**：局部看起来像平坦空间的表面/空间。
- **亏格**：描述表面“手柄式洞”的拓扑数量，与边界开口是不同概念。
- **边界**：局部“开口”可作为表面的圆形边界来研究。

## Mental Models
- **先选游戏规则，再玩到底**：规则一旦选定，推导应严谨；下一轮仍可换一套规则研究另一种结构。
- **骨架与关节**：数学的严密架构像骨架，视角切换像关节；力量来自两者同时存在。
- **故事从一个天真问题开始**：问题的价值不取决于答案是否短，而取决于它打开哪些结构。

## Anti-patterns
- **争“吸管到底一个洞还是两个洞”却不定义洞**：双方可能在数不同对象。
- **把一个视角升级成唯一现实**：拓扑答案、功能答案、表面答案各自服务不同目标。
- **规则随推导结果临时改变**：允许换游戏，但必须明确宣布切换；不能在同一推导中偷换定义。

## Worked Example
“一支吸管有几个洞？”可形成视角矩阵：①功能故障语境：完整吸管可说“没有破洞”；②把贯穿通道当一个整体：像拉长的环，得到一个洞；③把表面开口当边界：两端各一个，得到两个；④考虑分子空隙：出现极大量微观空隙；⑤拓扑表面还可区分边界孔与亏格。处理争议时不要先投票选答案，而要问双方的对象和同一性标准，再按当前任务（维修、拓扑分类、表面建模等）选模型。

## Key Takeaways
1. 计数问题首先是定义与同一性问题。
2. 多个答案可以在不同明确背景下同时有效。
3. 严谨与灵活并存：选定视角后严谨推导，必要时再显式换视角。
4. 简单、易说的问题可以连接数论、凸性、微积分、拓扑和流形理论。
5. 全书最终方法是让好奇心提出问题，让直觉给方向，让逻辑保证可依赖性。
