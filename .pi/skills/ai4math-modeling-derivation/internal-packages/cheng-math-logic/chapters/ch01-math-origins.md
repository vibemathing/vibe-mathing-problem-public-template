# Chapter 1: 数学从哪里来

## Core Idea
数学从“为什么”和“规则能否被打破”的冲动出发。真正有力量的做法，是把显然的规则放进不同背景中测试，借助反例、抽象和基本构成要素，弄清它何时成立以及为什么成立。

## Frameworks Introduced
- **条件化规则（When is it true?）**：面对 `1+1=2` 一类结论，先问“在哪个世界里？”
  - When to use: 结论被当成绝对事实，或用户对规则感到被强迫时。
  - How: 改变对象、运算、舍入、组合规则等条件，寻找不同结果，再提炼使常规结论成立的条件。
- **抽象滤镜**：抽象是暂时忽略细节，保留当前关心的共性。
  - When to use: 多个具体案例相似，却被表面差异淹没。
  - How: 先选关注维度→忽略其他差异→构造抽象世界→在抽象世界研究→再映回现实。
- **螺旋楼梯**：新研究对象带来新方法，新方法又产生新对象；数学沿“对象↔方法”不断上升。
- **打包（Packaging）**：把重复模式压成一个概念，再把这个概念当成新的基本单元继续推理。
- **基本构成要素**：从少量公理/生成元构造一个世界，重点研究它们怎样互动，不把公理误当成绝对真理。

## Key Concepts
- **反例**：足以推翻全称命题的具体情形；用来定位规则边界。
- **抽象**：保留当前重要结构、暂时忽略其他细节的选择。
- **类比**：借共同结构迁移理解；必须同时检查差异，防止过度类推。
- **自由生成结构**：只给最基本规则，不额外施加限制，让结构展开。
- **对称与群论**：把具体图形的对称抽象成“变化如何组合”的结构，展示从研究对象走向研究方法。
- **关系与范畴论**：把对象看成关系网络，甚至把对称看成对象与自身的关系；强调数学可通过新抽象扩展研究对象。
- **单位元/抵消模式**：不同世界可有不同组合规律，表面同一符号未必同一结构。

## Mental Models
- **把规则当边界地图**：寻找“哪里会失效”往往比重复成功例更能解释规则。
- **把抽象当相机滤镜**：滤镜不是删除现实，而是暂时突出一种结构；需要时换滤镜。
- **把理论当行李打包**：一旦识别模式并命名，就能用更少认知资源处理更复杂问题。

## Anti-patterns
- **“因为就是这样”**：把定义或权威当解释，会遮住前提和可变条件。
- **只找相似，不找差异**：指数增长、传播等类比若忽略资源上限，会产生错误外推。
- **把抽象误解成脱离现实**：抽象的目的之一正是让更多现实情形可被同一结构理解。

## Worked Example
从 `1+1` 出发建立“结构而非答案”的理解：常规计数世界里，一个对象加一个不同对象得到两个；奇偶/负号抵消模式可以出现 `1+1=0`；幂等式组合可出现 `1+1=1`。操作步骤：①明确“1”和“+”代表什么；②列组合表；③找与其他现象共享的模式；④给模式打包命名；⑤回到常规自然数，说明 `1+1=2` 依赖无坍缩、无复制、无抵消的生成规则。这样得到的是适用条件，而不是权威口令。

## Key Takeaways
1. 把“为什么 X”改成“X 何时成立”，能暴露隐含前提。
2. 反例的价值是画出边界，再解释边界内为何安全。
3. 抽象必须同时管理相似与差异。
4. 数学通过打包重复结构扩大可思考的复杂度。
5. 公理定义一个可研究的世界，不保证跨世界仍为真。
