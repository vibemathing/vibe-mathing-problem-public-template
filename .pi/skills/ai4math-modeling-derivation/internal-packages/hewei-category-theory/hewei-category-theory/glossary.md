# Glossary

**Abelian category / Abel 范畴** — 加法且有限完备/余完备；mono/epi 分别为 kernel/cokernel（4.2）。
**Additive category / 加法范畴** — 有零对象与有限双积的准加法范畴（4.1）。
**Adjunction / 伴随** — `Hom(F(A),B)≅Hom(A,G(B))` 的双变量自然同构（3.1）。
**Bifunctor / 双函子** — 从 `C×D` 出发的函子（1.2）。
**Bimorphism / 双态射** — 同时 mono、epi（1.4）。
**Biproduct / 双积** — 同时为积与余积（4.1）。
**Cartesian closed** — 有有限积且每个 `A×-` 有右伴随（3.4）。
**Category / 范畴** — 对象、态射、复合、单位满足公理（1.1）。
**Cocomplete / 余完备** — 所有小图有余极限（2.5）。
**Coequalizer / 余等值子** — 强制平行态射相等的万有商（2.2）。
**Complete / 完备** — 所有小图有极限（2.5）。
**Coreflective / 余反射** — 满包含函子有右伴随（3.3）。
**Cokernel / 余核** — `f` 与零态射的余等值子（4.1）。
**Create limits / 产生极限** — 目标极限可唯一提升回源范畴（2.6）。
**Equalizer / 等值子** — 平行态射相等部分的万有子对象（2.2）。
**Eilenberg–Moore category** — T-代数范畴 `C^T`（3.5）。
**Epimorphism / 满态射** — 右消去（1.4）。
**Equivalence / 范畴等价** — 存在拟逆及自然同构（1.3）。
**Exact sequence / 正合序列** — 每点 `im=ker`（4.3）。
**Faithful / 局部单** — hom 映射均单射（1.2）。
**Full / 局部满** — hom 映射均满射（1.2）。
**Functor / 函子** — 保持单位与复合（1.2）。
**Grothendieck topology** — 满足最大筛、拉回稳定、局部传递的覆盖结构（5.5）。
**Image / 像** — `im(f)=ker(coker f)`（4.2）。
**Initial object / 初始对象** — 到每对象恰有一箭头（1.5）。
**Inverse image / 逆向层函子** — `f^*:Sh(Y)→Sh(X)`（5.4）。
**Kernel / 核** — `f` 与零态射的等值子（4.1）。
**Limit / 极限** — 锥范畴的终对象（2.1）。
**Local homeomorphism / 局部同胚** — 局部限制为同胚（5.2）。
**Matching family / 相容族** — 覆盖上在 pullback 交叠处一致的截面族（5.5）。
**Monad / 模** — `(T,η,μ)` 满足单位律与结合律（3.5）。
**Monadic / 可模** — comparison functor 到 `C^T` 为同构（3.5–3.6）。
**Monomorphism / 单态射** — 左消去（1.4）。
**Natural transformation / 自然变换** — 满足自然性方形的分量族（1.3）。
**Power object / 幂对象** — `A×-` 的右伴随值 `B^A`（3.4）。
**Preadditive / 准加法** — hom 为 Abel 群且复合双线性（4.1）。
**Presheaf / 准层** — 到 Set 的反变函子（5.1, 5.5）。
**Projective / 射影对象** — 对 epi 有 lifting property（1.7）。
**Pullback / 拉回** — `A→C←B` 的极限（2.4）。
**Pushout / 推出** — 拉回的对偶（2.4）。
**Reflective / 反射** — 满包含函子有左伴随（3.3）。
**Regular epi/mono / 正则满/单** — 某个 coequalizer/equalizer（2.2）。
**Representable / 可表达函子** — 自然同构于 hom 函子（1.6）。
**Sheaf / 层** — 相容局部数据可唯一粘合的 presheaf（5.1, 5.5）。
**Sheafification / 层化** — 准层的最佳层逼近（5.2）。
**Sieve / 筛** — `C(-,C)` 的子函子（5.5）。
**Site / 场** — 带 Grothendieck topology 的小范畴（5.5）。
**Subobject / 子对象** — 指向对象的 mono 的同构类（1.5）。
**Subobject classifier** — 用 characteristic morphism 分类 mono 的 `Ω`（5.3）。
**Terminal object / 终对象** — 每对象到它恰有一箭头（1.5）。
**Unit/Counit / 单位/余单位** — `η:1→GF`, `ε:FG→1`（3.1）。
**Yoneda lemma** — `Nat(C(A,-),F)≅F(A)`（1.6）。
**Zero object / 零对象** — 同时初始与终结（4.1）。
