# Cheatsheet — 结构到方法的快速路由

| 看到的结构 | 首选路线 | 失败后 |
|---|---|---|
| “用定义证明”极限 | 控制对象 → 放大/缩小 → 解控制量 | 最简初等函数改用等价不等式 |
| 不知道极限值但要证存在 | Cauchy / 单调有界 / 紧性 | 构造否定片段或换更高层工具 |
| 有限不定和/积 | 夹逼；若相邻差更简单则 Stolz | 精细分组/主项控制 |
| 幂指极限 | 对数法或重要极限标准化 | Taylor |
| 函数极限不存在 | Heine：一条坏序列或两条不同像极限 | 单侧极限/部分逻辑 |
| 零点/介值 | 构造函数 + 两个异号/夹值点 | Rolle/中值定理 |
| 导函数零点 | Rolle：找两个等值点 | 构造辅助函数/内部极值点 |
| 两点差值、平均变化率 | Lagrange/Cauchy 中值定理 | Taylor |
| 同点多阶信息/高阶0/0 | Taylor，阶数由首个非消去阶决定 | 中值定理/阶的代换 |
| 迭代数列 | 预判 → 单调 + 有界 → 固定点 | Stolz/夹逼 |
| 不定积分复合结构 | 换元 | 分部/主次分析 |
| 多项式×指数/三角 | 分部积分 | 先代换/递推 |
| 含参数 n 的积分 | 降阶递推 + 初值 | 恒等式/分部重新设计 |
| Riemann 和极限 | 标准化为 Σf(ξ)Δx | 夹逼/挖洞 |
| 定积分恒等式 | 对称/分段/换元 + 形式统一 | 变易法 |
| 广义积分敛散 | 比较/Cauchy；有阶则 p-积分试验 | Dirichlet/定义/临界处理 |
| 正项级数 | n幂→根值；阶乘→比值；ln慢变→积分；临界→Raabe/p试验 | 更精细比较 |
| 交错级数 | Leibniz | 形式统一/Dirichlet/Abel |
| 函数列一致收敛 | sup/max 误差 →0 | Dini/估计 |
| 非一致收敛 | 端点发散 → 通项必要条件 → 和函数性质逆否 → Cauchy | 构造坏点列 |
| 三角函数项级数 | 有界性 / 部分和一致有界 / 周期性三选一 | Cauchy 坏片段 |
| 幂级数和函数 | 几何级数 ↔ 逐项求导/积分 | 先简化系数 |
| Fourier 展开 | 先定一般/正弦/余弦 → 周期/奇偶 → 系数 | 重新设计延拓 |

## 五个硬检查
1. **量词**：N、δ 只能依赖允许依赖的先行参数。
2. **前提**：连续、可导、单调、正性、闭区间、非零分母逐项核验。
3. **量级**：放缩后仍保留正确主阶；夹逼两端必须可能会合。
4. **局部/整体**：点态、局部、一致、内闭一致不可互换。
5. **临界**：判别法返回临界值（如比值=1）时视为“无结论”，立即换路。
