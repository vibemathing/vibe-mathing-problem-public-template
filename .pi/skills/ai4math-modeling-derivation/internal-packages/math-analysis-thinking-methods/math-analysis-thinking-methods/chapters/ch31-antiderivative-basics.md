# 第 31 讲：不定积分计算的基本思想

## Core Idea
不定积分计算的总目标是把被积函数结构转成已知导数/基本积分公式。先识别“最难因子”和可能的微分关系，再选择代换、分部或代数分解。

## Frameworks Introduced
- **结构触发器**：当出现以下情形时，优先加载本讲。
- 不定积分无直接公式
- 多个因子复合
- 需要判断代换还是分部
- **核心操作**：按本讲的 `Operational Procedure` 选路；若结构不匹配，返回总控路由，不强套。

## Key Concepts
- **原函数**
- **结构简化**
- **基本积分**
- **复合微分**

## Operational Procedure
1. 列出被积函数的组成因子和运算关系。
2. 找最难/最特殊因子。
3. 检查其内层函数的导数是否同时出现。
4. 若有明显复合微分结构，用换元。
5. 若一个因子求导会显著简化且另一个因子易积分，用分部。
6. 若结构仍混杂，先分解或形式统一到基本公式。

## Decision Points
- 优先让复杂性单调下降；每一步都问“变换后是否更接近基本积分”。

## Mental Models
- 把定理看作有“作用对象”的工具：先匹配结构，再执行公式。
- 把证明/计算看作结构变换链：每一步都应降低不确定性或复杂度。

## Anti-patterns
- **避免**：只按表面函数类别选方法。
- **避免**：代换后仍同时含原变量和新变量。

## Worked Example
看到 f(g(x))g′(x) 立即考虑 t=g(x)；看到多项式×指数/三角且多项式求导降阶，优先分部。

## Failure Recovery
1. **工具无效**：回到题型结构，检查是否选错定理层级或漏掉更强/更弱条件。
2. **估计不收敛/不够紧**：恢复被过度丢弃的主阶信息，改用精细放缩、分段或另一标准对象。
3. **形式统一越变越复杂**：撤销最近变换，换统一方向；优先向已知、低阶、单变量或标准形靠拢。
4. **存在性无法证明**：若目标允许，切换到 Cauchy/紧性/单调有界等“不先知道极限值”的路线。

- [ ] 所选方法的前提是否逐项满足？

## Key Takeaways
- 先识别本讲的**作用对象特征**，再调用方法。
- 关键技术必须能解释“为什么这一步让结构更简单或更可控”。
- 保留例外、临界情形和失败信号；无法满足前提时应换路线。
