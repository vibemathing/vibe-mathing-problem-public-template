# 第 36 讲：三角函数的不定积分的计算方法

## Core Idea
三角不定积分先用恒等式和微分结构把角度、函数种类统一，再代换。目标是减少三角函数种类或把一个因子的微分显式化。

## Frameworks Introduced
- **结构触发器**：当出现以下情形时，优先加载本讲。
- sin^m x cos^n x
- tan/sec 或 cot/csc 组合
- 不同角度三角因子混合
- **核心操作**：按本讲的 `Operational Procedure` 选路；若结构不匹配，返回总控路由，不强套。

## Key Concepts
- **三角恒等式**
- **降幂**
- **角度统一**
- **微分配对**

## Operational Procedure
1. 先检查奇偶幂。
2. 奇次时保留一个与微分匹配的因子，其余用平方恒等式改写。
3. 偶次时考虑降幂/倍角。
4. tan/sec 结构检查 sec² 或 sec·tan 的微分对。
5. 不同角度先用和差化积/积化和差统一角度。
6. 再换元并检查新结构是否代数化。

## Decision Points
- 选恒等式的标准是减少函数种类并保持角度一致。

## Mental Models
- 把定理看作有“作用对象”的工具：先匹配结构，再执行公式。
- 把证明/计算看作结构变换链：每一步都应降低不确定性或复杂度。

## Anti-patterns
- **避免**：使用恒等式后角度更多、函数种类更多。
- **避免**：只凭记忆套固定“奇偶口诀”，忽略特殊结构。

## Worked Example
sin^3x cos^2x：保留 sin x dx，把其余 sin²x 改写为 1-cos²x，再 t=cos x 化成多项式积分。

## Failure Recovery
1. **工具无效**：回到题型结构，检查是否选错定理层级或漏掉更强/更弱条件。
2. **估计不收敛/不够紧**：恢复被过度丢弃的主阶信息，改用精细放缩、分段或另一标准对象。
3. **形式统一越变越复杂**：撤销最近变换，换统一方向；优先向已知、低阶、单变量或标准形靠拢。
4. **存在性无法证明**：若目标允许，切换到 Cauchy/紧性/单调有界等“不先知道极限值”的路线。

- 先识别本讲的**作用对象特征**，再调用方法。
- 关键技术必须能解释“为什么这一步让结构更简单或更可控”。
