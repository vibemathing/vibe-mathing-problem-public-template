# 第 42 讲：定积分不等式

## Core Idea
定积分不等式通过“点态不等式→积分”或“把积分关系变成辅助函数单调性”处理。复杂结构中，Cauchy–Schwarz 与变易法是两类核心工具。

## Frameworks Introduced
- **结构触发器**：当出现以下情形时，优先加载本讲。
- 证明积分上/下界
- 积的积分/平方结构
- 含积分上限变量的复杂不等式
- **核心操作**：按本讲的 `Operational Procedure` 选路；若结构不匹配，返回总控路由，不强套。

## Key Concepts
- **积分估计**
- **Cauchy-Schwarz**
- **变易法**
- **辅助函数**
- **单调性**

## Operational Procedure
1. 先找点态序关系，能直接积分则优先。
2. 平方/乘积结构尝试 Cauchy–Schwarz。
3. 中值型上界可用积分中值定理或最值。
4. 复杂端点常数：把上限 b 改为变量 t，定义差值函数 F(t)。
5. 求 F′ 并判符号，利用 F(a)=0 推出 F(b) 的符号。

## Decision Points
- 变易法适合“结论对任意终点都可写”的结构。

## Mental Models
- 把定理看作有“作用对象”的工具：先匹配结构，再执行公式。
- 把证明/计算看作结构变换链：每一步都应降低不确定性或复杂度。

## Anti-patterns
- **避免**：一看到积分不等式就套 Cauchy–Schwarz。
- **避免**：定义辅助函数后导数比原结构更复杂且不可控。

## Worked Example
若目标含 (∫fg)^2，比较 (∫f²)(∫g²)，优先 Cauchy–Schwarz；若目标是固定端点积分与函数值的关系，可把端点变成 t 后看差值函数单调性。

## Failure Recovery
1. **工具无效**：回到题型结构，检查是否选错定理层级或漏掉更强/更弱条件。
2. **估计不收敛/不够紧**：恢复被过度丢弃的主阶信息，改用精细放缩、分段或另一标准对象。
3. **形式统一越变越复杂**：撤销最近变换，换统一方向；优先向已知、低阶、单变量或标准形靠拢。
4. **存在性无法证明**：若目标允许，切换到 Cauchy/紧性/单调有界等“不先知道极限值”的路线。
