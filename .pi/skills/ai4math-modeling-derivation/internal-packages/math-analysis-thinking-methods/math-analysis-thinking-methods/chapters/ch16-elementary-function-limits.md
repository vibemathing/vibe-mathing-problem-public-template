# 第 16 讲：基本初等函数极限的建立方法

## Core Idea
当控制对象已经是最简的基本初等函数结构，继续放缩没有意义；应把 |f(x)-A|<ε 直接等价转化为自变量不等式，用函数单调性或反函数求出 δ。

## Frameworks Introduced
- **结构触发器**：当出现以下情形时，优先加载本讲。
- 指数、对数、三角、反三角函数的基本极限
- 极限定义中对象无法再结构简化
- 需要建立基础极限库
- **核心操作**：按本讲的 `Operational Procedure` 选路；若结构不匹配，返回总控路由，不强套。

## Key Concepts
- **等价不等式**
- **单调性**
- **反函数**
- **基本初等函数**

## Operational Procedure
1. 写目标不等式。
2. 利用函数单调性/反函数把函数值不等式反解为 x 的区间。
3. 把该区间转成 |x-x0|<δ。
4. 选择任一足够小的 δ。
5. 非正常极限同理，把 >G 反解为邻域条件。

## Decision Points
- 最简结构优先“不等式求解法”；不要硬造放缩链。

## Mental Models
- 把定理看作有“作用对象”的工具：先匹配结构，再执行公式。
- 把证明/计算看作结构变换链：每一步都应降低不确定性或复杂度。

## Anti-patterns
- **避免**：对原子函数做复杂 Taylor/中值展开，增加不必要工具。
- **避免**：忘记反函数适用区间或单调性。

## Worked Example
e^x→1：把 |e^x-1|<ε 化成 ln(1-ε)<x<ln(1+ε)，再取两侧允许范围的较小值作为 δ。

## Failure Recovery
1. **工具无效**：回到题型结构，检查是否选错定理层级或漏掉更强/更弱条件。
2. **估计不收敛/不够紧**：恢复被过度丢弃的主阶信息，改用精细放缩、分段或另一标准对象。
3. **形式统一越变越复杂**：撤销最近变换，换统一方向；优先向已知、低阶、单变量或标准形靠拢。
4. **存在性无法证明**：若目标允许，切换到 Cauchy/紧性/单调有界等“不先知道极限值”的路线。
