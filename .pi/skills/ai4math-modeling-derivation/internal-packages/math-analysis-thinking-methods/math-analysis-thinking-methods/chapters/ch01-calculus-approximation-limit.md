# 第 1 讲：微分学和积分学中的思想方法

## Core Idea
把微分与积分都视为“先近似、再借极限达到精确”的同一研究路线。遇到没有直接公式的变化率或整体量问题，先用已知的简单对象近似，再分析误差如何随尺度缩小。

## Frameworks Introduced
- **结构触发器**：当出现以下情形时，优先加载本讲。
- 瞬时变化率、切线、局部变化问题
- 曲边面积、体积、功、质量等整体量
- 直接精确求解没有现成公式
- **核心操作**：按本讲的 `Operational Procedure` 选路；若结构不匹配，返回总控路由，不强套。

## Key Concepts
- **近似研究**
- **局部平均**
- **分割求和**
- **误差控制**
- **极限**
- **抽象**

## Operational Procedure
1. 先把现实问题数学化并识别目标量。
2. 类比最接近的已知简单模型。
3. 构造可计算的近似量：局部平均或分割后的简单量。
4. 找出误差来源，并让局部尺度变小。
5. 若近似量趋于稳定，用极限定义准确值。
6. 去掉具体背景，抽象出导数、定积分等可复用结构。

## Decision Points
- 局部量优先用“段逼近点”；整体量优先用“分割—求和”。
- 近似方案不唯一时，优先简单、可算、误差可控的方案。

## Mental Models
- 把定理看作有“作用对象”的工具：先匹配结构，再执行公式。
- 把证明/计算看作结构变换链：每一步都应降低不确定性或复杂度。

## Anti-patterns
- **避免**：只写“令尺度趋于0”却没有说明近似量。
- **避免**：为了形式上的绝对精确，忽略模型和应用本身已有近似。

## Worked Example
瞬时速度：用包含时刻 t0 的短时间段平均速度近似瞬时速度；缩短时间段后取极限，得到导数结构。曲边面积同理：分割区间、矩形近似、求和，再令最大分割长度趋于0。

## Failure Recovery
1. **工具无效**：回到题型结构，检查是否选错定理层级或漏掉更强/更弱条件。
2. **估计不收敛/不够紧**：恢复被过度丢弃的主阶信息，改用精细放缩、分段或另一标准对象。
3. **形式统一越变越复杂**：撤销最近变换，换统一方向；优先向已知、低阶、单变量或标准形靠拢。
4. **存在性无法证明**：若目标允许，切换到 Cauchy/紧性/单调有界等“不先知道极限值”的路线。

## Key Takeaways
- 先识别本讲的**作用对象特征**，再调用方法。
- 关键技术必须能解释“为什么这一步让结构更简单或更可控”。
- 保留例外、临界情形和失败信号；无法满足前提时应换路线。
