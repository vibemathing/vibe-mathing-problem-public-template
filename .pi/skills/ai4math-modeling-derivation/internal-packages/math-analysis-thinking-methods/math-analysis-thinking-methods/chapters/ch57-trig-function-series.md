# 第 57 讲：含三角函数因子的函数项级数的一致收敛性

## Core Idea
含 sin(nx)/cos(nx) 的函数项级数有三种可利用结构：本身有界、部分和在避开坏点的区间上一致有界、周期性。分别对应 M-test/估计、Dirichlet、以及 Cauchy 反例构造。

## Frameworks Introduced
- **结构触发器**：当出现以下情形时，优先加载本讲。
- 三角因子函数项级数一致收敛
- 区间避开 0 或周期坏点
- 需要证明非一致收敛
- **核心操作**：按本讲的 `Operational Procedure` 选路；若结构不匹配，返回总控路由，不强套。

## Key Concepts
- **三角部分和**
- **一致有界**
- **周期性**
- **Dirichlet**
- **坏点**

## Operational Procedure
1. 先判断三角因子在当前任务中是“次要有界因子”还是“提供抵消的振荡因子”。
2. 若主因子已有可和上界，直接用 |sin|≤1。
3. 若主因子只单调趋0，求三角部分和并在给定区间建立一致界，使用 Dirichlet。
4. 若要判非一致，利用周期性选择 x_n，使一段 Cauchy 片段中的三角项同号且有正下界。
5. 坏点通常在使 sin(x/2) 分母趋0的位置。

## Decision Points
- 区间 [δ,2π-δ] 与包含0的区间性质可完全不同。

## Mental Models
- 把定理看作有“作用对象”的工具：先匹配结构，再执行公式。
- 把证明/计算看作结构变换链：每一步都应降低不确定性或复杂度。

## Anti-patterns
- **避免**：只用 |sin|≤1 导致丢掉关键振荡抵消。
- **避免**：在包含坏点的区间声称三角部分和一致有界。

## Worked Example
在远离0的闭区间，Σ_{k≤n}sin(kx) 可由求和公式统一控制；与单调趋0的 v_n(x) 配合 Dirichlet。若区间逼近0，构造 x_n≈c/n 可破坏一致性。

## Failure Recovery
1. **工具无效**：回到题型结构，检查是否选错定理层级或漏掉更强/更弱条件。
2. **估计不收敛/不够紧**：恢复被过度丢弃的主阶信息，改用精细放缩、分段或另一标准对象。
3. **形式统一越变越复杂**：撤销最近变换，换统一方向；优先向已知、低阶、单变量或标准形靠拢。
4. **存在性无法证明**：若目标允许，切换到 Cauchy/紧性/单调有界等“不先知道极限值”的路线。
