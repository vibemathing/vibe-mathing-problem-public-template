# 第 15 讲：函数极限定义及其应用方法

## Core Idea
函数极限的定义应用以“趋势对趋势”为核心：从函数值控制式中分离自变量控制式。正常极限用放大法，非正常极限用缩小法，并用预控制甩掉局部无关因子。

## Frameworks Introduced
- **结构触发器**：当出现以下情形时，优先加载本讲。
- 用定义证明函数极限
- 极限点、单侧、无穷远、无穷极限
- 复杂有理式需要局部估计
- **核心操作**：按本讲的 `Operational Procedure` 选路；若结构不匹配，返回总控路由，不强套。

## Key Concepts
- **函数极限**
- **δ-ε**
- **预控制**
- **放大法**
- **缩小法**
- **强制形式统一**

## Operational Procedure
1. 先识别自变量趋势与函数趋势的组合。
2. 写出函数值控制对象。
3. 正常极限：上界化简并分离 |x-x0| 或 1/|x|。
4. 非正常极限：下界化简并分离 |x| 或 1/|x-x0|。
5. 先预设局部范围控制分母、常数项等。
6. 由最终简单不等式取 δ 或 G/R。

## Decision Points
- 有限点附近常先限制 |x-x0|<1 等；无穷远常先限制 |x|>1。
- 不同极限类型只改变两个趋势的定量形式，路由逻辑相同。

## Mental Models
- 把定理看作有“作用对象”的工具：先匹配结构，再执行公式。
- 把证明/计算看作结构变换链：每一步都应降低不确定性或复杂度。

## Anti-patterns
- **避免**：直接把含 x 的分母当常数。
- **避免**：只给代数变形，没有把结果转成 δ/ε 或 G/R。

## Worked Example
有理式在 x0 附近：先把所有 x 写成 (x-x0)+x0，强制统一到目标差值；预控制差值使分母有确定正下界，再完成 ε-δ。

## Failure Recovery
1. **工具无效**：回到题型结构，检查是否选错定理层级或漏掉更强/更弱条件。
2. **估计不收敛/不够紧**：恢复被过度丢弃的主阶信息，改用精细放缩、分段或另一标准对象。
3. **形式统一越变越复杂**：撤销最近变换，换统一方向；优先向已知、低阶、单变量或标准形靠拢。
4. **存在性无法证明**：若目标允许，切换到 Cauchy/紧性/单调有界等“不先知道极限值”的路线。
