# 第 39 讲：可积的充要条件的应用方法

## Core Idea
可积性判别把“所有 Riemann 和稳定”转成振幅控制。结构良好的函数用总振幅和趋零；坏点有限/可控时，把坏区间总长度压小。

## Frameworks Introduced
- **结构触发器**：当出现以下情形时，优先加载本讲。
- 证明函数 Riemann 可积
- 函数有少量不连续点
- 直接按定义验证太繁琐
- **核心操作**：按本讲的 `Operational Procedure` 选路；若结构不匹配，返回总控路由，不强套。

## Key Concepts
- **Darboux和**
- **振幅**
- **可积性**
- **坏区间**
- **一致连续**

## Operational Procedure
1. 选择 Darboux/振幅型充要条件。
2. 好函数：用连续/单调/导数界控制每个小区间振幅。
3. 求和得到 ΣωiΔxi，并令网格变细。
4. 有坏点：用小区间包围坏点，使总长度很小。
5. 好区间上用统一连续/局部估计控制振幅。
6. 合并好坏两部分。

## Decision Points
- “坏区间少且总长度小”比逐点控制更适合不连续函数。

## Mental Models
- 把定理看作有“作用对象”的工具：先匹配结构，再执行公式。
- 把证明/计算看作结构变换链：每一步都应降低不确定性或复杂度。

## Anti-patterns
- **避免**：只证明函数有界就断言可积。
- **避免**：坏点附近仍试图用不存在的连续性估计。

## Worked Example
有限个不连续点：给每个坏点挖一个很小区间；坏区间贡献由函数总界×总长度控制，好区间上用一致连续性控制。

## Failure Recovery
1. **工具无效**：回到题型结构，检查是否选错定理层级或漏掉更强/更弱条件。
2. **估计不收敛/不够紧**：恢复被过度丢弃的主阶信息，改用精细放缩、分段或另一标准对象。
3. **形式统一越变越复杂**：撤销最近变换，换统一方向；优先向已知、低阶、单变量或标准形靠拢。
4. **存在性无法证明**：若目标允许，切换到 Cauchy/紧性/单调有界等“不先知道极限值”的路线。
