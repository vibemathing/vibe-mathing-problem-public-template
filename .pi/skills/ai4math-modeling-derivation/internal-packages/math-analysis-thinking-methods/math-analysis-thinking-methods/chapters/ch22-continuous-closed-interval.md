# 第 22 讲：闭区间上连续函数的性质应用方法

## Core Idea
把有限闭区间上的连续函数结论推广到无穷区间时，用“分段验证”：远端由极限控制，剩余有限段由闭区间定理控制。

## Frameworks Introduced
- **结构触发器**：当出现以下情形时，优先加载本讲。
- 无穷区间有界性
- 无穷区间取最值
- 已有无穷远极限
- **核心操作**：按本讲的 `Operational Procedure` 选路；若结构不匹配，返回总控路由，不强套。

## Key Concepts
- **分段法**
- **无穷远极限**
- **闭区间**
- **有界性**
- **最值**

## Operational Procedure
1. 用无穷远极限选分段点 M。
2. 远端用极限得到固定界或与极限值的比较。
3. 有限段 [a,M] 用有界/最值定理。
4. 合并两段的界。
5. 最值问题还要把有限段极值与远端上/下界比较。

## Decision Points
- 要得到固定界时取定 ε。
- 最值存在需要构造远端严格低于/高于某个已知点的比较。

## Mental Models
- 把定理看作有“作用对象”的工具：先匹配结构，再执行公式。
- 把证明/计算看作结构变换链：每一步都应降低不确定性或复杂度。

## Anti-patterns
- **避免**：只证明两段分别有界，却没给统一界。
- **避免**：无限区间直接套闭区间最值定理。

## Worked Example
若 f(x)→A 且连续，取 ε=1 控制 x>M 的尾段；[0,M+1] 上用最值定理，再取两段界的最大。

## Failure Recovery
1. **工具无效**：回到题型结构，检查是否选错定理层级或漏掉更强/更弱条件。
2. **估计不收敛/不够紧**：恢复被过度丢弃的主阶信息，改用精细放缩、分段或另一标准对象。
3. **形式统一越变越复杂**：撤销最近变换，换统一方向；优先向已知、低阶、单变量或标准形靠拢。
4. **存在性无法证明**：若目标允许，切换到 Cauchy/紧性/单调有界等“不先知道极限值”的路线。
