# 第 12 讲：闭区间套定理的应用方法

## Core Idea
闭区间套把区间上的整体属性逐步“套”到一个点上，是整体→局部的工具。构造时每一层都必须保留目标局部性质 P。

## Frameworks Introduced
- **结构触发器**：当出现以下情形时，优先加载本讲。
- 要从整体信息推出存在某个特殊点
- 证明有界数列存在收敛子列
- 需要把无限候选逐层缩小
- **核心操作**：按本讲的 `Operational Procedure` 选路；若结构不匹配，返回总控路由，不强套。

## Key Concepts
- **闭区间套**
- **性质P**
- **整体到局部**
- **子列**
- **等分法**

## Operational Procedure
1. 找出目标点应满足的局部性质 P。
2. 构造一个含有 P 的初始闭区间。
3. 等分区间并选仍保持 P 的子区间。
4. 重复得到嵌套且长度趋零的闭区间。
5. 用闭区间套得到唯一点 ξ。
6. 再从各区间选择对象，构造收敛到 ξ 的子列/序列。

## Decision Points
- 每一层“保留 P”比等分方式本身更重要；二分、三分均可。

## Mental Models
- 把定理看作有“作用对象”的工具：先匹配结构，再执行公式。
- 把证明/计算看作结构变换链：每一步都应降低不确定性或复杂度。

## Anti-patterns
- **避免**：只让区间长度趋零，却没保证每层含目标性质。
- **避免**：得到 ξ 后没有构造与原问题相连的对象。

## Worked Example
Weierstrass 子列定理：从含有数列无穷多项的有界区间开始，每次选仍含无穷多项的子区间；套住点后逐层选下标递增的项。

## Failure Recovery
1. **工具无效**：回到题型结构，检查是否选错定理层级或漏掉更强/更弱条件。
2. **估计不收敛/不够紧**：恢复被过度丢弃的主阶信息，改用精细放缩、分段或另一标准对象。
3. **形式统一越变越复杂**：撤销最近变换，换统一方向；优先向已知、低阶、单变量或标准形靠拢。
4. **存在性无法证明**：若目标允许，切换到 Cauchy/紧性/单调有界等“不先知道极限值”的路线。

## Key Takeaways
- 先识别本讲的**作用对象特征**，再调用方法。
- 关键技术必须能解释“为什么这一步让结构更简单或更可控”。
