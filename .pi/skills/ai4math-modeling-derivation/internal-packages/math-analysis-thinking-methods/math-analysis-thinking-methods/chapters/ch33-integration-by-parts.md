# 第 33 讲：不定积分计算的分部积分法

## Core Idea
分部积分是“微分负担转移”：让求导后本质简化的因子承担 u，让另一个因子承担 dv；目标是新积分结构更简单，并可形成递推或已知结构。

## Frameworks Introduced
- **结构触发器**：当出现以下情形时，优先加载本讲。
- 多项式×指数/三角
- 对数、反三角等本身难积分但易求导
- 需要降低参数/幂次
- **核心操作**：按本讲的 `Operational Procedure` 选路；若结构不匹配，返回总控路由，不强套。

## Key Concepts
- **分部积分**
- **复杂度转移**
- **递推**
- **降阶**

## Operational Procedure
1. 分析两个因子谁求导会降复杂度。
2. 选择 u 与 dv。
3. 先确认 v 易求。
4. 应用 ∫u dv=uv-∫v du。
5. 检查新积分是否本质简化、可递推或可与原式联立。
6. 若更复杂，交换角色或先代换。

## Decision Points
- “求导简化”与“易求原函数”同时满足时最优。

## Mental Models
- 把定理看作有“作用对象”的工具：先匹配结构，再执行公式。
- 把证明/计算看作结构变换链：每一步都应降低不确定性或复杂度。

## Anti-patterns
- **避免**：按口诀机械选 u，导致新积分更难。
- **避免**：忽略边界项或不定积分常数。

## Worked Example
多项式×e^x：多项式作 u，每次求导降阶；e^x dx 作 dv，原函数结构不变，重复分部直至结束。

## Failure Recovery
1. **工具无效**：回到题型结构，检查是否选错定理层级或漏掉更强/更弱条件。
2. **估计不收敛/不够紧**：恢复被过度丢弃的主阶信息，改用精细放缩、分段或另一标准对象。
3. **形式统一越变越复杂**：撤销最近变换，换统一方向；优先向已知、低阶、单变量或标准形靠拢。
4. **存在性无法证明**：若目标允许，切换到 Cauchy/紧性/单调有界等“不先知道极限值”的路线。
