# 第 8 讲：夹逼定理的应用思想

## Core Idea
夹逼定理的操作价值是“化繁为简”：对运算法则失效的复杂或不定项结构，构造容易求极限的上下界。最大/最小因子是常用控制器，但要避免放缩过头。

## Frameworks Introduced
- **结构触发器**：当出现以下情形时，优先加载本讲。
- 有限不定和/积的数列极限
- 每项易算但项数随 n 变化
- 复杂结构无法直接四则运算
- **核心操作**：按本讲的 `Operational Procedure` 选路；若结构不匹配，返回总控路由，不强套。

## Key Concepts
- **夹逼定理**
- **有限不定和**
- **最大因子**
- **最小因子**
- **精细放缩**

## Operational Procedure
1. 识别不定项数量导致的失效。
2. 寻找最大项、最小项或统一可控界。
3. 构造上下界并尽量保留正确量级。
4. 分别计算两端极限。
5. 两端同极限时完成夹逼。
6. 若两端不同，回退并做更精细分组或保留更多结构。

## Decision Points
- 粗放缩后仍应保留原量级；否则需要精细分段或局部比较。

## Mental Models
- 把定理看作有“作用对象”的工具：先匹配结构，再执行公式。
- 把证明/计算看作结构变换链：每一步都应降低不确定性或复杂度。

## Anti-patterns
- **避免**：用最大项乘项数造成上界过大，无法夹到同一极限。
- **避免**：只有一侧界，没有另一侧或符号信息。

## Worked Example
对含 n 项的和，先以最小项和最大项乘 n 得上下界；若上界太粗，保留末端若干项或用可望远镜结构精细控制。

## Failure Recovery
1. **工具无效**：回到题型结构，检查是否选错定理层级或漏掉更强/更弱条件。
2. **估计不收敛/不够紧**：恢复被过度丢弃的主阶信息，改用精细放缩、分段或另一标准对象。
3. **形式统一越变越复杂**：撤销最近变换，换统一方向；优先向已知、低阶、单变量或标准形靠拢。
4. **存在性无法证明**：若目标允许，切换到 Cauchy/紧性/单调有界等“不先知道极限值”的路线。
