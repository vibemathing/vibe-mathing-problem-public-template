# 第 20 讲：函数极限的结构表示定理及其应用方法

## Core Idea
极限结构表示 f(x)=a+α(x), α(x)→0 把抽象函数局部具体化。它适合只有极限条件、却要继续研究导数或局部性质的问题。

## Frameworks Introduced
- **结构触发器**：当出现以下情形时，优先加载本讲。
- 抽象函数只给一个极限条件
- 需要计算点值/导数但无显式表达式
- 要从极限中分离函数信息
- **核心操作**：按本讲的 `Operational Procedure` 选路；若结构不匹配，返回总控路由，不强套。

## Key Concepts
- **无穷小表示**
- **局部表达**
- **化不定为确定**
- **阶的代换**

## Operational Procedure
1. 把给定极限改写成“常数 + 无穷小”。
2. 解出目标函数的局部表达式。
3. 将这个表达式代入导数/其他局部定义。
4. 用已知极限、阶的代换或 Taylor 处理剩余项。
5. 检查只在目标点附近使用该表示。

## Decision Points
- 表示式是局部的，适合局部性质；区间整体问题不要滥用。

## Mental Models
- 把定理看作有“作用对象”的工具：先匹配结构，再执行公式。
- 把证明/计算看作结构变换链：每一步都应降低不确定性或复杂度。

## Anti-patterns
- **避免**：把 α(x) 当成具体可微函数，擅自求导。
- **避免**：在远离极限点处使用局部表示。

## Worked Example
若某比值极限为1，就写成比值=1+α(x)；再解出 f(x) 的局部表达，代回 f(x)-f(0) 的差商。

## Failure Recovery
1. **工具无效**：回到题型结构，检查是否选错定理层级或漏掉更强/更弱条件。
2. **估计不收敛/不够紧**：恢复被过度丢弃的主阶信息，改用精细放缩、分段或另一标准对象。
3. **形式统一越变越复杂**：撤销最近变换，换统一方向；优先向已知、低阶、单变量或标准形靠拢。
4. **存在性无法证明**：若目标允许，切换到 Cauchy/紧性/单调有界等“不先知道极限值”的路线。

- 先识别本讲的**作用对象特征**，再调用方法。
