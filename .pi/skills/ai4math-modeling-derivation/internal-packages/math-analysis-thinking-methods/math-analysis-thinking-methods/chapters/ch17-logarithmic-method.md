# 第 17 讲：对数法求极限的思想方法

## Core Idea
对数法利用复合极限的合法性把幂指结构转成乘积结构：先求 g(x)ln f(x) 的极限，再指数还原。它是形式统一和化繁为简的典型。

## Frameworks Introduced
- **结构触发器**：当出现以下情形时，优先加载本讲。
- f(x)^g(x) 型极限
- 1^∞、0^0、∞^0 等幂指待定型
- 变量代换可简化复合结构
- **核心操作**：按本讲的 `Operational Procedure` 选路；若结构不匹配，返回总控路由，不强套。

## Key Concepts
- **复合极限**
- **变量代换**
- **对数法**
- **幂指结构**

## Operational Procedure
1. 确认底在邻域内为正。
2. 设 h=f^g，取 ln h=g ln f。
3. 计算乘积极限，必要时转成 0/0 或 ∞/∞。
4. 若 ln h→C，则 h→e^C。
5. 若复合函数更自然，先做变量代换，再用已知基本极限。

## Decision Points
- 对数只在正底下直接使用；符号问题需先分支。
- 如果取对数后乘积更复杂，换重要极限或 Taylor。

## Mental Models
- 把定理看作有“作用对象”的工具：先匹配结构，再执行公式。
- 把证明/计算看作结构变换链：每一步都应降低不确定性或复杂度。

## Anti-patterns
- **避免**：忽略底的正性。
- **避免**：只“取对数”却没有说明最后如何还原。

## Worked Example
(1+u(x))^{v(x)}：把指数与 ln(1+u) 合并；若 u→0，可继续利用 ln(1+u)/u→1 将结构统一为 u·v。

## Failure Recovery
1. **工具无效**：回到题型结构，检查是否选错定理层级或漏掉更强/更弱条件。
2. **估计不收敛/不够紧**：恢复被过度丢弃的主阶信息，改用精细放缩、分段或另一标准对象。
3. **形式统一越变越复杂**：撤销最近变换，换统一方向；优先向已知、低阶、单变量或标准形靠拢。
4. **存在性无法证明**：若目标允许，切换到 Cauchy/紧性/单调有界等“不先知道极限值”的路线。

## Key Takeaways
- 先识别本讲的**作用对象特征**，再调用方法。
- 关键技术必须能解释“为什么这一步让结构更简单或更可控”。
