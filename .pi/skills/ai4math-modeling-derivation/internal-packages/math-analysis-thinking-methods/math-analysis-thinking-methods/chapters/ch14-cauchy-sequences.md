# 第 14 讲：Cauchy收敛准则及其应用方法

## Core Idea
Cauchy 准则绕过未知极限值，仅用对象自身的远端片段判断极限存在性。关键是量词独立：N 由 ε 决定，后续的 p、m、n 必须保持任意。

## Frameworks Introduced
- **结构触发器**：当出现以下情形时，优先加载本讲。
- 不知道极限值但要证收敛
- 要证数列发散
- 部分和/尾项结构适合相消或估计
- **核心操作**：按本讲的 `Operational Procedure` 选路；若结构不匹配，返回总控路由，不强套。

## Key Concepts
- **Cauchy片段**
- **基本列**
- **放大法**
- **缩小法**
- **量词独立**

## Operational Procedure
1. 收敛：写 Cauchy 片段 |xn+p-xn|。
2. 上界估计并甩掉 p，得到 G(n)→0。
3. 由 G(N)<ε 选 N，并验证任意 p。
4. 发散：写否定形式，固定 ε0>0。
5. 对任意 N 构造 n>N 与 p，使片段有统一正下界 ε0。
6. 检查 N 是否错误依赖 p。

## Decision Points
- 肯定性用放大法；否定性用缩小/构造法。
- 把下标写成 n 与 n+p 往往比 m,n 更便于利用结构。

## Mental Models
- 把定理看作有“作用对象”的工具：先匹配结构，再执行公式。
- 把证明/计算看作结构变换链：每一步都应降低不确定性或复杂度。

## Anti-patterns
- **避免**：令 N=N(ε,p)。
- **避免**：只验证固定 p，误当成任意 p。
- **避免**：发散证明中 ε0 随 N 变小。

## Worked Example
调和型部分和发散：对任意 N，取 n 与 p 成比例，使一段尾和含足够多同阶项，从而得到不随 N 消失的下界。

## Failure Recovery
1. **工具无效**：回到题型结构，检查是否选错定理层级或漏掉更强/更弱条件。
2. **估计不收敛/不够紧**：恢复被过度丢弃的主阶信息，改用精细放缩、分段或另一标准对象。
3. **形式统一越变越复杂**：撤销最近变换，换统一方向；优先向已知、低阶、单变量或标准形靠拢。
4. **存在性无法证明**：若目标允许，切换到 Cauchy/紧性/单调有界等“不先知道极限值”的路线。
