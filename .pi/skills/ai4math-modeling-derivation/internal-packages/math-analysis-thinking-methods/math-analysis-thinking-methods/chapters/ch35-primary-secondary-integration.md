# 第 35 讲：不定积分计算的主次分析法

## Core Idea
主次分析法把被积式中决定难度的“主要因子”锁定，其他因子围绕它改写；通过代数关系或微分关系，把所有结构统一成主要因子及其微分。

## Frameworks Introduced
- **结构触发器**：当出现以下情形时，优先加载本讲。
- 多个复杂因子耦合
- 普通换元/分部都不明显
- 某个复合因子显著支配结构
- **核心操作**：按本讲的 `Operational Procedure` 选路；若结构不匹配，返回总控路由，不强套。

## Key Concepts
- **主次分析**
- **主因子**
- **配项**
- **微分关系**
- **结构统一**

## Operational Procedure
1. 识别最难、最独特的主因子。
2. 探索其他因子与主因子的代数关系。
3. 探索主因子的导数能产生哪些伴随因子。
4. 必要时拆项、配项、乘除因子，使次要部分写成主因子函数。
5. 以主因子为新变量换元。
6. 若结果仍复杂，重新选择主因子。

## Decision Points
- 主因子选择正确时，变换后变量数和结构类别会明显减少。

## Mental Models
- 把定理看作有“作用对象”的工具：先匹配结构，再执行公式。
- 把证明/计算看作结构变换链：每一步都应降低不确定性或复杂度。

## Anti-patterns
- **避免**：把“主项”仅理解为次数最高项，不看积分中的微分关系。
- **避免**：强行换元后出现无法消去的原变量。

## Worked Example
若复杂表达中出现 t=g(x) 且 g′(x) 可通过其他因子组合产生，就围绕 g 配项，把被积式全部写成 t 与 dt，常会暴露有理分式的基本积分。

## Failure Recovery
1. **工具无效**：回到题型结构，检查是否选错定理层级或漏掉更强/更弱条件。
2. **估计不收敛/不够紧**：恢复被过度丢弃的主阶信息，改用精细放缩、分段或另一标准对象。
3. **形式统一越变越复杂**：撤销最近变换，换统一方向；优先向已知、低阶、单变量或标准形靠拢。
4. **存在性无法证明**：若目标允许，切换到 Cauchy/紧性/单调有界等“不先知道极限值”的路线。

- 先识别本讲的**作用对象特征**，再调用方法。
- 关键技术必须能解释“为什么这一步让结构更简单或更可控”。
