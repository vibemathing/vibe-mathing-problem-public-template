# 第 47 讲：广义积分敛散性判别的试验性方法

## Core Idea
试验性判别法把非负广义积分的敛散性转成“选择合适阶 p 并计算极限”。p 的选择通过参数匹配试验确定；临界情形通常回到底层定义或更精细标准。

## Frameworks Introduced
- **结构触发器**：当出现以下情形时，优先加载本讲。
- 非负函数广义积分敛散性
- 被积函数无穷远/奇点处有明确阶
- 含参数需找临界值
- **核心操作**：按本讲的 `Operational Procedure` 选路；若结构不匹配，返回总控路由，不强套。

## Key Concepts
- **Cauchy判别法**
- **p积分**
- **阶**
- **试验法**
- **临界情形**

## Operational Procedure
1. 选 p-积分作比较标准。
2. 计算 x^p f(x) 的极限（奇点处改用相应距离幂）。
3. 让 p 与极限 0/有限正数/∞ 的结论条件匹配。
4. 存在参数时先求“哪些 p 能给哪类极限”，再与 p-积分收敛阈值求交集。
5. 无交集即该试验失效。
6. 临界参数用定义、积分判别或更精细比较。

## Decision Points
- 有限正极限最稳定，直接同阶。
- 极限0只方便推出收敛；极限∞只方便推出发散，方向要和标准的敛散性匹配。

## Mental Models
- 把定理看作有“作用对象”的工具：先匹配结构，再执行公式。
- 把证明/计算看作结构变换链：每一步都应降低不确定性或复杂度。

## Anti-patterns
- **避免**：先猜 p 后不检查为什么。
- **避免**：在临界情形继续强套失效判别法。

## Worked Example
若 f(x)≈1/[x^λ ln x]，试验 x^p f(x)：λ≠1 时可选 p 得收敛/发散；λ=1 是临界，需要直接计算或换更精细标准。

## Failure Recovery
1. **工具无效**：回到题型结构，检查是否选错定理层级或漏掉更强/更弱条件。
2. **估计不收敛/不够紧**：恢复被过度丢弃的主阶信息，改用精细放缩、分段或另一标准对象。
3. **形式统一越变越复杂**：撤销最近变换，换统一方向；优先向已知、低阶、单变量或标准形靠拢。
4. **存在性无法证明**：若目标允许，切换到 Cauchy/紧性/单调有界等“不先知道极限值”的路线。
