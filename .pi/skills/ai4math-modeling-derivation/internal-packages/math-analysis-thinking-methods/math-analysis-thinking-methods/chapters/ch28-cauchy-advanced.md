# 第 28 讲：再论Cauchy收敛准则及其应用

## Core Idea
复杂 Cauchy 判别的本质是“把尾部任意片段控制成简单结构”。对于级数、函数项级数、广义积分等，先找局部/尾项的统一估计，再决定证明收敛还是构造反例片段。

## Frameworks Introduced
- **结构触发器**：当出现以下情形时，优先加载本讲。
- 级数/积分的 Cauchy 条件
- 抽象极限存在性
- 直接求和或求极限困难
- **核心操作**：按本讲的 `Operational Procedure` 选路；若结构不匹配，返回总控路由，不强套。

## Key Concepts
- **Cauchy准则**
- **尾项**
- **统一估计**
- **望远镜**
- **反例片段**

## Operational Procedure
1. 写出对应对象的 Cauchy 片段。
2. 利用分部、变换、单调性、周期性等简化片段。
3. 肯定：建立与起点相关、与片段长度无关的趋零上界。
4. 否定：选择片段长度与起点的关系，构造固定正下界。
5. 复核所有后续自由变量仍保持任意。

## Decision Points
- 如果估计仍依赖片段长度且无法统一消去，肯定证明失败；尝试否定或改用更强条件。

## Mental Models
- 把定理看作有“作用对象”的工具：先匹配结构，再执行公式。
- 把证明/计算看作结构变换链：每一步都应降低不确定性或复杂度。

## Anti-patterns
- **避免**：只估计单个通项，未估计整个 Cauchy 片段。
- **避免**：把局部收敛误当成统一/整体收敛。

## Worked Example
对于尾和，若能做望远镜变换，直接把任意长片段压成首尾两个边界项；若周期性使每段累积固定正量，则用于发散。

## Failure Recovery
1. **工具无效**：回到题型结构，检查是否选错定理层级或漏掉更强/更弱条件。
2. **估计不收敛/不够紧**：恢复被过度丢弃的主阶信息，改用精细放缩、分段或另一标准对象。
3. **形式统一越变越复杂**：撤销最近变换，换统一方向；优先向已知、低阶、单变量或标准形靠拢。
4. **存在性无法证明**：若目标允许，切换到 Cauchy/紧性/单调有界等“不先知道极限值”的路线。
