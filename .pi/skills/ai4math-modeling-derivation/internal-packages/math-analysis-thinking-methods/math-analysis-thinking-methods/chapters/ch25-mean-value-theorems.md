# 第 25 讲：微分中值定理的结构分析及应用方法

## Core Idea
微分中值定理连接“函数差值/增量”与“某中值点导数”。应用时抓住两个分离结构：中值点与端点分离、两个端点彼此分离。

## Frameworks Introduced
- **结构触发器**：当出现以下情形时，优先加载本讲。
- 中值/介值型等式
- 函数差值估计
- 需要把函数信息转成导数信息或反过来
- **核心操作**：按本讲的 `Operational Procedure` 选路；若结构不匹配，返回总控路由，不强套。

## Key Concepts
- **Lagrange中值定理**
- **Cauchy中值定理**
- **差值结构**
- **双中值点**

## Operational Procedure
1. 判断 Lagrange 还是 Cauchy 形式更贴近。
2. 把目标等式改写成端点差值比。
3. 分离中值点与端点。
4. 若右端含两个不同函数差值，构造 F,G 用 Cauchy 中值定理。
5. 双中值点问题：对两个相关函数分别用中值定理，用共同的端点差值比连接。
6. 完成后检查所有区间条件。

## Decision Points
- 一端只含 ξ、一端只含 a,b 时，中值结构最明显。
- 含两类端点差值比时优先 Cauchy。

## Mental Models
- 把定理看作有“作用对象”的工具：先匹配结构，再执行公式。
- 把证明/计算看作结构变换链：每一步都应降低不确定性或复杂度。

## Anti-patterns
- **避免**：把 ξ 当成可预先指定的点。
- **避免**：同一个证明里默认两次中值定理得到同一 ξ。

## Worked Example
要证明含 f(ξ)、f′(ξ) 的关系，先通过平方差或插项把右端变成 [f(b)-f(a)]/(b-a) 一类共同桥梁，再分别应用中值定理。

## Failure Recovery
1. **工具无效**：回到题型结构，检查是否选错定理层级或漏掉更强/更弱条件。
2. **估计不收敛/不够紧**：恢复被过度丢弃的主阶信息，改用精细放缩、分段或另一标准对象。
3. **形式统一越变越复杂**：撤销最近变换，换统一方向；优先向已知、低阶、单变量或标准形靠拢。
4. **存在性无法证明**：若目标允许，切换到 Cauchy/紧性/单调有界等“不先知道极限值”的路线。
