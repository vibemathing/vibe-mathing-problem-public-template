# 第 38 讲：定积分定义的结构分析方法

## Core Idea
利用定积分定义解决题目时，关键是识别 Riemann 和的“标准结构”：小区间宽度×样点函数值，并把有限不定和的下标结构映射成区间与样点。

## Frameworks Introduced
- **结构触发器**：当出现以下情形时，优先加载本讲。
- 有限和极限转定积分
- 需要从定义识别积分区间/函数
- 证明某和是 Riemann 和
- **核心操作**：按本讲的 `Operational Procedure` 选路；若结构不匹配，返回总控路由，不强套。

## Key Concepts
- **定积分定义**
- **Riemann和**
- **样点**
- **标准化**

## Operational Procedure
1. 把求和写成 Σ f(ξi)Δxi。
2. 从 Δxi 识别区间长度与分割。
3. 从 ξi 的形式识别样点和变量代换。
4. 检查最大分割长度→0。
5. 若有附加因子，先形式统一到样点函数。
6. 利用定义得到积分。

## Decision Points
- 等分结构常给 Δx=(b-a)/n；但不必拘泥于等分。

## Mental Models
- 把定理看作有“作用对象”的工具：先匹配结构，再执行公式。
- 把证明/计算看作结构变换链：每一步都应降低不确定性或复杂度。

## Anti-patterns
- **避免**：只看 Σ 符号就强行凑积分。
- **避免**：样点不落在对应小区间。

## Worked Example
形如 (1/n)Σ f(i/n) 的极限，直接识别为 [0,1] 等分的右端点 Riemann 和；复杂权重需先变形确认对应 Δx。

## Failure Recovery
1. **工具无效**：回到题型结构，检查是否选错定理层级或漏掉更强/更弱条件。
2. **估计不收敛/不够紧**：恢复被过度丢弃的主阶信息，改用精细放缩、分段或另一标准对象。
3. **形式统一越变越复杂**：撤销最近变换，换统一方向；优先向已知、低阶、单变量或标准形靠拢。
4. **存在性无法证明**：若目标允许，切换到 Cauchy/紧性/单调有界等“不先知道极限值”的路线。
