# 第 59 讲：幂级数的和函数的计算方法

## Core Idea
幂级数求和从两个几何级数基本公式出发，通过逐项求导/积分在“系数结构”和“1 或 (-1)^n”之间往返；选择方向取决于系数中 n 或 1/(n+1) 等因子。

## Frameworks Introduced
- **结构触发器**：当出现以下情形时，优先加载本讲。
- 求幂级数和函数
- 系数含 n、n²、1/(n+1)
- 可由几何级数衍生
- **核心操作**：按本讲的 `Operational Procedure` 选路；若结构不匹配，返回总控路由，不强套。

## Key Concepts
- **幂级数**
- **和函数**
- **逐项求导**
- **逐项积分**
- **几何级数**

## Operational Procedure
1. 先求收敛区间。
2. 识别系数相对几何级数多了什么。
3. 含 n 因子：把它看作求导产生，或对目标积分来消去。
4. 含 1/(n+1)：把它看作积分产生，或对目标求导来消去。
5. 经过逐项操作化为几何级数求和。
6. 对和函数做反向积分/求导，并用初值确定常数。
7. 单独检查端点。

## Decision Points
- 可以从目标出发，也可以从基本公式出发；选步骤更少者。

## Mental Models
- 把定理看作有“作用对象”的工具：先匹配结构，再执行公式。
- 把证明/计算看作结构变换链：每一步都应降低不确定性或复杂度。

## Anti-patterns
- **避免**：只在开收敛区间内推导后忘记端点。
- **避免**：逐项求导/积分后不更新收敛域或常数。

## Worked Example
Σ x^n/(n+1)：先求导/或从 1/(1-x) 逐项积分，得到 -ln(1-x)/x 一类表达，并用 x=0 的连续延拓补值。

## Failure Recovery
1. **工具无效**：回到题型结构，检查是否选错定理层级或漏掉更强/更弱条件。
2. **估计不收敛/不够紧**：恢复被过度丢弃的主阶信息，改用精细放缩、分段或另一标准对象。
3. **形式统一越变越复杂**：撤销最近变换，换统一方向；优先向已知、低阶、单变量或标准形靠拢。
4. **存在性无法证明**：若目标允许，切换到 Cauchy/紧性/单调有界等“不先知道极限值”的路线。

## Key Takeaways
- 先识别本讲的**作用对象特征**，再调用方法。
- 关键技术必须能解释“为什么这一步让结构更简单或更可控”。
- 保留例外、临界情形和失败信号；无法满足前提时应换路线。
