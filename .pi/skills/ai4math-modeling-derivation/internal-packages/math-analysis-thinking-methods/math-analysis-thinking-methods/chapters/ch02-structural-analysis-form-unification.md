# 第 2 讲：结构分析和形式统一的思想方法

## Core Idea
全书的总控方法：先用结构分析解决“用什么理论”，再用形式统一解决“怎么用”。结构匹配决定工具，标准化决定技术路线。

## Frameworks Introduced
- **结构触发器**：当出现以下情形时，优先加载本讲。
- 不知道该选哪个定理/公式
- 知道定理但不会把题目接到定理上
- 证明或计算中出现多个不同结构
- **核心操作**：按本讲的 `Operational Procedure` 选路；若结构不匹配，返回总控路由，不强套。

## Key Concepts
- **结构分析**
- **形式统一**
- **作用对象**
- **标准形**
- **类比已知**
- **技术路线**

## Operational Procedure
1. 分析整个题型与目标结论。
2. 挖掘条件、结论中的关键结构特征。
3. 与已知定理/结论的作用对象类比，选最匹配工具。
4. 比较题目与定理在条件和结论形式上的差异。
5. 用代换、插项、分解、乘因子、分段、变形等把形式统一到标准结构。
6. 执行定理并检查所有前提。

## Decision Points
- 先“大结构”后“小结构”：先定题型，再处理局部形式。
- 多个工具都能用时，选标准化成本最低、后续结构最简单者。

## Mental Models
- 把定理看作有“作用对象”的工具：先匹配结构，再执行公式。
- 把证明/计算看作结构变换链：每一步都应降低不确定性或复杂度。

## Anti-patterns
- **避免**：直接套公式，无法解释为什么可用。
- **避免**：为了统一形式引入更复杂或不可控的新项。
- **避免**：只完成结构匹配，没有验证定理条件。

## Worked Example
求幂指型极限时，先识别 (1+0)^∞ 结构，再把底统一成 1+u，把指数统一成 u 的倒数乘常量；中值问题则先把中值点与端点、两个端点彼此分离。

## Failure Recovery
1. **工具无效**：回到题型结构，检查是否选错定理层级或漏掉更强/更弱条件。
2. **估计不收敛/不够紧**：恢复被过度丢弃的主阶信息，改用精细放缩、分段或另一标准对象。
3. **形式统一越变越复杂**：撤销最近变换，换统一方向；优先向已知、低阶、单变量或标准形靠拢。
4. **存在性无法证明**：若目标允许，切换到 Cauchy/紧性/单调有界等“不先知道极限值”的路线。

## SELF_CHECK
- [ ] 题型和目标是否已经结构化，而非只按关键词选定理？
- [ ] 所选方法的前提是否逐项满足？
- [ ] 变形后是否真正更接近已知标准结构？
- [ ] 量词、估计方向、区间/端点/符号条件是否保持正确？
- [ ] 若首选路线失败，是否根据失败原因切换到更匹配的方法？

## Key Takeaways
- 先识别本讲的**作用对象特征**，再调用方法。
- 关键技术必须能解释“为什么这一步让结构更简单或更可控”。
- 保留例外、临界情形和失败信号；无法满足前提时应换路线。
