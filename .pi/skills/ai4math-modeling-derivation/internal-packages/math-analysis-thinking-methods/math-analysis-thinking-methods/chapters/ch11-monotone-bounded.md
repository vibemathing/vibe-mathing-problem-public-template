# 第 11 讲：单调有界收敛定理的应用方法

## Core Idea
处理迭代数列时先“预判”单调方向和可能的界，再分别验证单调性与有界性；收敛后才把极限代回递推式。

## Frameworks Introduced
- **结构触发器**：当出现以下情形时，优先加载本讲。
- 递推/迭代数列极限
- 题目要求证明收敛并求极限
- 单调有界定理可用但方向不明
- **核心操作**：按本讲的 `Operational Procedure` 选路；若结构不匹配，返回总控路由，不强套。

## Key Concepts
- **预判法**
- **固定点**
- **单调性**
- **有界性**
- **迭代数列**

## Operational Procedure
1. 假设收敛，解固定点方程得到候选极限。
2. 算前几项并与候选极限比较，预判单调方向与界。
3. 用差值法、比值法、归纳法或连续化验证单调性。
4. 用归纳或递推不等式验证界。
5. 按依赖关系决定先证单调还是先证界。
6. 由单调有界得到收敛，再代回递推式筛选候选根。

## Decision Points
- 若单调性证明需要已知界，先证界；若界来自单调性，反之。
- 固定点方程只给候选，必须结合界/单调性排除伪根。

## Mental Models
- 把定理看作有“作用对象”的工具：先匹配结构，再执行公式。
- 把证明/计算看作结构变换链：每一步都应降低不确定性或复杂度。

## Anti-patterns
- **避免**：一上来就把极限代入递推式，跳过存在性。
- **避免**：预判结果当成证明。

## Worked Example
递推 xn+1=F(xn)：先由 α=F(α) 找候选，再用 xn+1-xn 或 F 的单调性验证方向，用归纳证明 xn 被候选或其他常数夹住。

## Failure Recovery
1. **工具无效**：回到题型结构，检查是否选错定理层级或漏掉更强/更弱条件。
2. **估计不收敛/不够紧**：恢复被过度丢弃的主阶信息，改用精细放缩、分段或另一标准对象。
3. **形式统一越变越复杂**：撤销最近变换，换统一方向；优先向已知、低阶、单变量或标准形靠拢。
4. **存在性无法证明**：若目标允许，切换到 Cauchy/紧性/单调有界等“不先知道极限值”的路线。

- 先识别本讲的**作用对象特征**，再调用方法。
- 关键技术必须能解释“为什么这一步让结构更简单或更可控”。
