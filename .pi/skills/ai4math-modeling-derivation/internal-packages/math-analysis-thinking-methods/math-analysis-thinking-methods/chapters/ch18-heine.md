# 第 18 讲：Heine归结定理中的数学思想

## Core Idea
Heine 归结定理把函数极限与所有趋近该点的数列极限连接起来。其最强实用场景是“以部分否定全体”：找一条坏数列或两条给出不同像极限的数列即可否定函数极限。

## Frameworks Introduced
- **结构触发器**：当出现以下情形时，优先加载本讲。
- 证明函数极限不存在
- 振荡/稠密分段函数
- 把数列极限转成函数极限
- **核心操作**：按本讲的 `Operational Procedure` 选路；若结构不匹配，返回总控路由，不强套。

## Key Concepts
- **Heine定理**
- **全体与部分**
- **反例序列**
- **连续化**

## Operational Procedure
1. 非存在性：分析函数造成不稳定的结构特征。
2. 按周期、分段、符号等构造趋向同一点的序列。
3. 若一条像序列不收敛，或两条像序列极限不同，结束。
4. 数列极限计算：将 n 连续化为 x，先算函数极限，再由 Heine 返回。

## Decision Points
- 构造点列必须利用函数的具体结构：周期性、分段稠密性等。

## Mental Models
- 把定理看作有“作用对象”的工具：先匹配结构，再执行公式。
- 把证明/计算看作结构变换链：每一步都应降低不确定性或复杂度。

## Anti-patterns
- **避免**：试图验证“所有数列”来证明存在，造成无限验证。
- **避免**：构造的序列没有趋向目标点。

## Worked Example
sin(1/x) 在0附近：选择使 1/x 落在不同相位的两条序列，函数值分别趋向不同常数，立即否定极限。

## Failure Recovery
1. **工具无效**：回到题型结构，检查是否选错定理层级或漏掉更强/更弱条件。
2. **估计不收敛/不够紧**：恢复被过度丢弃的主阶信息，改用精细放缩、分段或另一标准对象。
3. **形式统一越变越复杂**：撤销最近变换，换统一方向；优先向已知、低阶、单变量或标准形靠拢。
4. **存在性无法证明**：若目标允许，切换到 Cauchy/紧性/单调有界等“不先知道极限值”的路线。
