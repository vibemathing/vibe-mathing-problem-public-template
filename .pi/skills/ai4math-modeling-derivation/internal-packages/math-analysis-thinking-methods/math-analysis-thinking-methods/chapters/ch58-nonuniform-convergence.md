# 第 58 讲：函数项级数的非一致收敛性的研究方法

## Core Idea
证明非一致收敛应按“从简单必要条件到强工具”排序：先查端点发散，再查通项不能一致趋0，再用和函数性质的逆否，最后才上 Cauchy 准则构造坏片段。

## Frameworks Introduced
- **结构触发器**：当出现以下情形时，优先加载本讲。
- 证明函数项级数非一致收敛
- 逐点收敛但怀疑不一致
- 坏点位于端点或无穷远
- **核心操作**：按本讲的 `Operational Procedure` 选路；若结构不匹配，返回总控路由，不强套。

## Key Concepts
- **端点发散**
- **必要条件**
- **坏点**
- **逆否**
- **一致Cauchy**

## Operational Procedure
1. 先检查端点极限对应的数项级数是否发散。
2. 检查必要条件：sup|u_n| 是否不趋0；构造 x_n 逼近坏点。
3. 若部分和/和函数可算，检查连续性、逐项积分/求导结论是否被破坏。
4. 前述失效时写一致 Cauchy 准则的否定。
5. 对任意 N 构造 n,p,x，使片段有固定正下界。

## Decision Points
- 坏点通常在区间端点、无穷远或三角部分和失控处；x_n 应朝坏点走。

## Mental Models
- 把定理看作有“作用对象”的工具：先匹配结构，再执行公式。
- 把证明/计算看作结构变换链：每一步都应降低不确定性或复杂度。

## Anti-patterns
- **避免**：一开始就做最复杂 Cauchy 构造。
- **避免**：用一个固定 x 的失败来证明不一致，但该点并不随 n 暴露统一性问题。

## Worked Example
nx(1-x)^n：取 x_n≈1/(n+1) 命中每个 n 的最大点，通项的最大值不趋0，从一致收敛必要条件直接否定。

## Failure Recovery
1. **工具无效**：回到题型结构，检查是否选错定理层级或漏掉更强/更弱条件。
2. **估计不收敛/不够紧**：恢复被过度丢弃的主阶信息，改用精细放缩、分段或另一标准对象。
3. **形式统一越变越复杂**：撤销最近变换，换统一方向；优先向已知、低阶、单变量或标准形靠拢。
4. **存在性无法证明**：若目标允许，切换到 Cauchy/紧性/单调有界等“不先知道极限值”的路线。
