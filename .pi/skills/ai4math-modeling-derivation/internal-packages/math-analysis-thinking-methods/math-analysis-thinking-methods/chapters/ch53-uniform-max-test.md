# 第 53 讲：函数项级数一致收敛性的最值判别法

## Core Idea
一致收敛的最值/确界判别把“对所有 x 的统一误差”转成一个数列 α_n=sup_x|error|。于是最难的统一性问题变成函数最值计算与普通数列收敛。

## Frameworks Introduced
- **结构触发器**：当出现以下情形时，优先加载本讲。
- 具体函数列一致收敛
- 函数项级数可找优级数
- 需要判一致或非一致
- **核心操作**：按本讲的 `Operational Procedure` 选路；若结构不匹配，返回总控路由，不强套。

## Key Concepts
- **一致收敛**
- **确界判别**
- **Weierstrass判别**
- **最大值**
- **优级数**

## Operational Procedure
1. 函数列先求点态极限 S(x)。
2. 对固定 n，研究 h_n(x)=|S_n(x)-S(x)|。
3. 求 sup/最大值 α_n。
4. 检查 α_n→0；若不趋0则非一致。
5. 函数项级数：对每项求统一上界 a_n，并判 Σa_n 收敛。
6. 结构复杂时，用估计法代替精确最值。

## Decision Points
- 函数列确界法可判是也可判非；M-test 主要判是。
- 复杂结构可先形式统一，再用极限保序性构造简单上界。

## Mental Models
- 把定理看作有“作用对象”的工具：先匹配结构，再执行公式。
- 把证明/计算看作结构变换链：每一步都应降低不确定性或复杂度。

## Anti-patterns
- **避免**：只看每个固定 x 的误差趋0，就误判一致收敛。
- **避免**：最大点随 n 变化却只在固定点检查。

## Worked Example
nx(1-x)^n 在 [0,1]：先求最大点 x=1/(n+1)，最大值不趋0，因此虽逐点趋0，却非一致。

## Failure Recovery
1. **工具无效**：回到题型结构，检查是否选错定理层级或漏掉更强/更弱条件。
2. **估计不收敛/不够紧**：恢复被过度丢弃的主阶信息，改用精细放缩、分段或另一标准对象。
3. **形式统一越变越复杂**：撤销最近变换，换统一方向；优先向已知、低阶、单变量或标准形靠拢。
4. **存在性无法证明**：若目标允许，切换到 Cauchy/紧性/单调有界等“不先知道极限值”的路线。
