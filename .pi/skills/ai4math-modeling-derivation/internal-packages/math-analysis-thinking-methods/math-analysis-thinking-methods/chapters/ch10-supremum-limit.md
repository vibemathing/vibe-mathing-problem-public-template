# 第 10 讲：确界与极限的关系及应用方法

## Core Idea
确界的极限表示把抽象的 sup/inf 转成数列极限，从而把“集合的极值边界”问题交给成熟的极限运算和保序理论。

## Frameworks Introduced
- **结构触发器**：当出现以下情形时，优先加载本讲。
- 证明两个集合的确界关系
- 确界定义直接使用很繁琐
- 要把抽象边界具体化为可计算序列
- **核心操作**：按本讲的 `Operational Procedure` 选路；若结构不匹配，返回总控路由，不强套。

## Key Concepts
- **确界**
- **极限表示**
- **逼近点列**
- **保序性**

## Operational Procedure
1. 给每个确界选逼近它的点列。
2. 把集合间的代数/序关系转成点列关系。
3. 利用极限运算或保序性得到确界关系。
4. 不等式只需从更简单的一端出发。

## Decision Points
- 等式常需双向比较；不等式优先从结构更简单的一端构造逼近序列。

## Mental Models
- 把定理看作有“作用对象”的工具：先匹配结构，再执行公式。
- 把证明/计算看作结构变换链：每一步都应降低不确定性或复杂度。

## Anti-patterns
- **避免**：把 sup 当成一定能取到的最大值。
- **避免**：只构造一条逼近序列却要证明双向等式。

## Worked Example
证明 sup(xn+yn)≤sup xn+sup yn：选逼近 sup(xn+yn) 的子列，再用各分量的上确界控制其极限。

## Failure Recovery
1. **工具无效**：回到题型结构，检查是否选错定理层级或漏掉更强/更弱条件。
2. **估计不收敛/不够紧**：恢复被过度丢弃的主阶信息，改用精细放缩、分段或另一标准对象。
3. **形式统一越变越复杂**：撤销最近变换，换统一方向；优先向已知、低阶、单变量或标准形靠拢。
4. **存在性无法证明**：若目标允许，切换到 Cauchy/紧性/单调有界等“不先知道极限值”的路线。
