# 第 48 讲：广义积分的计算方法

## Core Idea
广义积分计算先用定义把无穷/奇点转成极限；若原函数难求，分段后用换元建立两段关系，或把未知积分形式统一到已知积分。

## Frameworks Introduced
- **结构触发器**：当出现以下情形时，优先加载本讲。
- 计算具体广义积分
- 同时有无穷限与无界奇点
- 已知一个相关积分求另一个
- **核心操作**：按本讲的 `Operational Procedure` 选路；若结构不匹配，返回总控路由，不强套。

## Key Concepts
- **定义法**
- **分段**
- **倒代换**
- **形式统一**
- **广义点**

## Operational Procedure
1. 先确认各广义点并分别定义极限。
2. 原函数可算时直接定义法。
3. 原函数难算：在自然点分段。
4. 寻找倒代换、对称、平移或三角变换把一段转成另一段。
5. 若给已知积分，比较结构并用分部/积化和差等统一到已知式。
6. 最后检查每个广义端的收敛性，避免非法合并发散积分。

## Decision Points
- 同时含两类广义点时分开处理后再合并。
- 未知→已知优先看分母降幂、三角积化和差等结构转换。

## Mental Models
- 把定理看作有“作用对象”的工具：先匹配结构，再执行公式。
- 把证明/计算看作结构变换链：每一步都应降低不确定性或复杂度。

## Anti-patterns
- **避免**：在收敛性未确认前拆成两个各自发散的积分。
- **避免**：换元跨越奇点却未重新分段。

## Worked Example
对 ∫_0^∞ ln x/(1+x²) 类积分，可在1处分段，第二段用 x=1/t 变回 (0,1)，两段结构联立后简化。

## Failure Recovery
1. **工具无效**：回到题型结构，检查是否选错定理层级或漏掉更强/更弱条件。
2. **估计不收敛/不够紧**：恢复被过度丢弃的主阶信息，改用精细放缩、分段或另一标准对象。
3. **形式统一越变越复杂**：撤销最近变换，换统一方向；优先向已知、低阶、单变量或标准形靠拢。
4. **存在性无法证明**：若目标允许，切换到 Cauchy/紧性/单调有界等“不先知道极限值”的路线。

## Key Takeaways
- 先识别本讲的**作用对象特征**，再调用方法。
- 关键技术必须能解释“为什么这一步让结构更简单或更可控”。
