# 第 9 讲：Stolz定理及其应用

## Core Idea
Stolz 定理把数列商的待定型极限转成相邻差之比。使用它的判据不是“看到分式”，而是“做差后结构明显更简单”。

## Frameworks Introduced
- **结构触发器**：当出现以下情形时，优先加载本讲。
- 数列 0/0 或 ∞/∞ 型商极限
- 分子是有限不定和
- 阶乘/递推结构相邻项可大量抵消
- **核心操作**：按本讲的 `Operational Procedure` 选路；若结构不匹配，返回总控路由，不强套。

## Key Concepts
- **Stolz定理**
- **待定型**
- **差分**
- **有限不定和**
- **结构简化**

## Operational Procedure
1. 确认 Stolz 的单调/趋向条件满足。
2. 比较原序列与相邻差的复杂度。
3. 选择适合的 0/0 或 ∞/∞ 版本。
4. 计算 Δxn/Δyn。
5. 若差分后仍复杂，先做结构简化或改写再用 Stolz。
6. 检查反向推理是否被误用。

## Decision Points
- 相邻差能消掉求和或递推累积时优先。
- 如果做差更复杂，换夹逼、单调有界或其他方法。

## Mental Models
- 把定理看作有“作用对象”的工具：先匹配结构，再执行公式。
- 把证明/计算看作结构变换链：每一步都应降低不确定性或复杂度。

## Anti-patterns
- **避免**：从 xn/yn 有极限反推差比一定有极限。
- **避免**：只因是分式就机械套 Stolz。

## Worked Example
分子为 Σ k a^k 时，相邻差只剩新添的一项，结构显著简化；再用主项控制求差比极限。

## Failure Recovery
1. **工具无效**：回到题型结构，检查是否选错定理层级或漏掉更强/更弱条件。
2. **估计不收敛/不够紧**：恢复被过度丢弃的主阶信息，改用精细放缩、分段或另一标准对象。
3. **形式统一越变越复杂**：撤销最近变换，换统一方向；优先向已知、低阶、单变量或标准形靠拢。
4. **存在性无法证明**：若目标允许，切换到 Cauchy/紧性/单调有界等“不先知道极限值”的路线。
