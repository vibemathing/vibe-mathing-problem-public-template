# 第 46 讲：含三角函数的广义积分方法

## Core Idea
含三角振荡因子的广义积分要分别利用三角函数的有界性、周期性和“积分部分和”有界性。绝对收敛多靠比较；条件收敛多靠 Dirichlet；发散/非绝对则利用周期累计。

## Frameworks Introduced
- **结构触发器**：当出现以下情形时，优先加载本讲。
- sin/cos×衰减因子广义积分
- 判断绝对/条件收敛
- 周期零点导致无界被积函数
- **核心操作**：按本讲的 `Operational Procedure` 选路；若结构不匹配，返回总控路由，不强套。

## Key Concepts
- **振荡**
- **周期性**
- **Dirichlet判别**
- **绝对收敛**
- **条件收敛**

## Operational Procedure
1. 先检查绝对值后能否被可积正函数控制。
2. 若不能，检查振荡因子的原函数/积分片段是否一致有界。
3. 配合单调趋零因子使用 Dirichlet。
4. 要证非绝对/发散，按周期分段并寻找每周期的正贡献。
5. 结构不标准时，用代换/恒等式直接转化；不能直接转化则化用上述机制。
6. 奇点与周期共存时逐周期精细估计。

## Decision Points
- 振荡能抵消，绝对值会消除抵消；因此条件收敛与绝对收敛要分开。

## Mental Models
- 把定理看作有“作用对象”的工具：先匹配结构，再执行公式。
- 把证明/计算看作结构变换链：每一步都应降低不确定性或复杂度。

## Anti-patterns
- **避免**：看到 sin/cos 就断言收敛。
- **避免**：用有界性证明绝对收敛却忽略衰减因子不可积。

## Worked Example
∫ sin x /x^α：绝对值比较决定绝对收敛阈值；若衰减单调趋0但绝对值不可积，可用 Dirichlet 的振荡抵消判断条件收敛。

## Failure Recovery
1. **工具无效**：回到题型结构，检查是否选错定理层级或漏掉更强/更弱条件。
2. **估计不收敛/不够紧**：恢复被过度丢弃的主阶信息，改用精细放缩、分段或另一标准对象。
3. **形式统一越变越复杂**：撤销最近变换，换统一方向；优先向已知、低阶、单变量或标准形靠拢。
4. **存在性无法证明**：若目标允许，切换到 Cauchy/紧性/单调有界等“不先知道极限值”的路线。
