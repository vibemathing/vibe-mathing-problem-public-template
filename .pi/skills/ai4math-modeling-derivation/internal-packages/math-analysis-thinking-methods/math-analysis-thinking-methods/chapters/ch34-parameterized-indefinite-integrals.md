# 第 34 讲：含n结构的不定积分的计算方法

## Core Idea
含整数参数 n 的不定积分常靠递推解决。先确定 n 出现在哪个结构位置，再设计能把 n→n-1/n-2 的分部、恒等变换或代换。

## Frameworks Introduced
- **结构触发器**：当出现以下情形时，优先加载本讲。
- 积分含 x^n、sin^n、cos^n 等参数
- 需要给递推公式
- 直接求一般 n 原函数困难
- **核心操作**：按本讲的 `Operational Procedure` 选路；若结构不匹配，返回总控路由，不强套。

## Key Concepts
- **递推积分**
- **参数降阶**
- **初值**
- **奇偶性**

## Operational Procedure
1. 定位参数所在因子。
2. 寻找求导/恒等式可降低参数的操作。
3. 做分部或恒等变换，尽量保留原类型积分。
4. 整理得到 I_n 与 I_{n-k} 的递推。
5. 给出足够的初始值。
6. 检查奇偶分支是否需要不同初值。

## Decision Points
- 参数在幂指数常用求导降幂；参数在三角幂常配合恒等式与分部。

## Mental Models
- 把定理看作有“作用对象”的工具：先匹配结构，再执行公式。
- 把证明/计算看作结构变换链：每一步都应降低不确定性或复杂度。

## Anti-patterns
- **避免**：递推式出现比原题更复杂的新积分。
- **避免**：没有给终止递推所需初值。

## Worked Example
对 sin^n x 类积分，拆出 sin^{n-1}x·sin x，分部并用 cos²=1-sin²，把结果重新写回 I_n 与 I_{n-2}。

## Failure Recovery
1. **工具无效**：回到题型结构，检查是否选错定理层级或漏掉更强/更弱条件。
2. **估计不收敛/不够紧**：恢复被过度丢弃的主阶信息，改用精细放缩、分段或另一标准对象。
3. **形式统一越变越复杂**：撤销最近变换，换统一方向；优先向已知、低阶、单变量或标准形靠拢。
4. **存在性无法证明**：若目标允许，切换到 Cauchy/紧性/单调有界等“不先知道极限值”的路线。

## Key Takeaways
- 先识别本讲的**作用对象特征**，再调用方法。
- 关键技术必须能解释“为什么这一步让结构更简单或更可控”。
- 保留例外、临界情形和失败信号；无法满足前提时应换路线。
