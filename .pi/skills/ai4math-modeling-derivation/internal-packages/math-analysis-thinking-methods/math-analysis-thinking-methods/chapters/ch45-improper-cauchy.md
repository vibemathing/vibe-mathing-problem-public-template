# 第 45 讲：无穷限广义积分的Cauchy收敛准则及应用方法

## Core Idea
无穷限广义积分的 Cauchy 准则说：充分远处的任意积分片段都能任意小。它把广义积分收敛性与函数远端行为直接连接，并导出比较、Dirichlet、Abel 等判别思想。

## Frameworks Introduced
- **结构触发器**：当出现以下情形时，优先加载本讲。
- 广义积分收敛性存在判断
- 不知道积分值
- 需要利用尾积分/余项
- **核心操作**：按本讲的 `Operational Procedure` 选路；若结构不匹配，返回总控路由，不强套。

## Key Concepts
- **广义积分**
- **Cauchy准则**
- **尾积分**
- **余项**
- **远端片段**

## Operational Procedure
1. 写出远端片段 ∫_{A′}^{A″}f。
2. 肯定：给出只依赖较小端点的趋零上界。
3. 或用余项 ∫_A^∞f 的趋零形式。
4. 否定：对任意远端阈值构造一个片段，其积分绝对值有固定下界。
5. 若 f 有振荡，考虑分部或周期片段。

## Decision Points
- 余项形式适合估计误差；双端点形式适合判别本身。

## Mental Models
- 把定理看作有“作用对象”的工具：先匹配结构，再执行公式。
- 把证明/计算看作结构变换链：每一步都应降低不确定性或复杂度。

## Anti-patterns
- **避免**：只证明单个尾积分在某条路径小，没有任意端点控制。
- **避免**：绝对值放置错误，混淆绝对收敛与条件收敛。

## Worked Example
比较判别法可由 Cauchy 片段直接推出：若 |f|≤g 且 g 的尾片段任意小，则 f 的尾片段也任意小。

## Failure Recovery
1. **工具无效**：回到题型结构，检查是否选错定理层级或漏掉更强/更弱条件。
2. **估计不收敛/不够紧**：恢复被过度丢弃的主阶信息，改用精细放缩、分段或另一标准对象。
3. **形式统一越变越复杂**：撤销最近变换，换统一方向；优先向已知、低阶、单变量或标准形靠拢。
4. **存在性无法证明**：若目标允许，切换到 Cauchy/紧性/单调有界等“不先知道极限值”的路线。
