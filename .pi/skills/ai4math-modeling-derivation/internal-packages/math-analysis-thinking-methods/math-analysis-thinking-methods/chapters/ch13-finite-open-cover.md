# 第 13 讲：有限开覆盖定理及其应用方法

## Core Idea
有限开覆盖是局部→整体的工具：先在每一点得到匹配目标结构的局部性质，再用闭区间紧性把无限多个局部控制压成有限个，从而取得统一常数。

## Frameworks Introduced
- **结构触发器**：当出现以下情形时，优先加载本讲。
- 由逐点连续推出一致连续
- 每点都有局部半径但需要统一半径
- 要把无限验证转成有限验证
- **核心操作**：按本讲的 `Operational Procedure` 选路；若结构不匹配，返回总控路由，不强套。

## Key Concepts
- **有限开覆盖**
- **紧性**
- **局部到整体**
- **一致连续**
- **统一常数**

## Operational Procedure
1. 必要时延拓端点以避免邻域越界。
2. 任取一点，挖掘与目标整体性质同构的局部性质 P。
3. 让点跑遍闭区间，形成开覆盖。
4. 取有限子覆盖。
5. 从有限个局部常数中取最小/最大，得到统一常数。
6. 验证整体性质。

## Decision Points
- 局部性质必须和目标整体性质结构一致，例如一致连续要“两动点”形式。
- 只在有限闭区间上使用此紧性路线。

## Mental Models
- 把定理看作有“作用对象”的工具：先匹配结构，再执行公式。
- 把证明/计算看作结构变换链：每一步都应降低不确定性或复杂度。

## Anti-patterns
- **避免**：从普通连续性的一动一定结构直接跳到一致连续。
- **避免**：局部半径依赖点，却没通过有限覆盖统一。

## Worked Example
Cantor 一致连续性：每点先得到控制邻域，再将局部结论改写成邻域内任意两点的差值控制；有限子覆盖后取有限个半径的最小值。

## Failure Recovery
1. **工具无效**：回到题型结构，检查是否选错定理层级或漏掉更强/更弱条件。
2. **估计不收敛/不够紧**：恢复被过度丢弃的主阶信息，改用精细放缩、分段或另一标准对象。
3. **形式统一越变越复杂**：撤销最近变换，换统一方向；优先向已知、低阶、单变量或标准形靠拢。
4. **存在性无法证明**：若目标允许，切换到 Cauchy/紧性/单调有界等“不先知道极限值”的路线。

## Key Takeaways
- 先识别本讲的**作用对象特征**，再调用方法。
- 关键技术必须能解释“为什么这一步让结构更简单或更可控”。
- 保留例外、临界情形和失败信号；无法满足前提时应换路线。
