# 第 37 讲：定积分定义中的数学思想方法

## Core Idea
定积分定义沿用“分割—局部近似—求和—极限”：把整体量拆成局部小块，以简单值代替局部变化，再用极限消除近似误差。

## Frameworks Introduced
- **结构触发器**：当出现以下情形时，优先加载本讲。
- 理解/构造 Riemann 和
- 由定义证明积分
- 从现实整体量抽象定积分
- **核心操作**：按本讲的 `Operational Procedure` 选路；若结构不匹配，返回总控路由，不强套。

## Key Concepts
- **Riemann和**
- **分割**
- **样点**
- **局部近似**
- **最大分割长度**

## Operational Procedure
1. 确认被积量具有可加的整体结构。
2. 分割区间。
3. 在每个小区间选样点，用 f(ξi)Δxi 做局部近似。
4. 求和得到整体近似。
5. 控制最大分割长度 λ。
6. 令 λ→0，并要求极限与分割/样点选择无关。

## Decision Points
- 积分定义中的自由度有两层：分割方式和样点选择；可积性要求结果对这些选择稳定。

## Mental Models
- 把定理看作有“作用对象”的工具：先匹配结构，再执行公式。
- 把证明/计算看作结构变换链：每一步都应降低不确定性或复杂度。

## Anti-patterns
- **避免**：只取等分和固定端点就把它当定义本身。
- **避免**：忽略样点任意性。

## Worked Example
曲边面积：每个小区间用矩形面积近似，区间越细误差越小；极限独立于分割与样点时得到定积分。

## Failure Recovery
1. **工具无效**：回到题型结构，检查是否选错定理层级或漏掉更强/更弱条件。
2. **估计不收敛/不够紧**：恢复被过度丢弃的主阶信息，改用精细放缩、分段或另一标准对象。
3. **形式统一越变越复杂**：撤销最近变换，换统一方向；优先向已知、低阶、单变量或标准形靠拢。
4. **存在性无法证明**：若目标允许，切换到 Cauchy/紧性/单调有界等“不先知道极限值”的路线。
