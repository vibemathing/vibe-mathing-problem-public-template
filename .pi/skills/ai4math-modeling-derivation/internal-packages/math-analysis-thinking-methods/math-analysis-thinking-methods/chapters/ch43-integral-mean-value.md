# 第 43 讲：定积分的中值问题

## Core Idea
积分中值问题要在“积分整体量”和“某点函数值/导数”之间建立桥梁。可用积分中值定理、微分中值定理、Taylor 或分部积分；选择取决于结论中的阶数与中值点结构。

## Frameworks Introduced
- **结构触发器**：当出现以下情形时，优先加载本讲。
- 存在 ξ 使积分等于某函数值组合
- 高阶导数中值
- 积分平均值与导数关系
- **核心操作**：按本讲的 `Operational Procedure` 选路；若结构不匹配，返回总控路由，不强套。

## Key Concepts
- **积分中值定理**
- **Taylor**
- **分部积分**
- **展开点**
- **矩消去**

## Operational Procedure
1. 分析结论需要几阶导数/几个中值点。
2. 低阶：尝试积分中值定理直接产生点。
3. 要导数信息：先把积分变成差值或辅助函数，再用微分中值定理。
4. 高阶：用 Taylor 带 Lagrange 余项并选择展开点。
5. 若一阶项积分后会干扰，选展开中心使其积分为0。
6. 分部积分可把积分转成边界项与导数积分。

## Decision Points
- 展开点可以为了消掉低阶积分矩而主动选择。

## Mental Models
- 把定理看作有“作用对象”的工具：先匹配结构，再执行公式。
- 把证明/计算看作结构变换链：每一步都应降低不确定性或复杂度。

## Anti-patterns
- **避免**：机械在端点 Taylor，低阶项不能消掉。
- **避免**：多次中值定理默认产生同一点。

## Worked Example
要得到二阶导数的积分中值式，可在区间中点展开；一阶项关于对称区间积分为0，剩下二阶余项再用积分中值处理。

## Failure Recovery
1. **工具无效**：回到题型结构，检查是否选错定理层级或漏掉更强/更弱条件。
2. **估计不收敛/不够紧**：恢复被过度丢弃的主阶信息，改用精细放缩、分段或另一标准对象。
3. **形式统一越变越复杂**：撤销最近变换，换统一方向；优先向已知、低阶、单变量或标准形靠拢。
4. **存在性无法证明**：若目标允许，切换到 Cauchy/紧性/单调有界等“不先知道极限值”的路线。
