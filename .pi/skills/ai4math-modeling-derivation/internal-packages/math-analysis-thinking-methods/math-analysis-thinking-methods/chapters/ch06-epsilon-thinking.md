# 第 6 讲：量ε中的数学思想

## Core Idea
ε 的价值在于把无限多种精度要求压缩为一个任意参数：给定前可任意小，给定后可作为确定常数参与运算。善用这两种属性可以完成唯一性、有界性和复杂依赖证明。

## Frameworks Introduced
- **结构触发器**：当出现以下情形时，优先加载本讲。
- 证明极限唯一性
- 由收敛推出有界
- 证明中需要把动态误差变成固定常数
- **核心操作**：按本讲的 `Operational Procedure` 选路；若结构不匹配，返回总控路由，不强套。

## Key Concepts
- **ε任意性**
- **ε确定性**
- **唯一性**
- **有界性**
- **冻结参数**

## Operational Procedure
1. 先判断当前步骤需要 ε 的任意性还是确定性。
2. 要证明常数差为0：保留 ε 的任意性，得到“<ε 对所有 ε 成立”。
3. 要得到固定界：取某个具体 ε（如1），把动态条件冻结。
4. 复杂证明中，一旦 ε 给定，由它确定的 N 及有限前项都可视为确定量。

## Decision Points
- 证明相等时利用“任意小”；证明有界时利用“取定后确定”。

## Mental Models
- 把定理看作有“作用对象”的工具：先匹配结构，再执行公式。
- 把证明/计算看作结构变换链：每一步都应降低不确定性或复杂度。

## Anti-patterns
- **避免**：在同一步既把 ε 当任意量又随意修改其值。
- **避免**：需要固定界时仍保留未定 ε，导致所谓“界”不确定。

## Worked Example
唯一性：若 xn→a 且 xn→b，则 |a-b|≤|a-xn|+|xn-b|<ε；由 ε 可任意小推出 a=b。收敛蕴含有界：取 ε=1 控制尾段，再合并有限前段。

## Failure Recovery
1. **工具无效**：回到题型结构，检查是否选错定理层级或漏掉更强/更弱条件。
2. **估计不收敛/不够紧**：恢复被过度丢弃的主阶信息，改用精细放缩、分段或另一标准对象。
3. **形式统一越变越复杂**：撤销最近变换，换统一方向；优先向已知、低阶、单变量或标准形靠拢。
4. **存在性无法证明**：若目标允许，切换到 Cauchy/紧性/单调有界等“不先知道极限值”的路线。
