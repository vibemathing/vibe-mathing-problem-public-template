# 第 54 讲：Dini定理中的判别思想方法

## Core Idea
Dini 判别利用函数自身的连续性与关于 n 的单调性，把函数列/同号函数项级数的点态收敛升级为闭区间上一致收敛。它体现“函数对象比数对象多出的分析性质”。

## Frameworks Introduced
- **结构触发器**：当出现以下情形时，优先加载本讲。
- 闭区间函数列一致收敛
- 极限函数可算且连续
- 对每个 x，序列关于 n 单调
- **核心操作**：按本讲的 `Operational Procedure` 选路；若结构不匹配，返回总控路由，不强套。

## Key Concepts
- **Dini定理**
- **连续性**
- **单调性**
- **闭区间**
- **连续化**

## Operational Procedure
1. 求极限/和函数。
2. 验证每个 S_n 连续，极限 S 连续。
3. 验证对每个 x，S_n(x) 关于 n 单调。
4. 若 n 的单调性难看，把 n 连续化为 t，再用导数判符号。
5. 确认区间是有限闭区间。
6. 应用 Dini。

## Decision Points
- Dini 很好用，但闭区间与极限函数连续是硬前提。

## Mental Models
- 把定理看作有“作用对象”的工具：先匹配结构，再执行公式。
- 把证明/计算看作结构变换链：每一步都应降低不确定性或复杂度。

## Anti-patterns
- **避免**：在开区间或无界区间直接套 Dini。
- **避免**：未算出/未验证极限函数连续。

## Worked Example
(1+x/n)^n 在 [0,1]：点态极限 e^x 连续，各项连续；再验证关于 n 单调，即可由 Dini 得一致收敛。

## Failure Recovery
1. **工具无效**：回到题型结构，检查是否选错定理层级或漏掉更强/更弱条件。
2. **估计不收敛/不够紧**：恢复被过度丢弃的主阶信息，改用精细放缩、分段或另一标准对象。
3. **形式统一越变越复杂**：撤销最近变换，换统一方向；优先向已知、低阶、单变量或标准形靠拢。
4. **存在性无法证明**：若目标允许，切换到 Cauchy/紧性/单调有界等“不先知道极限值”的路线。

## Key Takeaways
- 先识别本讲的**作用对象特征**，再调用方法。
- 关键技术必须能解释“为什么这一步让结构更简单或更可控”。
- 保留例外、临界情形和失败信号；无法满足前提时应换路线。
