# 第 5 讲：从数列极限的性质谈起

## Core Idea
把极限性质按“运算性质”和“序性质”区分使用：等式型性质主要用于把复杂结构拆成简单结构；不等式型性质主要用于估计、控制未知项和建立有界性。

## Frameworks Introduced
- **结构触发器**：当出现以下情形时，优先加载本讲。
- 复杂数列极限不能直接用定义
- 需要证明商、积等运算法则
- 估计未知量、甩掉无关项
- **核心操作**：按本讲的 `Operational Procedure` 选路；若结构不匹配，返回总控路由，不强套。

## Key Concepts
- **运算性质**
- **序性质**
- **有界性**
- **保序性**
- **插项**
- **估计**

## Operational Procedure
1. 识别目标是计算还是估计。
2. 计算型：用极限运算性质拆分复杂结构。
3. 估计型：用有界、保序、夹逼等序性质产生可控上下界。
4. 含未知分母时，先由收敛性/保序性给出远处的正下界。
5. 通过插项把未知差值分解成已知差值。

## Decision Points
- 等式性质用于结构简化；序性质用于控制。
- 存在性、唯一性、有界性是判断概念和后续理论的基础属性。

## Mental Models
- 把定理看作有“作用对象”的工具：先匹配结构，再执行公式。
- 把证明/计算看作结构变换链：每一步都应降低不确定性或复杂度。

## Anti-patterns
- **避免**：商极限中直接把分母当常数，未证明远离0。
- **避免**：只知道性质名称，却没有识别它解决的是“计算”还是“估计”。

## Worked Example
证明 xn/yn→a/b：分子通过插项分离 |xn-a|、|yn-b|；分母利用 yn→b≠0 得到 |yn| 的确定正下界，再统一估计。

## Failure Recovery
1. **工具无效**：回到题型结构，检查是否选错定理层级或漏掉更强/更弱条件。
2. **估计不收敛/不够紧**：恢复被过度丢弃的主阶信息，改用精细放缩、分段或另一标准对象。
3. **形式统一越变越复杂**：撤销最近变换，换统一方向；优先向已知、低阶、单变量或标准形靠拢。
4. **存在性无法证明**：若目标允许，切换到 Cauchy/紧性/单调有界等“不先知道极限值”的路线。
