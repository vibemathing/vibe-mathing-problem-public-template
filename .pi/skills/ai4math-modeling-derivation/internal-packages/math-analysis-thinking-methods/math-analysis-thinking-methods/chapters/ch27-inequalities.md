# 第 27 讲：不等式中的数学思想方法

## Core Idea
不等式题先按结构分类，再把它统一到最匹配的分析工具：单变量函数用单调/极值，Taylor 型用展开，两点差值用中值定理，三点关系用凸性，离散整数参数可连续化。

## Frameworks Introduced
- **结构触发器**：当出现以下情形时，优先加载本讲。
- 证明函数不等式
- 含两点函数值差
- 含三点或加权平均
- 整数参数不等式
- **核心操作**：按本讲的 `Operational Procedure` 选路；若结构不匹配，返回总控路由，不强套。

## Key Concepts
- **单调性**
- **极值**
- **中值定理**
- **Taylor**
- **凸性**
- **连续化**

## Operational Procedure
1. 移项构造 F，并确定变量数量。
2. 单变量：求导看单调或最值。
3. 两点差值：优先中值定理，把函数差变成导数。
4. 同点高阶结构：Taylor。
5. 三点/加权：检查凸性加权结构。
6. 整数离散：把 n 连续化为 x，研究对应函数。
7. 选择等号点作为构造和展开中心。

## Decision Points
- 等号成立位置是辅助函数和展开点的重要线索。
- 先找结构工具，再做代数；避免盲目求导。

## Mental Models
- 把定理看作有“作用对象”的工具：先匹配结构，再执行公式。
- 把证明/计算看作结构变换链：每一步都应降低不确定性或复杂度。

## Anti-patterns
- **避免**：把所有不等式都转成求导，造成高阶复杂性。
- **避免**：忽略参数范围，使导数符号判断失效。

## Worked Example
形如 f(b)-f(a) 与 b-a 的比较，直接用中值定理把差值比变为 f′(ξ)，再对导数做上下界。

## Failure Recovery
1. **工具无效**：回到题型结构，检查是否选错定理层级或漏掉更强/更弱条件。
2. **估计不收敛/不够紧**：恢复被过度丢弃的主阶信息，改用精细放缩、分段或另一标准对象。
3. **形式统一越变越复杂**：撤销最近变换，换统一方向；优先向已知、低阶、单变量或标准形靠拢。
4. **存在性无法证明**：若目标允许，切换到 Cauchy/紧性/单调有界等“不先知道极限值”的路线。

## Key Takeaways
- 先识别本讲的**作用对象特征**，再调用方法。
- 关键技术必须能解释“为什么这一步让结构更简单或更可控”。
- 保留例外、临界情形和失败信号；无法满足前提时应换路线。
