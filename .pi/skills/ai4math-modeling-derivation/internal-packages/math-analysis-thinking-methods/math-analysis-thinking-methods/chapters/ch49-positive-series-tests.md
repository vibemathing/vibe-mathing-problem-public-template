# 第 49 讲：正项级数敛散性判别法则的逻辑关系及其应用思想方法

## Core Idea
正项级数判别法按通项结构路由：根值法适合 n 次幂/幂指，比值法适合阶乘，积分判别适合慢变因子，Raabe 处理比值法临界且有确定阶的结构。所有方法都源于比较思想。

## Frameworks Introduced
- **结构触发器**：当出现以下情形时，优先加载本讲。
- 判断正项级数敛散
- 通项含 n 次幂、阶乘、对数、双阶乘
- 多个判别法不知道选谁
- **核心操作**：按本讲的 `Operational Procedure` 选路；若结构不匹配，返回总控路由，不强套。

## Key Concepts
- **比较判别**
- **根值法**
- **比值法**
- **积分判别**
- **Raabe判别**

## Operational Procedure
1. 先确认正项。
2. 识别最复杂/最有区分度的因子。
3. n 次幂/幂指→根值法；阶乘→比值法。
4. 慢变 ln n 等导致阶不确定→积分判别。
5. 比值极限=1 且有精细阶→Raabe 或更精细法。
6. 仍不清楚时用 p-级数比较/试验法。
7. 临界值必须另判，不能由“=1”推出结论。

## Decision Points
- 判别法的条件结构就是其作用对象说明书。
- 比较标准要“已知且结构简单”。

## Mental Models
- 把定理看作有“作用对象”的工具：先匹配结构，再执行公式。
- 把证明/计算看作结构变换链：每一步都应降低不确定性或复杂度。

## Anti-patterns
- **避免**：遇到正项级数依次把所有判别法都试一遍。
- **避免**：根值/比值极限=1 就判发散。

## Worked Example
n! 与 a^n 混合优先比值；(ln n) 因子造成缓慢变化时，积分判别或 p-级数试验更自然；双阶乘常进入 Raabe。

## Failure Recovery
1. **工具无效**：回到题型结构，检查是否选错定理层级或漏掉更强/更弱条件。
2. **估计不收敛/不够紧**：恢复被过度丢弃的主阶信息，改用精细放缩、分段或另一标准对象。
3. **形式统一越变越复杂**：撤销最近变换，换统一方向；优先向已知、低阶、单变量或标准形靠拢。
4. **存在性无法证明**：若目标允许，切换到 Cauchy/紧性/单调有界等“不先知道极限值”的路线。

- 先识别本讲的**作用对象特征**，再调用方法。
- 关键技术必须能解释“为什么这一步让结构更简单或更可控”。
