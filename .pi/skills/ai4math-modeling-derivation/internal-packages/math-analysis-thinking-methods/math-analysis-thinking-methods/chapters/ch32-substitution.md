# 第 32 讲：不定积分计算的换元法

## Core Idea
换元的选择原则是“让最困难结构本质性简化，同时让其他因子至多非本质变复杂”，最终所有变量必须统一到新变量。

## Frameworks Introduced
- **结构触发器**：当出现以下情形时，优先加载本讲。
- 复合函数积分
- 根式/三角/有理结构可被代换消去
- 局部出现某函数及其导数
- **核心操作**：按本讲的 `Operational Procedure` 选路；若结构不匹配，返回总控路由，不强套。

## Key Concepts
- **换元法**
- **变量统一**
- **困难因子**
- **复合结构**

## Operational Procedure
1. 确定最困难因子。
2. 候选 t=g(x) 应直接简化该因子。
3. 检查 dx 与其余因子能否全部改写为 t。
4. 比较多个候选，选总结构最简单者。
5. 完成换元后用基本积分；最后回代。

## Decision Points
- “最难因子变简单”优先于“某一项看起来方便”。
- 若换元后混入两套变量，立即回退。

## Mental Models
- 把定理看作有“作用对象”的工具：先匹配结构，再执行公式。
- 把证明/计算看作结构变换链：每一步都应降低不确定性或复杂度。

## Anti-patterns
- **避免**：只替换局部表达式，dx 或其他因子未统一。
- **避免**：三角代换产生比原题更复杂的根式。

## Worked Example
根式含 a²-x² 时，可根据根式结构选三角代换；若被积式本身已含某复合函数与内导数，则优先直接内层换元。

## Failure Recovery
1. **工具无效**：回到题型结构，检查是否选错定理层级或漏掉更强/更弱条件。
2. **估计不收敛/不够紧**：恢复被过度丢弃的主阶信息，改用精细放缩、分段或另一标准对象。
3. **形式统一越变越复杂**：撤销最近变换，换统一方向；优先向已知、低阶、单变量或标准形靠拢。
4. **存在性无法证明**：若目标允许，切换到 Cauchy/紧性/单调有界等“不先知道极限值”的路线。
