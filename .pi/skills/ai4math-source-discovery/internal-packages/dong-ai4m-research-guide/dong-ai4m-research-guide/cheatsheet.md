# Cheatsheet

## 先选问题类型
| 用户目标 | 路线 | 关键条件 | 失败时 |
|---|---|---|---|
| 快速学习理论/找相似结论 | 知识导航 | 可检索资料、明确主题 | 缩小主题；补术语 |
| 严格验证证明 | Lean/形式化 | 可形式化命题 | 先查库与表示错误 |
| 从数据找规律/猜想 | 专用工具 | 可生成数据、数学解释能力 | 重做表征/缩题 |
| 系统解决一类数学任务 | 通用模型 + 形式反馈 | 形式数据、验证器 | 先修自动形式化/反馈 |
| 多步复杂求解 | Agent | 强基座、工具、反馈 | 补验证器/终止条件 |
| 优化已有方案 | Evolve | 可量化目标 + 好初始化 | 校准目标函数或换路 |

## 快速决策规则
- **数学兴趣为主** → 优先问“哪里能用数据发现结构？”
- **算法/编程兴趣为主** → 优先问“怎样形式化、验证、训练与编排？”
- **只有预测准确率** → 结论等级停在“线索”。
- **Lean 卡住** → 先分辨：库检索 / 自动形式化 / 证明搜索 / 局部补全。
- **强模型 + 多步任务 + 可验证反馈** → 优先评估 Agent。
- **目标可量化 + 有初始方案** → 可评估 Evolve。
- **评价指标与数学价值不一致** → 停止自动优化，先修指标。
- **自动化节省了时间** → 把时间投入结构、联系、猜想和解释。

## SELF_CHECK
1. 主目标属于知识导航、证明验证、洞察连接中的哪类？
2. 路线与兴趣和能力匹配吗？
3. 数据/形式化/工具/验证器前提齐吗？
4. 输出是数学结论、验证结果，还是仅仅线索？
5. 有明确失败信号与换路条件吗？
6. 最终是否增加了数学理解？
