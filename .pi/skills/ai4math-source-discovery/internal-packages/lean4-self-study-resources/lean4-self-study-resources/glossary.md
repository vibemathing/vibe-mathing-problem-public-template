# Glossary

**Functional Programming in Lean** — functional-programming learning track listed under the Chinese Lean resource hub (Ch 1).

**Lean official online compiler** — online Lean execution platform at https://live.lean-lang.org/ (Ch 2).

**LeanSearch** — theorem-search engine named in the archive (Ch 2).

**leanprover.cn** — Chinese Lean resource hub that lists functional programming, theorem proving, metaprogramming, and formal mathematics learning material (Ch 1).

**Mathematics in Lean** — formal-mathematics learning resource described by the archive as main class content and strongly recommended (Ch 1).

**Mathlib API Documentation** — Mathlib documentation used for theorem/declaration/API lookup; https://leanprover-community.github.io/mathlib4_docs/ (Ch 2).

**Metaprogramming in Lean** — metaprogramming learning track listed under the Chinese Lean resource hub (Ch 1).

**Moogle** — theorem-search engine at https://www.moogle.ai/ (Ch 2).

**Natural Number Game** — introductory game around natural-number theorems at https://adam.math.hhu.de/#/g/leanprover-community/nng4 (Ch 1).

**NUS Lean minicourse** — Lean lecture/minicourse material at https://github.com/NUS-Math-Formalization/minicourse/tree/main (Ch 1).

**Quokka** — automated formalization platform at https://quokka-beta.reaslab.io/; the archive says bug feedback is welcome but does not record a channel (Ch 2).

**ReasLab** — general learning resource listed at https://beta.reaslab.io; the archive gives no narrower feature definition and says bug feedback is welcome without naming a channel (Ch 1).

**Terence Tao's Lean cheatsheet** — compact Lean reference linked from the archive (Ch 1).

**Theorem Proving in Lean** — theorem-proving learning track listed under the Chinese Lean resource hub (Ch 1).

**Zulip** — Lean community chat referenced by the archive as a routine support resource (Ch 2).
