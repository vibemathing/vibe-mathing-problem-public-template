# Workflow — Evaluation design

1. Translate each product/research claim into a measurable capability.
2. Pick at least one benchmark that directly measures it.
3. Add one stress test for shortcut learning, modality use, multilingual transfer, or contamination when relevant.
4. Record exact split/version and inference protocol.
5. Report answer-level and process/formal metrics when final accuracy can hide invalid paths.
6. Compare systems only under compatible tool/search/TTRL budgets; otherwise separate them.
7. If the chosen benchmark is near saturation, add a harder/live/frontier set.
8. If freshness matters, retrieve current benchmark state beyond July 2026.
