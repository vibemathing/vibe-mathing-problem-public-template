# AI4Math Research Navigator

An installable research-routing skill compiled from the uploaded July 2026 AI4Math survey companion index.

Use it to classify AI-for-math tasks, choose method families and verifiers, design benchmark/evaluation protocols, diagnose common failure modes, and locate indexed systems/datasets/papers. The skill keeps detailed catalog data outside the main instructions so agents can load it progressively.

The source archive is a companion index, not the full survey paper. The skill preserves that boundary explicitly.
